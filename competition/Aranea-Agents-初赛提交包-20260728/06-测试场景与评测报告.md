### 8.3 核心创新点（差异化）

1. **岗位化静态编组 + Skill 自动进化双引擎**：以现实社会分工规则先验定义岗位职责/权限/验收标准（方向约束不漂移、可审计），同时从历史活动观测中自动发现高频工具调用模式、LLM 融合生成新 Skill 经审批注册——组织稳定，能力生长（TS-1/TS-9 + TS-4）。
2. **引擎硬驱动的零人工运维闭环**（TS-9）：预规划复杂度评估 + plan confirm 硬门控 + DAG 状态机推进 + 高危操作审批 + 交付物认知信封，P2 事故从告警到复盘全链路自主闭环，流程控制权在引擎不在 AI。
3. **五层记忆 + 共享黑板**（TS-7）：L0-L4 记忆体系 + graph StateFields 团队黑板 + deliverable 产物引用，解决多 Agent 上下文传递。

### 8.4 已知限制（诚实披露）

- TS-9 实跑为**模拟事故环境**（事故指标与恢复指令由场景脚本构造），未对接真实监控系统；Prometheus / Zabbix webhook 接入列入复赛计划。
- TS-9 复盘环节当前由复盘文档专家**补位执行**（Spirit DAG 未自动编排复盘团队），闭环类任务自动追加复盘节点列入复赛计划（TS9-GAP-1）。
- MCP 当前接入 1 个 stdio Server（Playwright），remote MCP（HTTP/SSE）尚未实测。
- 团队运行历史中存在 failed/cancelled 记录（`ts2-team-run.json`），失败恢复与重试策略仍有优化空间。
- 知识库截图（`ts7-02-knowledge.png`）中文档显示 error 状态为**预期降级行为**：实跑环境未配置 Embedder API Key 时，文档按原始文本入库并保证 `content_text` 可访问与全文预览，仅向量检索不可用；配置 Embedder 后自动转为向量化摄入流程。
