# 作品简介

**项目名称**：Aranea-Agents —— 以社会分工规则组织 AI、以历史活动驱动自我进化的岗位化多 Agent 编排平台

**问题与场景**：零人工运维要求「告警聚合→根因定位→修复执行→恢复验证→事故复盘」全链路自主闭环。单 Agent 上下文见顶，无法承载跨域排障；主流方案由 LLM 即兴生成子 Agent，角色边界模糊、约束随上下文稀释、行为不可审计，难以进入生产。

**核心解决方案**：以 trpc-agent-go 为内核，首创「行业→部门→岗位」三级科层组织——以现实社会分工规则静态定义 304 个 Agent 的岗位职责、能力边界与工具白名单；三层确定性编排引擎（Team 六模式 / Graph / Spirit）将任务编译为 DAG，由状态机硬驱动推进；五层记忆与团队共享黑板防决策稀释；高危动作强制审批、回滚、审计。

**创新点与差异化优势**：① 岗位化静态编组——职责、权限与验收标准先验定义、可审计，方向约束不漂移，相比即兴生成子 Agent 可控性本质提升；② Skill 自动进化——从历史活动观测挖掘高频工具调用模式，LLM 合成新 Skill 经审批状态机注册发布，平台依据运行经验自我生长；③ 引擎硬驱动门控——推进由结构化信号判定，AI 无权跳过质量关卡。

**开放/复用价值**：内核 trpc-agent-go 开放；岗位包、Skill、团队模板可跨行业复制分发；计划以 Apache-2.0 开源核心编排与 Skill 工程体系。

**当前进展**：平台可运行。P2 生产事故零人工运维闭环端到端实跑（告警分诊→根因定位→修复执行→恢复验证→复盘，502 错误率 23%→0.03%，人工介入 0）；Skill 自动进化全链路实证（检测→去重→LLM 生成→审批→注册）；附 25 张 UI 证据、16 份 API 记录与评测报告（自评 90/100）。
