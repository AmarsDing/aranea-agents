## 一、代码包内容

| 目录 | 内容 |
|------|------|
| `cmd/` | 运行入口：`cmd/admin`（服务端）、`cmd/aranea`（CLI） |
| `internal/` | 业务核心：service / biz / data / agent / event 分层（45+ 模块） |
| `pkg/trpc-agent-go/` | Agent 运行时内核（Runner / Agent / Session / Memory / Tool / Skill / Graph / Team）——多 Agent 协同设计基点框架 |
| `api/kratos/` | Proto 定义（HTTP/gRPC/WebSocket 契约） |
| `web/` | 前端：Vue 3 + Quasar + Pinia + TypeScript |
| `configs/` | 配置文件样例（`config.yaml`） |
| `docs/` | 模块开发文档（需求/设计/开发计划三件套，65+ 篇）与架构决策记录 ADR |
| `scenario/` | 内置行业模板（金融/自媒体/软件开发：部门、岗位、团队种子） |
| `Makefile` | 一键初始化 / 构建 / 测试 / lint |

## 二、依赖说明

- Go 1.25+ · Node.js 20+ · SQLite 3+
- PostgreSQL 14+（可选，pgvector 向量存储；不启用时自动降级）
- 完整依赖锁定于 `go.mod` / `web/package.json`

## 三、运行入口与配置

```bash
# 1. 初始化（生成 proto + wire + 前端依赖）
make all

# 2. 启动后端（免登录开发模式）
#    Linux/macOS:
DEPLOY_ENV=dev KRATOS_HTTP_AUTH_DISABLED=1 go run ./cmd/admin -conf ./configs/config.yaml
#    Windows PowerShell:
#    $env:DEPLOY_ENV="dev"; $env:KRATOS_HTTP_AUTH_DISABLED="1"
#    go run ./cmd/admin -conf ./configs/config.yaml

# 3. 启动前端
cd web && npm install && npm run dev   # http://localhost:9001

# 4. 健康检查
curl http://localhost:8000/healthz     # 本地账号 dev / dev
```

LLM Provider 在 Web 控制台「模型目录」中配置（支持 DeepSeek / Qwen / OpenAI / OpenRouter 等 12+ Provider，实跑使用 deepseek-v4-flash）。

**输入**（Web 聊天框，精灵助手）：
> 请调研云计算在医疗行业的市场趋势，分析 2-3 个主要竞品（如阿里云、腾讯云的医疗云方案），并生成一份包含成本估算的策略简报。

完整证据：提交包 `evidence/ts2-*.png`、`api/ts2-*.json`、`06-测试场景与评测报告.md` §四。
