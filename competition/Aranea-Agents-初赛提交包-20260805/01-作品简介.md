# 作品简介

**项目名称**：Aranea-Agents —— 岗位化多 Agent 编排平台：以社会分工规则组织 AI，以历史活动驱动自我进化

**问题与场景**：零人工运维要求「告警聚合→根因定位→修复执行→恢复验证→事故复盘」全链路自主闭环。主流方案由 LLM 即兴生成子 Agent，角色边界模糊、约束随上下文稀释、行为不可审计，进不了生产。

**核心解决方案**：以 trpc-agent-go 为内核，按「行业→部门→岗位」三级科层静态定义 304 个 Agent 的职责、权限与工具白名单；三层编排引擎（Team 六模式 / Graph / Spirit）将任务编译为 DAG，由状态机硬驱动推进——AI 输出的「完成了」不参与推进判定；五层记忆与团队共享黑板防决策稀释；高危动作强制审批、回滚、审计。

**创新与差异化**：① 岗位化静态编组——职责权限先验落库、越权调用引擎层拒绝，方向约束不漂移；② Skill 自动进化——从运行观测挖掘高频工具调用模式，LLM 合成新 Skill 经审批状态机注册，平台随经验自我生长；③ 引擎硬门控——流程推进由结构化信号判定，AI 无权跳关。

**实跑证据**：P2 生产事故零人工闭环端到端实跑（分诊→定位→修复→验证→复盘）：502 错误率 23%→0.03%、慢查询 187→2/min、QPS 45→320、人工介入 0；224 个活动、12 份交付物全链落库；Skill 自动进化全链路实证（检测→去重→LLM 生成→审批→注册）；8 大测试场景全通过，实跑发现并修复 5 个缺陷（附回归测试）。

**开放/复用**：内核 trpc-agent-go 开放；岗位包、Skill、团队模板可跨行业复制分发；计划以 Apache-2.0 开源核心编排与 Skill 工程体系。
