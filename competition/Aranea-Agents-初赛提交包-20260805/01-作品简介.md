# 作品简介

**项目名称**：Aranea-Agents —— 岗位化多 Agent 编排平台：以社会分工规则组织 AI，以历史活动驱动自我进化

**问题与场景**：数据中心规模膨胀——数千台服务器与交换机/防火墙等异构设备，配置项数十万级，变更日均数十起，运维人力却线性受限。核心需求四层：看得见（全域可观测）、诊断快（告警风暴 90%+ 为噪声，须分钟级降噪定根因）、执行稳（70%+ 事故源于变更，须事前验证、事中门控、事后回滚）、经验长（处置经验沉淀复用，不随人流失）。零人工运维须自主承接三大场景：告警自愈闭环、配置变更升级、设备批量初始化。主流方案由 LLM 即兴生成子 Agent，角色模糊、约束稀释、不可审计，进不了生产。

**核心解决方案**：以 trpc-agent-go 为内核，按「行业→部门→岗位」三级科层静态定义 304 个 Agent 的职责、权限与工具白名单；三层编排引擎（Team/Graph/Spirit）将任务编译为 DAG，由状态机硬驱动推进；五层记忆与共享黑板防决策稀释。① 告警自愈：聚合降噪→根因链+置信度→可回滚优先处置（高危强制审批）→基线验证→复盘入库→高频模式固化为 Skill→输出防范优化，从治病走向免疫；② 配置升级：用户指令→策略生成→虚拟环境灰度验证→成熟策略 Skill 化→金丝雀批次升级→失败自动回滚；③ 设备初始化：配置模板化为 Skill，经 MCP 对接异构设备，批量下发、回读校验、漂移纠偏，千台初始化从数周缩至小时级。

**创新与差异化**：岗位化静态编组——职责权限先验落库、越权调用引擎层拒绝；Skill 自动进化——高频模式经 LLM 合成、审批注册，平台随经验自我生长；引擎硬门控——结构化信号推进，AI 无权跳关。

**实跑证据**：P2 事故零人工闭环实跑：502 错误率 23%→0.03%、慢查询 187→2/min、QPS 45→320、人工介入 0；224 个活动、12 份交付物全链落库；9 大测试场景全通过。

**开放/复用**：内核 trpc-agent-go 开放；岗位包、Skill、团队模板跨行业复制；核心编排与 Skill 工程体系计划 Apache-2.0 开源。
