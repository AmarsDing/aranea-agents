## 三大核心技术（差异化）

1. **岗位化静态编组**：304 个 Agent 职责/权限/工具白名单先验落库，方向约束不漂移、越权引擎层拒绝——vs LLM 即兴生成子 Agent 的本质差异。
2. **引擎硬门控**：任务编译为 DAG 由状态机推进，AI 输出的「完成了」不参与推进判定；plan confirm 人工硬门控，AutoHop 连跳上限防空转。
3. **Skill 自动进化**：运行观测 → 模式检测（confidence=1.0）→ Pattern Hash 幂等去重 → LLM 合成 → 审批状态机 → 注册发布，平台随经验自我生长（全链路 API 实证）。

## 开源与路线

内核 trpc-agent-go 已开放；计划 Apache-2.0 开源编排引擎、Skill 工程体系、五层记忆；岗位模板包跨行业复制（IT 运维/金融/自媒体/软件研发）。路线：初赛 V0.4（8 场景实证）→ 复赛 V0.6（Prometheus/Zabbix 真实接入、远程 MCP）→ 决赛 V1.0（开源 + Skill 市场）。
