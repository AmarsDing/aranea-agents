# Aranea-Agents · 初赛提交包（2026-08-05）

> 赛道：新智基座丨Agent Infra —— **方向一：零人工运维**
> 项目：Aranea-Agents 岗位化多 Agent 编排平台 —— 以社会分工规则组织 AI，以历史活动驱动自我进化

## 30 秒了解本项目

电商 P2 生产事故（502 错误率 23% + 慢查询 47s + 连接池耗尽）端到端实跑：**告警分诊 → 根因定位 → 修复方案 → 恢复执行 → 事故复盘，全程人工介入 0 次**，502 错误率 23%→0.03%，QPS 45→320；224 个运维活动、12 份交付物全链落库可复核。

三大差异化：① 岗位化静态编组（304 Agent 职责/权限/工具白名单先验落库，vs LLM 即兴生成子 Agent）② 引擎硬门控（DAG 状态机推进，AI 无权跳关）③ Skill 自动进化（观测→检测→去重→LLM 生成→审批→注册，全链路实证）。
