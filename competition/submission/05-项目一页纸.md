## 目标场景与核心问题

个人与中小团队的跨职能复杂任务（市场调研、投研分析、研发协同）：单 Agent 能力见顶、多 Agent 编排黑盒、经验无法沉淀、成本与安全失控。让每个用户像总裁一样，通过"精灵"指挥按行业/部门/岗位组织的 Agent 团队完成端到端闭环。

## 方案概述

以 trpc-agent-go 为运行时内核、Kratos v2 为传输层：**三层编排引擎**（Team 六模式 / Graph 图编排 / Spirit 动态编排）+ **274 个职能 Agent**（行业→部门→岗位三级组织）+ **Skill 能力抽象层** + **MCP 工具连接层** + **五层记忆（L0-L4）与团队共享黑板** + **Trace/Log/Metrics 全链路可观测与审批/回滚/审计**。

## 多 Agent 架构（AgentTeams 五要素映射）

角色编排（Orchestrator/Worker/Synthesizer + coordinator）· 任务拆解（plan_and_execute → DAG）· 上下文传递（StateFields 共享黑板 + deliverable 产物引用）· 协同执行（成员并行 + 流式活动树 + 失败降级）· 状态追踪（TeamRun 状态机 + 会话参与者/运行记录）——五要素全部落地并有实跑实证。

## 关键 Skill 与工具链

- **Skill（必选）**：全生命周期管理（注册/版本/渐进加载/健康治理/消亡重生）+ **自动进化闭环**（观测→模式检测→Pattern Hash 去重→LLM 生成→人工审批→注册发布）。核心清单：InformationResearch（自动生成）、planning-and-task-breakdown（5113 次调用 100% 成功）、idea-refine（5116 次 100%）。
- **工具/MCP**：65 个内置工具（统一注册表契约）+ MCP Server（Playwright stdio，health=ok，凭证加密 + 健康监控）。
- **RAG/上下文**：五层记忆 + 知识库 RAG（pgvector）+ 团队共享黑板（4 项能力实现 3 项+）。

## Demo 运行结果（2026-07-25 实跑）

任务：「调研云计算在医疗行业的市场趋势，分析 2-3 个竞品，生成含成本估算的策略简报」。精灵动态组建「医疗云市场研究小组」（Orchestrator/WebSearch/MarketResearch/CostEstimation，DAG 约 5 步）→ 就成本维度**人工确认** → 并行执行（Web 断连自动降级）→ 输出策略简报（信创合规评分 + 三甲医院上云 60-90 万/年 vs 传统机房 300-500 万 CAPEX + 分阶段建议）。**8 大测试场景全通过，五维自评 88/100**，32 张 UI 截图 + 15 份 API 记录可复核。

## 开放/开源贡献

运行时内核 trpc-agent-go 已开放；计划 Apache-2.0 开源三层编排引擎、Skill 工程体系（含自动进化）、五层记忆与工具契约；可分发 Skill 包、Agent/团队/行业模板与评测数据集。

## 业务价值与可复制性

复杂知识工作从「数天人工」到「一次指令、分钟级闭环」；方法论固化为 Skill 持续增值；「行业→部门→岗位」模板 + 统一编排引擎可复制到金融、医疗、电商、政务等任何知识密集型行业。
