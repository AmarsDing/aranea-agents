## 问题与痛点（行业共性 → 我们的解法）

| 痛点 | 行业现状 | Aranea-Agents 解法 |
|------|---------|-------------------|
| **AI 无质量门控** | AI 想跳过审查就能跳过，没有人拦得住 | 三层编排引擎 + 门控信号判定，AI 输出的"完成了"不参与推进判定 |
| **流程不一致** | 同一任务今天走五步明天走三步，结果不可预测 | Graph StateFields 共享黑板 + deliverable 工具集，决策不稀释 |
| **经验无法沉淀** | 好的工作方法只存在于某次对话，换项目一切归零 | Skill 自动进化：高频模式 → LLM 生成 → 审批注册 → 生态生长 |
| **提示词 = 建议 ≠ 约束** | 把流程写成提示词，AI 想不遵守就不遵守 | 流程写在引擎确定性逻辑里，三层引擎就是给 AI 装的红绿灯 |
| **全自动无限空转** | 全自动流程一直空转，永不交还控制权 | AutoHopState 连跳上限 + 人工确认介入点，超 N 步强制暂停 |

> 上述痛点提炼自外部对标视频（抖音 @云淡风轻《Harness引擎》），与我们的架构设计形成完整映射。详见 [09-视频音频转录全文.md](./09-视频音频转录全文.md) §一。
