# 作品简介

**项目名称**：Aranea-Agents —— 一人统领 N 家虚拟公司的多 Agent 编排平台

**问题与场景**：个人与中小团队面对跨领域复杂任务时，单 Agent 能力见顶、多 Agent 编排黑盒。更根本的是：AI 无质量门控——想跳过审查就能跳过；流程不一致——同一任务今天走五步明天走三步；经验无法沉淀——换项目一切归零；全自动流程无限空转——永不交还控制权。主流方案把流程写成提示词，但"建议不等于约束"。

**核心解决方案**：以 trpc-agent-go 为运行时内核、Kratos v2 为传输层，构建三层编排引擎（Team 六模式 / Graph 图编排 / Spirit 动态编排），让引擎管流程、模型管执行。274 个不同职能 Agent 按"行业→部门→岗位"三级组织；Skill 为能力抽象层，MCP 为工具连接层；五层记忆（L0–L4）+ 团队共享黑板传递上下文；Trace/Log/Metrics 全链路可观测，高风险动作审批/回滚/审计全覆盖。

**创新点与差异化优势**：① Skill 自动进化——从运行观测发现高频工具调用模式，LLM 生成新 Skill，经审批注册发布，生态自我生长；② 精灵动态编排——无需预定义团队，按任务拆解 DAG、组建临时团队、合成结果，支持人工确认介入点与连跳上限安全阀；③ 五层记忆 + 认知信封产物引用，系统化解决多 Agent 上下文传递与决策稀释。

**开放/复用价值**：运行时内核 trpc-agent-go 开放；Skill/Agent/团队模板可跨行业复制分发；计划以 Apache-2.0 开源核心编排与 Skill 工程体系。

**当前进展**：平台可运行。已完成"医疗云市场调研"端到端实跑（拆解→组队→人工审批→并行执行→降级容错→合成简报）；Skill 自动进化全链路实证（检测→去重→LLM 生成→审批→注册）；附 25 张 UI 证据、15 份 API 记录与评测报告（自评 88/100）。
