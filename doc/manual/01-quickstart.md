# 01 快速上手

本章带你在 15 分钟内完成：部署 → 首次对话 → 组建公司 → 触发第一次团队编排。

## 1. 部署（三选一）

| 方式 | 适用 | 命令 |
|------|------|------|
| **Docker 一键** | 服务器 / 开发机（推荐） | `powershell -File docker/dev-up.ps1` 或 `docker compose up -d` |
| **Windows 安装包** | 零命令行桌面用户 | 双击安装包，Launcher 自动完成全部部署 |
| **源码开发** | 二次开发 | 见 [15 部署运维](15-deployment.md) |

验证：浏览器打开 `http://localhost:8810/healthz` 返回健康信息；前端开发模式访问 `http://localhost:9301`。

## 2. 首次对话（30 秒）

1. 打开 Web 界面 → 左侧导航 **聊天**；
2. 默认对话对象是**精灵助手**（`__spirit__`，系统内置总管家）；
3. 输入：「帮我做一份新能源汽车行业简报」；
4. 观察消息流中的三个关键信号：
   - **已召回 N 条记忆** —— 五层记忆系统在为回答提供上下文；
   - **已引用 N 条知识** —— 知识库检索结果注入；
   - **执行过程** —— Spirit 的规划/分配/编排步骤实时可见。

![精灵对话](../assets/screenshots/aranea-chat.png)

## 3. 组建你的第一家虚拟公司（10 分钟）

1. 左侧导航 **组织架构** → 新增公司；
2. 选择行业模板（金融 / 自媒体 / 软件开发），系统批量生成部门与岗位；
3. 每个岗位自动就位**专项 Agent**（自带使命、工具画像、技能）；
4. 回到聊天页，对精灵下达业务指令，Spirit 会从花名册中匹配专项 Agent 组队执行。

![组织架构](../assets/screenshots/aranea-organization.png)

## 4. 触发第一次编排

三种编排方式，按确定性从低到高：

| 方式 | 入口 | 适用 |
|------|------|------|
| **Spirit 动态编排** | 聊天页直接对话 | 开放式任务，系统自动规划 |
| **Team 固定团队** | Team 页 → 新增 TEAM → 选模式 |  repeatable 的固定协作流程 |
| **Graph 工作流** | Graph 页 → 新增 GRAPH / 从模板创建 | 需要条件分支、人工审批节点的确定性流程 |

Team 页可以按「公司 / 部门」浏览团队归属，点击运行按钮直接触发：

![Team 管理](../assets/screenshots/aranea-team.png)

## 5. 让系统开始进化

- 日常使用即在学习：记忆系统持续积累，进化检测器在后台扫描工具调用模式；
- 定期到 **进化建议** 页审批提案（全部需人工批准才会生效）；
- 到 **记忆中心** 查看五层记忆沉淀；到 **用量事件** 查看每笔 Token 消费。

![记忆中心](../assets/screenshots/aranea-memory.png)
