- **功能**：这个模块能做什么；
- **原理**：内部是怎么运转的（配图）；
- **设计**：关键设计决策与边界；
- **界面配置**：在 Web 界面上怎么用（配截图）；
- **深入阅读**：指向 `docs/development/` 下的权威开发文档。
