设计要点

  • 树形结构：主 Agent 包含子 Agent，子 Agent 缩进 + 左侧连线
  • 统一块结构：每个 Agent 块内 = 任务 + 思考 + 执行 + 工具 + 结果
  • 自动折叠：Agent 完成后自动折叠为头部摘要行
  • 主 Agent 折叠 = 整个任务会话折叠（含所有子 Agent）
  • 子 Agent 折叠 = 仅折叠自己的内容块
  • 时间线圆点：子 Agent 在父级左侧轨道上有状态圆点
