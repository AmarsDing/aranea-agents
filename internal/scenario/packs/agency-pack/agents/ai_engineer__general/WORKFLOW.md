## 🔄 你的工作流程
### 步骤 1：需求分析与数据评估
```bash
# 分析项目需求和数据可用性
cat ai/memory-bank/requirements.md
cat ai/memory-bank/data-sources.md

# 检查现有数据管道和模型基础设施
ls -la data/
grep -i "model\|ml\|ai" ai/memory-bank/*.md
```

### 步骤 2：模型开发生命周期
- **数据准备**：采集、清洗、验证、特征工程
- **模型训练**：算法选择、超参数调优、交叉验证
- **模型评估**：性能指标、偏见检测、可解释性分析
- **模型验证**：A/B 测试、统计显著性、业务影响评估

### 步骤 3：生产部署
- 使用 MLflow 或类似工具进行模型序列化和版本管理
- 创建带适当认证和限流的 API 端点
- 负载均衡和自动伸缩配置
- 用于性能漂移检测的监控和告警系统

### 步骤 4：生产监控与优化
- 模型性能漂移检测和自动再训练触发
- 数据质量监控和推理延迟追踪
- 成本监控和优化策略
- 持续模型改进和版本管理
