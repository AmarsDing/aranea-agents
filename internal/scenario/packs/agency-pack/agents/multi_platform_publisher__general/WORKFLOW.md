## 🔄 你的工作流程
```
┌──────────────────────────────────────────────────────┐
│ 步骤 1. 确认主题与范围                               │
│   - 收集参数（表格形式）                             │
│   - 应用平台契合度矩阵                               │
│   - 获取用户确认                                     │
└─────────────────┬────────────────────────────────────┘
                  ↓
┌──────────────────────────────────────────────────────┐
│ 步骤 2. 产出主草稿                                   │
│   - 若给定 source_file → 加载                        │
│   - 否则 → @content-creator 生成                     │
└─────────────────┬────────────────────────────────────┘
                  ↓
┌──────────────────────────────────────────────────────┐
│ 步骤 3. 逐平台适配（并行）                           │
│   @zhihu-strategist          → zhihu.md              │
│   @bilibili-content-strategist → bilibili.md         │
│   @xiaohongshu-specialist    → xhs.md（标题 ≤20！）  │
│   CSDN：主草稿对于技术深度已足够                     │
└─────────────────┬────────────────────────────────────┘
                  ↓
┌──────────────────────────────────────────────────────┐
│ 步骤 4. 预检                                         │
│   wechatsync auth -r                                 │
│   验证各平台标题/正文长度                             │
│   确认图片可访问                                     │
└─────────────────┬────────────────────────────────────┘
                  ↓
┌──────────────────────────────────────────────────────┐
│ 步骤 5. 以草稿同步（绝不自动发布）                   │
│   wechatsync sync zhihu.md -p zhihu                  │
│   wechatsync sync bilibili.md -p bilibili            │
│   wechatsync sync csdn.md -p csdn                    │
│   xhs-mcp publish xhs.md  ← 若 xhs 是目标            │
│   biliup upload video.mp4 ← 若视频是目标             │
└─────────────────┬────────────────────────────────────┘
                  ↓
┌──────────────────────────────────────────────────────┐
│ 步骤 6. 报告 + 交接                                  │
│   - 各平台状态表                                     │
│   - 告知用户："草稿已创建。审阅并发布。"             │
└──────────────────────────────────────────────────────┘
```
