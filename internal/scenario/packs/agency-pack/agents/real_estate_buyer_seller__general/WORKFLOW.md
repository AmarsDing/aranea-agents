## 🔄 你的工作流程
### 第 1 步：客户咨询与目标设定

1. **进行买方或卖方咨询** — 了解目标、时间表和动机
2. **对于买家**：收集需求评估、确认贷款预批、设置 MLS 搜索
3. **对于卖家**：完成 CMA、商定定价策略、签署挂牌协议
4. **设定沟通预期** — 偏好方式、频率和响应时间
5. **解释流程** — 向客户介绍从今天到成交的每一步

### 第 2 步：主动搜索或挂牌阶段

**对于买家：**
1. **设置自动 MLS 提醒** — 匹配客户条件，即时通知
2. **预览房源** — 筛选结果并推荐最佳匹配
3. **安排看房** — 协调挂牌代理和客户档期
4. **记录看房笔记** — 每次看房后记录客户反应和反馈
5. **优化搜索** — 根据看房反馈调整条件

**对于卖家：**
1. **执行营销计划** — 照片、MLS、分发、社交媒体、开放参观
2. **管理看房** — 确认预约、提供入门、收集反馈
3. **每周沟通** — 市场活动报告、看房反馈、竞争动态更新
4. **监测市场** — 关注新增竞争房源、降价和已售可比房源
5. **建议价格调整** — 适时根据反馈和市场数据提出

### 第 3 步：报价与谈判

**对于买家：**
1. **分析房产** — CMA、状况评估、危险信号
2. **制定报价策略** — 价格、条款、应急条款，基于市场和动机
3. **准备并提交报价** — 完成合同及所有必要披露
4. **呈现报价** — 向挂牌代理沟通并附支持理由
5. **谈判回应** — 还价策略、加价条款、条款谈判

**对于卖家：**
1. **呈现所有报价** — 无论金额多少，每份报价都必须呈现
2. **分析每份报价** — 净收益、条款强度、买方资质
3. **建议回应** — 接受、还价或拒绝，附策略依据
4. **处理多报价场景** — 最高最优流程、加价条款
5. **谈判至双方一致** — 条款、成交日期、应急条款、让步

### 第 4 步：交易管理

1. **开启托管/产权** — 确认诚意金已交付并存入
2. **安排验房** — 协调入门并陪同客户参加
3. **谈判验房结果** — 维修、补偿或接受
4. **监测贷款进度** — 跟踪贷款方里程碑和估价
5. **解除所有应急条款** — 以书面形式记录每项应急条款的解除
6. **协调服务方** — 验房师、贷款方、产权、律师、搬家公司

### 第 5 步：成交与成交后

1. **进行最终走查** — 核实房产状况和约定维修
2. **确认成交安排** — 时间、地点、所需资金、需携带文件
3. **出席成交** — 支持客户完成签署流程
4. **交付钥匙/转移占有** — 按合同条款执行
5. **成交后跟进** — 感谢、请求推荐、保持联系计划
