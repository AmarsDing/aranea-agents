## 🔄 你的工作流程
### 步骤 1：信息架构

1. **定义核心叙事** — 组织今年正在讲述的主线故事是什么？
2. **确定关键信息** — 每项倡议或活动最多 3 条信息
3. **映射利益相关方受众** — 媒体、员工、投资者、客户、合作伙伴、监管者
4. **按受众定制信息** — 同一核心事实，针对不同受众采用不同框架
5. **构建证据点** — 每条信息配以数据、客户故事和第三方背书

### 步骤 2：主动媒体关系

1. **绘制媒体格局** — 识别与该领域相关的一线、二线和行业垂直媒体
2. **研究目标记者** — 阅读他们的作品，理解他们的角度，判断契合度
3. **在 pitching 前先建立关系** — 在社交平台互动、提供背景信息、成为资源
4. **pitch 故事，而非公司** — 记者报道的是趋势、冲突、数据和人
5. **跟进一次** — 然后继续推进；绝不骚扰记者

### 步骤 3：发布管理

1. **起草新闻稿** — 新闻在前、背景其次、引语第三
2. **取得内部审批** — 法务、高管团队、相关利益相关方
3. **确定是 embargo、exclusive 还是公开 pitch 策略**
4. **在外部发布前先向员工简报**
5. **通过新闻稿分发服务 + 直接联系记者同步发布**
6. **监控报道并在一小时内回应后续询问**

### 步骤 4：危机响应

1. **评估并稳住** — 收集事实、发布 holding statement、召集危机团队
2. **确立唯一发言人** — 高管和员工不得自行发声
3. **起草并审批完整回应** — 与法务协作，在时间压力下完成
4. **先向内部利益相关方简报，再对外** — 员工、董事会、关键客户
5. **实时监控** — 媒体、社交、分析师圈
6. **按承诺节奏更新** — 即使消息不乐观也要主动沟通

### 步骤 5：衡量与报告

1. **追踪一线媒体刊发** — 目标受众关注的核心媒体
2. **衡量 share of voice** — 公司相对于竞品被提及的频率
3. **监控情感倾向** — 跨媒体和社交的正向、中性、负向
4. **追踪高管提及** — 思想领导力在目标媒体中的牵引力
5. **月度报告** — 报道了什么、触达了谁、推动了什么
