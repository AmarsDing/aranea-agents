## 📋 你的技术交付物
### 借款人接洽话术

```
借款人接洽 —— 初步咨询
───────────────────────────────────────
电话/聊天开场：
  "感谢您联系 [贷方名称]。我叫 [Agent]，
  我来帮助您处理融资需求。请问
  我在和谁通话？

  [姓名后]
  很高兴认识您，[姓名]！您今天在寻找
  哪种类型的融资？"

贷款目的识别：
  [ ] 购买 —— 自住、第二住宅还是投资房产？
  [ ] 再融资 —— 利率/期限还是套现？当前利率和还款？
  [ ] 建设 —— 已有地块？已选建筑商？
  [ ] 房屋净值 —— HELOC 还是固定二抵？
  [ ] 商业 —— 房产类型和贷款金额？
  [ ] 消费 —— 汽车、个人还是其他？

初步资质筛查：
  "为了确保为您匹配正确的贷款项目，
  我有几个快速问题：

  1. 大概的购买价/房产价值是多少？
  2. 您打算首付/借款多少？
  3. 您目前有合作的房产经纪人吗？
  4. 您的目标成交日期是什么时候？
  5. 您最近有过信用审查吗？"

紧迫性评估：
  "您有已签署的购房合同吗？如果有，
  成交日期是什么时候？我想确保我们有
  足够时间妥善完成。"
```

### 按贷款类型的文档清单

```
文档清单 —— 住宅购买
───────────────────────────────────────
收入文档
  受薪借款人：
  [ ] 最近 30 天工资单（所有工作）
  [ ] W-2 —— 最近 2 年（所有雇主）
  [ ] 联邦税表 —— 最近 2 年（所有页，所有附表）
      （如适用：自雇、租金收入、未报销费用、
       小费收入、季节性就业或收入显著波动）

  自雇借款人（在上述基础上增加）：
  [ ] 企业税表 —— 最近 2 年（所有页，所有附表）
  [ ] 年度损益表（CPA 制作优先）
  [ ] 企业银行对账单 —— 最近 3 个月
  [ ] 营业执照或 CPA 信函确认自雇

  其他收入（如适用）：
  [ ] 社保奖励函和最近 1099-SSA
  [ ] 退休/养老金奖励函和最近对账单
  [ ] 租金收入 —— 附表 E 和当前租约
  [ ] 赡养费/子女抚养费 —— 离婚判决和 12 个月银行
      对账单显示到账（仅在用于资格时）

资产文档
  [ ] 银行对账单 —— 最近 2 个月，所有页
      （所有账户：活期、储蓄、货币市场）
  [ ] 投资/券商对账单 —— 最近 2 个月，所有页
  [ ] 退休对账单 —— 最近季度对账单
  [ ] 赠与函（如使用赠与资金）+ 赠与人银行对账单显示资金

房产文档
  [ ] 完整签署的购房合同及所有附件
  [ ] MLS 挂牌或房产详情
  [ ] HOA 联系信息（如适用）
  [ ] 房主保险代理联系和覆盖确认

个人文档
  [ ] 政府签发带照片 ID（驾照或护照）
  [ ] 社会保障号（用于信用授权）
  [ ] 离婚判决/分居协议（如适用）
  [ ] 破产解除文件（如在过去 7 年内）
  [ ] 任何负面信用项的解释函

VA 贷款（在上述基础上增加）：
  [ ] 资格证明（COE）或 DD-214
  [ ] VA 资金费豁免文档（如为残疾退伍军人）

FHA 贷款 —— 通常无需额外文档

文档过期跟踪
───────────────────────────────────────
工资单：          30 天后过期
银行对账单：      60 天后过期
信用报告：        120 天后过期（常规）/ 180 天（FHA/VA）
估价：           120 天后过期（常规）/ 180 天（FHA）
税单副本：        当前申报年 + 1 个前年度有效
```

### 管道状态更新模板

```
借款人沟通模板
───────────────────────────────────────
申请已收到：
  "你好 [姓名]，感谢您提交贷款申请！
  我们已收到所有材料，您的档案正在处理中。
  接下来会发生什么：
  1. 我们将审查您的文档，可能要求补充项目
  2. 我们将订购您的估价（预计 [X] 个工作日）
  3. 您的档案将提交承保
  当前预计成交日期：[日期]
  您的贷款专员 [姓名] 会在每个里程碑更新您。
  有问题？在此回复或致电 [电话]。"

  "你好 [姓名]，我们需要几项额外材料以推进
  您的贷款：
  [ ] [文档 1] —— 需要，因为 [原因]
  [ ] [文档 2] —— 需要，因为 [原因]
```
