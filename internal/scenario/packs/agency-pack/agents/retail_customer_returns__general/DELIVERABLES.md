### 退货处理工作流

```
退货处理清单
───────────────────────────────────────
第 1 步：问候与验证
  [ ] 热情问候客户
  [ ] 索取收据、订单确认或订单查询
  [ ] 在系统中验证购买——确认商品、价格和日期
  [ ] 如政策要求验证客户身份

第 2 步：检验商品
  [ ] 检查商品成色——全新、几乎全新、已使用、损坏
  [ ] 检查所有原装组件——配件、说明书、包装
  [ ] 检查使用、磨损或损坏痕迹
  [ ] 检查序列号匹配（电子产品）
  [ ] 检查价签/标签篡改
  [ ] 检查欺诈迹象——收据涂改、价格切换

第 3 步：判定资格
  [ ] 确认在退货窗口内
  [ ] 确认商品符合成色要求
  [ ] 确认无类目限制适用
  [ ] 检查客户退货历史（如系统可用）
  [ ] 确定退款金额——全额、部分或商店信用

第 4 步：处理退货
  [ ] 在 POS/系统中选择退货原因代码
  [ ] 向原支付方式处理退款
  [ ] 如适用发放商店信用
  [ ] 如请求则处理换货
  [ ] 向客户打印/邮件退货确认

第 5 步：处置商品
  [ ] 重新入库（全新/未开封，无瑕疵）
  [ ] 开箱/翻新区（已开封，良好状态）
  [ ] 供应商退货/RMA（瑕疵，供应商责任）
  [ ] 残值/清仓（损坏，不可售）
  [ ] 销毁（健康/安全，不可转售）
  [ ] 保留供 LP 审查（疑似欺诈）

第 6 步：结束互动
  [ ] 真诚感谢客户
  [ ] 如换货则协助寻找替代品
  [ ] 记录关于商品或购买体验的反馈
  [ ] 邀请客户再次光临
```

### 退货原因代码指南

```
退货原因代码
───────────────────────────────────────
使用准确的原因代码——退货数据驱动采购决策、
商品质量反馈和供应商索赔。

商品问题
  P01——瑕疵/不工作
  P02——损坏——到货即损（电商）
  P03——缺少配件或附件
  P04——与描述/图片不符
  P05——发错货（电商履约错误）
  P06——尺码/合身问题（服装、鞋类）
  P07——颜色/款式与预期不同
  P08——质量低于预期

客户偏好
  C01——改变主意/不再需要
  C02——在其他地方找到更低价格
  C03——重复购买/作为礼物收到
  C04——订购错误商品/尺码
  C05——礼物——收礼人不需要/不想要

运营
  O01——收银员错误——扫错商品
  O02——价格差异
  O03——促销商品——未满足促销条款

欺诈标记（内部使用——不告知客户）
  F01——疑似退货被盗商品
  F02——疑似 wardrobing（穿后退货）
  F03——疑似收据欺诈
  F04——疑似价格切换
  F05——过度退货——政策滥用
  F06——连环退货者——升级至管理层
```

### 欺诈防范指南

```
退货欺诈红旗
───────────────────────────────────────
⚠️ 这些是内部标记——绝不直接指控客户。
   对所有疑似欺诈案例遵循升级协议。

收据/交易欺诈
  🚩 收据疑似涂改——不同墨水、模糊、错位
  🚩 高价值商品的收据来自不同门店
  🚩 收据日期明显早于商品表观新旧
  🚩 客户持同一商品的多张收据
  🚩 收据条形码与商品不匹配

商品欺诈
  🚩 价签疑似被切换——此商品标签错误
  🚩 商品序列号与收据或包装不匹配
  🚩 商品明显已使用但客户声称全新/瑕疵
  🚩 包装疑似重新封口或被篡改
  🚩 高价值商品退货无原包装
  🚩 退回空箱或装有其他物品的箱子

行为标记
  🚩 客户极其紧张或具有攻击性
  🚩 客户今日多次到店
  🚩 客户拒绝商品检验
  🚩 客户无法描述商品如何使用/出了什么问题
  🚩 被询问时客户说法改变
  🚩 客户坚持刷卡消费要现金退款

模式标记（基于系统）
  🚩 客户在 [Y] 天内退货超过 [X] 件
  🚩 客户在 [Y] 天内退货总额超过 $[X]
  🚩 同一客户多次退回同一商品
  🚩 客户账户被防损标记

升级协议
───────────────────────────────────────
如疑似欺诈：
  1. 不要指控客户
  2. 不要处理退货
  3. 说："我需要请经理来协助处理这次退货。"
  4. 立即联系经理/防损
  5. 记录互动及升级原因
  6. 从此点起由经理处理
  7. 如客户变得敌对——优先安全，让其离开
```

### 退款方式指南

```
退款方式政策
───────────────────────────────────────
原支付方式（默认）
  信用卡/借记卡：
  - 退款至原卡——3-5 个工作日到账
  - 需刷卡验证（核对后 4 位）
  - 如卡已注销/过期——发放商店信用或支票
    （需经理批准）
  - 未经批准绝不可以现金代替刷卡退款

  现金购买：
  - 现金退款 $[X] 以内——店员可处理
  - 现金退款超过 $[X]——需经理批准
  - 所有现金退款需记录客户 ID

  PayPal/数字钱包：
  - 退款至原数字支付方式
  - 处理时间：3-5 个工作日
  - 如账户已关闭——发放商店信用

  礼品卡：
  - 退款至新礼品卡
  - 绝不为礼品卡购买发放现金

商店信用
  发放时机：
  - 无收据退货（标准）
  - 超出退货窗口（例外）
  - 客户偏好
  - 无礼品收据的礼物退货

  商店信用条款：
  - 无过期（或按政策 [X] 年过期）
  - 可在门店和线上使用
  - 不可兑换现金
  - 按政策可/不可转让

换货
  同款商品——不同尺码/颜色：
  - 按退货 + 以同价重新购买处理
  - 同价则无额外收费
  - 价格不同则客户补/退差额

  不同商品：
  - 按退货 + 新购买处理
  - 将退款应用于新购买
  - 收取或退还差额

部分退款
  适用情形：
  - 缺少配件或组件
  - 开箱/重新入库费适用
  - 商品以低于阈值的已使用状态退回
  - 价格匹配商品的价格调整

  计算：
  原价：$___________
  扣除：$___________  原因：_______________
  部分退款：$___________
  经理批准：[ ] 需要  [ ] 不需要
```

### 客户留存话术

```
退货中的客户留存
───────────────────────────────────────
开场——共情优先：
  "很遗憾 [商品] 不适合您。
  让我们马上为您处理。"

  绝不说："它有什么问题？"（指责性）
  绝不说："您有收据吗？"（在问候之前）
  始终：在提问前先确认不便

提议换货时：
  "在我为您处理的同时，需要我帮您找找
  可能更合适的吗？我们刚到货的 [类似商品]
  很多客户都很喜欢。"

发放商店信用时：
  "今天我将以商店信用形式发放——这意味着
  您将有 $[金额] 可用于门店或线上的任何商品，
  无过期。您今天有什么想找的，我可以帮您吗？"

拒绝退货时（超出政策）：
  "我完全理解您的沮丧，我也希望能做得更多。
  我们的退货窗口是 [X] 天，而您的购买是
  [X] 天前。我无法处理全额退货，但我能做的
  是 [提供部分信用/为您联系制造商保修/升级至经理]。
  这两者哪个对您有帮助？"

  绝不说："抱歉，我无能为力。"（未提供替代方案）
  始终：至少提供一条前进的替代路径

客户不满时：
  "我听到了，很抱歉给您带来困扰。
  您本不该应对这些。让我看看能做些什么
  来妥善解决。"

  如需升级：
  "我想确保您得到最好的解决方案。
  让我请我的经理来——他有更多选项，
  马上就到。"

退货后收尾：
  "今天还有什么我可以帮您的吗？
  期待很快再次见到您。"
```
