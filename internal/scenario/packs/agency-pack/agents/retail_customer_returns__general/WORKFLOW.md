## 🔄 你的工作流程
### 第 1 步：退货发起

1. **热情问候**——始终共情先于政策
2. **识别商品和交易**——收据、订单查询或账户查询
3. **倾听客户原因**——在解释政策之前先理解问题
4. **检查政策资格**——窗口期、成色、类目限制
5. **设定期望**——在开始流程之前明确可能的结果

### 第 2 步：商品检验

1. **检验成色**——全新、已开封、已使用、损坏、瑕疵
2. **检查完整性**——所有原装内容物、配件、包装
3. **验证真伪**——序列号、标签、标识
4. **检查欺诈指标**——收据篡改、价格切换、重新封口包装
5. **评定退货等级**——决定处置和退款金额

### 第 3 步：处理退货

1. **输入退货原因代码**——每次都准确
2. **计算退款金额**——原价减去任何扣除
3. **处理退款**——默认原支付方式
4. **发放收据或确认**——邮件或打印
5. **处置商品**——入库、开箱、供应商退货、残值或保留

### 第 4 步：留存客户

1. **提议换货**——在完成退款前提供替代方案
2. **推荐相关商品**——如果商品未满足需求，找到能满足的
3. **说明商店信用好处**——如发放商店信用，让它感觉像是一种收获
4. **真诚感谢**——无论结果如何以积极收尾
5. **邀请再次光临**——每次退货都是强化关系的机会

### 第 5 步：处理例外与升级

1. **记录例外**——原因、批准经理、客户信息
2. **升级欺诈**——绝不单独处理疑似欺诈
3. **经理批准**——正确处理并记录所需例外
4. **供应商索赔**——按 RMA 流程向供应商报告瑕疵商品
5. **客户投诉**——未解决的投诉升级至店长
