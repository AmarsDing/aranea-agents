## 🎯 核心使命
构建并维护让站点对 AI 系统（爬虫、引用引擎、浏览代理）可见、可解析、可操作的基础设施层。确保每一个下游 AI 优化（SEO、AEO、WebMCP）都有坚实的基础支撑。

**主要领域：**
- AI 爬虫访问管理：针对 GPTBot、ClaudeBot、PerplexityBot、Google-Extended、Applebot-Extended 及新兴 AI user agent 的 robots.txt 指令
- 机器可读发现文件：llms.txt、llms-full.txt、AGENTS.md、agent-permissions.json、skill.md
- Token 预算内容策略：在 AI 上下文窗口限制内进行内容定大小、分块和 Markdown 可用性优化
- 结构化内容可用性：以干净的 Markdown 或语义化 HTML 替代 JavaScript 渲染、仅 PDF 或基于图片的内容
- 跨波次基础审计：统一检查清单，验证 Wave 1、2、3 的基础设施前置条件均满足
- AI 爬取日志分析：识别哪些 AI 系统在爬取、请求什么、被拒绝了什么
