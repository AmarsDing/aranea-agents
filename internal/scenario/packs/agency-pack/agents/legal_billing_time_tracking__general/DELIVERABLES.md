## 📋 你的技术交付物
### 时间条目标准

```
时间条目标准指南
───────────────────────────────────────
最小时间增量：0.1 小时（6 分钟）
标准舍入：向上舍入到最近的 0.1 小时
时间条目截止：工作当日录入（首选）
                     工作后不超过 48 小时

好的时间条目示例
───────────────────────────────────────
✅ "审阅和分析原告的即决判决动议；
    识别关键论点和证据缺口；开始概述
    回应策略。"——2.4 小时

✅ "与客户电话会议，讨论对方律师发来的
    和解要约；讨论接受的利弊；
    建议客户如案件进入审判的诉讼风险；
    客户指示拒绝要约并继续谈判。"
    ——0.8 小时

✅ "草拟致 ABC 公司的违约索赔要求函；
    研究适用的诉讼时效；计算损害赔偿。"
    ——1.6 小时

✅ "审阅 123 Main Street 物业的产权承诺书；
    识别附表 B 例外项；准备产权
    问题摘要供客户审阅。"——0.9 小时

差的时间条目示例
───────────────────────────────────────
❌ "法律服务。"——太模糊，什么都没描述
❌ "审阅文件。"——什么文件？审阅了什么？为什么？
❌ "电话。"——和谁？关于什么？达成了什么？
❌ "研究。"——什么问题？发现了什么？
❌ "处理案件。"——这永远不可接受
❌ "杂项。"——作为计费条目永远不合适

批量计费警告
───────────────────────────────────────
批量计费（将多个任务合并到一个条目中）在
客户指南禁止时应避免。当允许批量计费时，
条目中的每个任务仍应被描述：

✅ 允许的批量计费：
"审阅客户文件（0.5）；研究惩罚性赔偿标准（1.2）；
草拟关于损害赔偿风险的备忘录（0.8）。"——2.5 小时

❌ 不当的批量计费：
"文件上的各种任务。"——2.5 小时
```

### 按业务领域划分的计费叙述模板

```
计费叙述模板
───────────────────────────────────────
诉讼
  研究：
    "就 [法律问题] 进行研究，与 [案件描述] 相关；
    审阅 [案例/法规/规章] 并分析对客户事实的
    适用性；准备研究摘要。"

  起草：
    "草拟 [文件类型]，与 [案件] 相关；纳入
    [特定要素]；根据 [律师/客户] 意见修改。"

  出庭：
    "出席 [听证会类型]，在 [法院/法官] 面前，关于 [案件]；
    [结果/后续步骤]。"

  证言：
    "准备并参加 [证人姓名] 的证言采集，关于 [主题]；
    [时长] 小时证词；识别关键承认。"

交易/公司
  合同审阅：
    "审阅和分析 [合同类型]，由 [当事方] 提交；
    识别非标准条款和潜在风险；
    准备带批注的红线版供客户审阅。"

  尽职调查：
    "审阅 [文件类型]，与 [交易] 相关；
    识别重大问题；更新尽职调查跟踪表。"

  起草：
    "为 [交易/案件] 草拟 [文件类型]；
    纳入 [特定交易条款]；分发审阅。"

房地产
  产权审阅：
    "审阅 [物业地址] 的产权承诺书；分析
    附表 B 例外项；识别产权缺陷和
    所需的修复措施。"

  结案：
    "准备并参加 [交易类型] 的结案，
    物业为 [物业]；审阅和签署结案文件；
    与 [贷款方/产权公司] 协调。"

遗产规划
  文件起草：
    "为客户草拟 [遗嘱/信托/授权书/医疗指示]；
    纳入客户关于 [特定条款] 的意愿；
    准备供客户审阅和签署。"

  客户会议：
    "与客户会面审阅和签署遗产规划文件；
    解释条款并回答客户问题；见证
    [文件] 的签署。"

劳动法
  调查：
    "审阅 [文件/通信]，与
    就业歧视/骚扰调查相关；
    准备事件时间线；识别关键证人。"

  EEOC/机构回应：
    "准备对 [投诉人] 提交的 EEOC 指控的回应；
    草拟立场声明；汇总支持文件。"
```

  [ ] 所有减记经负责律师批准

  [ ] 信托余额已更新以反映任何支付
  [ ] 如信托低于阈值则包含补充请求
  [ ] 信托账户活动与案件分类账一致

### 收款沟通模板

```
收款沟通序列
───────────────────────────────────────
第 1 次——发票交付（第 0 天）
  主题："来自 [律所名称] 的发票 [#]——[案件名称]"
  "附件为截至 [日期] 提供法律服务的
  发票 [#]。付款期限为 [30] 天。如有任何
  问题，请随时联系。"

第 2 次——友好提醒（第 35 天）
  主题："友好提醒——来自 [律所名称] 的发票 [#]"
  "我想跟进日期为 [日期]、金额为 [金额]
  的发票 [#]，该发票似乎未付。如已付款，
  请忽略此消息。如对发票有任何疑问，
  我很乐意协助。否则，请在方便时
  尽快汇款。"

第 3 次——逾期通知（第 60 天）
  主题："逾期——发票 [#]——[律所名称]"
  "我们的记录显示截至 [日期]，金额为
  [金额] 的发票 [#] 仍未支付。此发票
  现已逾期 [X] 天。请立即汇款或联系我们
  讨论您的账户。我们珍视您与本所的
  关系，希望能及时解决此事。"

第 4 次——最终通知（第 90 天）
  主题："最终通知——发票 [#]——[律所名称]"
  "尽管此前已发出通知，金额为 [金额]
  的发票 [#] 仍未支付。这是我们
  [暂停服务/转介收款/按适用规则退出
  代理] 前的最终通知。请立即联系
  [计费联系人]（电话/邮箱）解决此事。"

第 5 次——律师升级（第 90 天以上）
  升级给负责律师进行：
  - 对客户关系联系人进行个人联系
  - 决定付款计划、核销或收款转介
  - 根据适用道德规则审查退出义务

付款计划模板
───────────────────────────────────────

我们理解意外支出可能造成财务困难。
我们愿意安排如下付款计划：

首付款：        [金额] 于 [日期] 前支付

请于 [日期] 前确认您同意这些条款。根据
我们与 [律师姓名] 的讨论，后续法律服务

```

### 信托账户管理

```
信托账户合规框架
───────────────────────────────────────
IOLTA 要求（因州而异——始终核实当前规则）

信托存款：
  [ ] 客户预付费用（未赚取）
  [ ] 客户成本预付
  [ ] 待分配的和解收益
  [ ] 托管资金

  每笔存款所需文档：
  - 客户名称和案件编号
  - 资金来源
  - 存款日期
  - 金额
  - 用途

信托支付：
  允许的支付：
  [ ] 赚取费用后转入运营账户
  [ ] 代客户支付客户成本
  [ ] 向客户分配和解收益
  [ ] 代客户向第三方付款

  每笔支付所需文档：
  - 客户授权（首选书面）
  - 收款人和用途
  - 金额
  - 日期
  - 支付后剩余余额

三方对账（每月）
───────────────────────────────────────
第 1 步：银行对账单余额
  银行对账单期末余额：$___________

第 2 步：客户分类账余额
  所有个人客户分类账余额之和：$___________

第 3 步：信托日记账余额
  信托日记账/会计系统余额：$___________

三者必须一致。任何差异需立即调查。

信托账户红旗
───────────────────────────────────────
❌ 任何个人客户分类账出现负余额
❌ 银行余额小于客户分类账余额之和
❌ 资金清算前支付
❌ 费用赚取前转入运营账户
❌ 使用一个客户的资金支付另一客户的成本
❌ 未能每月对账
❌ 任何交易缺少文档

任何红旗必须立即报告给主管律师。
```
