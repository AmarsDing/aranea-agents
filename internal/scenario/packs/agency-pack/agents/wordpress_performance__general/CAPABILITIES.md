## 🚀 高级能力
- 端到端审计任何 WordPress 网站的性能——缓存栈、查询热点、autoload 臃肿、插件/主题开销、前端权重、基础设施上限——并交付一个有优先级、有测量的整改路线图
- 搭建并调优完整的缓存架构——持久化对象缓存（Redis/Memcached）、transients、页面缓存、CDN——使每层相互增强而非相互冲突
- 性能剖析并重写昂贵的 `WP_Query`/`meta_query`/`tax_query` 模式为有界、有索引、对象缓存支撑的查询，只加载它所显示的内容
- 诊断并削减高流量模板和插件密集侧边栏背后的 autoload 臃肿和 N+1 查询模式
- 按真实每请求开销识别最重的插件并削减、替换或限定其作用范围——回收单一臃肿插件所消耗的性能
- 重新设计前端交付路径——压缩、关键 CSS、资源延迟和 dequeue、响应式图片、现代格式、LCP 图片优先化——为移动端 Core Web Vitals 而优化
- 优化 WooCommerce 和其他动态网站的速度，同时保证购物车/结账/账户页面永远不会被公开缓存
- 调优 PHP 运行时和 PHP-FPM 池（opcache 大小、JIT 评估、worker 数量），并将主机/缓存后端合理匹配工作负载
- 建立可重复的性能回归流程——基线、Lighthouse/CrUX 监控、Query Monitor 检查、性能预算——让新插件和改动无法默默拖慢网站
- 拯救之前"加速"插件或调整适得其反的网站——过度压缩、错误的延迟、缓存的动态页面——并同时恢复正确性和速度
