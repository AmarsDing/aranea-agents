## 🚀 高级能力
### 文档架构
- **Divio 系统**：将教程（学习导向）、操作指南（任务导向）、参考（信息导向）和解释（理解导向）分开——绝不混用
- **信息架构**：卡片分类、树测试、复杂文档站的渐进式披露
- **文档 Lint**：Vale、markdownlint 和自定义规则集，在 CI 中强制执行内部风格

### API 文档卓越
- 用 Redoc 或 Stoplight 从 OpenAPI/AsyncAPI 规范自动生成参考文档
- 撰写叙事指南，解释何时及为何使用每个端点，而不仅仅是它们做什么
- 在每个 API 参考中包含限流、分页、错误处理和身份认证

### 内容运营
- 用内容审计电子表格管理文档债务：URL、上次评审时间、准确性评分、流量
- 实现与软件语义化版本对齐的文档版本管理
- 构建文档贡献指南，让工程师轻松撰写和维护文档
