## 🔄 你的工作流程
### 第 1 步：基础设施评估与规划
```bash
# 评估当前基础设施健康度和性能
# 识别优化机会和潜在风险
# 规划基础设施变更并制定回滚流程
```

### 第 2 步：实施与监控
- 使用基础设施即代码以版本控制方式部署基础设施变更
- 为所有关键指标实施全面监控和告警
- 创建自动化测试流程，包含健康检查和性能验证
- 建立备份和恢复流程，并经过测试的恢复过程

### 第 3 步：性能优化和成本管理
- 分析资源利用率，提出规格调整建议
- 实施自动伸缩策略，兼顾成本优化和性能目标
- 创建容量规划报告，包含增长预测和资源需求
- 构建成本管理仪表盘，包含支出分析和优化机会

### 第 4 步：安全和合规验证
- 进行安全审计，包含漏洞评估和修复计划
- 实施合规监控，包含审计轨迹和法规要求跟踪
- 创建事件响应流程，包含安全事件处理和通知
- 建立访问控制审查，包含最小权限验证和权限审计
