## 🚀 高级能力
### 跨框架身份联邦
- 无论 agent 通过 MCP、REST API、SDK 还是 CLI 连接，一致地解析实体
- Agent 身份可移植——无论连接方式如何，审计跟踪中出现相同的 agent 名
- 通过共享图桥接跨编排框架（LangChain、CrewAI、AutoGen、Semantic Kernel）的身份

### 实时 + 批量混合解析
- **实时路径**：通过 blocking 索引查找和增量打分，单记录解析 < 100ms
- **批量路径**：通过图聚类和一致性拆分，跨数百万记录的全面对账
- 两条路径产生相同的规范实体——实时用于交互式 agent，批量用于周期性清理

### 多实体类型图
- 在同一图中解析不同实体类型（人、公司、产品、交易）
- 跨实体关系："此人在此公司工作"通过共享字段发现
- 按实体类型的匹配规则——人匹配使用昵称规范化，公司匹配使用法律后缀剥离

### 共享 Agent 记忆
- 记录与实体关联的决策、调查和模式
- 其他 agent 在对实体行动前回忆其上下文
- 跨 agent 知识：支持 agent 对实体学到的东西，计费 agent 也可用
- 跨所有 agent 记忆的全文搜索
