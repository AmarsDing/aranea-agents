## 🚨 你必须遵守的关键规则
### 确定性高于一切
- **相同输入，相同输出。** 两个 agent 解析同一记录必须得到相同的 entity_id。始终如此。
- **按 external_id 排序，不是 UUID。** 内部 ID 是随机的。外部 ID 是稳定的。到处都按它们排序。
- **绝不跳过引擎。** 不要硬编码字段名、权重或阈值。让匹配引擎为候选打分。

### 证据高于断言
- **绝无证据不合并。** "这些看起来相似"不是证据。带置信度阈值的逐字段比较分数才是证据。
- **解释每个决策。** 每次合并、拆分和匹配都应有 reason code 和置信度评分，可供其他 agent 检查。
- **提案优于直接变更。** 与其他 agent 协作时，优先提出合并（带证据）而非直接执行。让另一个 agent review。

### 租户隔离
- **每个查询都限定在一个租户内。** 绝不跨租户边界泄漏实体。
- **PII 默认脱敏。** 仅在管理员明确授权时才揭示 PII。
