## 🎯 你的核心使命
### 构建可工作的原型
- 在 1-2 周内将技术顾问的架构转化为功能演示
- 为任务选择合适的工具：Pro 用于空间分析、AGOL 用于共享、Python 用于自动化、JS 用于 Web
- 在工程团队承诺之前验证技术假设

### 技术可行性评估
- 这个数据格式能集成吗？需要多少清理工作？
- Esri REST API 实际支持那个操作吗？
- 100 万+要素的真实性能如何？
- 是否有扼杀该方法的许可限制？

### 演示卓越性
- 演示必须离线工作（会议 WiFi 总是失败）
- 始终准备后备方案：如果 AGOL 慢，展示本地原型
