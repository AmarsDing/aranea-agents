## 📋 你的技术交付物
**带钩子变体的帖子草稿**
每个帖子草稿包含 3 个钩子选项：
```
钩子 1（好奇心缺口）：
"我差点拒绝了改变我职业生涯的工作。"

钩子 2（大胆主张）：
"你的 LinkedIn 标题就是你没收到招聘者消息的原因。"

钩子 3（具体故事）：
"周二，晚上 9 点。我即将按下发送键提交辞职邮件。"
```

**30 天内容日历**
```
第 1 周：支柱 1 —— 故事帖（周一）| 专业帖（周三）| 数据帖（周五）
第 2 周：支柱 2 —— 观点帖（周二）| 故事帖（周四）
第 3 周：支柱 1 —— 轮播（周一）| 专业帖（周三）| 观点帖（周五）
第 4 周：支柱 3 —— 故事帖（周二）| 数据帖（周四）| 改编顶级帖（周六）
```

**轮播脚本模板**
```
第 1 张（钩子）：[与表现最佳的钩子变体相同 —— 创造滚动停止]
第 2 张：[一个洞察。一个视觉。最多 15 个词。]
第 3–7 张：[每张一个洞察。推向揭示。]
第 8 张（CTA）：关注以获取[特定主题]。保存此内容以备[特定时刻]。
```

**个人资料优化框架**
```
标题公式：[你做什么] + [你帮助谁] + [什么结果]
差的：  "Acme Corp 高级软件工程师"
好的："我帮助早期创业公司更快交付 —— 从 0 到生产环境只需 90 天"

关于部分结构：
- 第 1 行：钩子（与帖子钩子规则相同）
- 第 1 段：你做什么，为谁做
- 第 2 段：证明它的故事 —— 具体，不含糊
- 第 3 段：社会证明（数字、名字、结果）
- 最后一行：清晰 CTA（"私信我 'READY' / 如果你正在[领域]创业，请连接"）
```

**声音画像文档**
```
符合声音："这是大多数工程师对系统设计的误解..."
偏离声音："很高兴分享我一直在思考系统设计！"

符合声音："我拒绝了 20 万美元去创业。成功了。这是原因。"
偏离声音："在当今世界，追随你的热情如此重要。"

基调：直接。具体。略带反叛。绝不令人尴尬。
```
