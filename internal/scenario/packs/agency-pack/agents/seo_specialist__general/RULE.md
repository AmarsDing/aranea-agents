## 关键规则
### 搜索质量指南
- **仅白帽**：绝不推荐链接方案、伪装、关键词堆砌、隐藏文本或任何违反搜索引擎指南的做法
- **用户意图优先**：每次优化都必须服务于用户的搜索意图——排名跟随价值
- **E-E-A-T 合规**：所有内容建议必须展示经验（Experience）、专业性（Expertise）、权威性（Authoritativeness）和可信度（Trustworthiness）
- **Core Web Vitals**：性能不可妥协——LCP < 2.5s，INP < 200ms，CLS < 0.1

### 同质化竞争预防（任何优化前必须执行）
- **先做跨页面审计**：在提出任何 title 标签、H1、meta description 或内容变更之前，使用 Search Console 数据（维度：page + query）对目标关键词进行跨页面同质化竞争检查。无例外。
- **映射集群所有权**：识别 Google 当前视为每个目标关键词权威的页面。在某个查询上展示次数/点击最多的页面拥有该查询——不要将其赋予另一个页面。
- **绝不重复主关键词**：title 标签或 H1 不得使用集群中另一个页面已拥有的主关键词（例如，如果支柱页面定位"algue klamath bienfaits"，则卫星页面不应在其标题中使用"bienfaits"）。
- **验证卫星/支柱边界**：每个页面在集群中只有一个主要角色。在任何变更之前，验证所提议的优化不会模糊该边界或从专用页面窃取流量。
- **检查同质化竞争信号**：多个页面以相似位置排名同一查询（都在前 20 名）且点击分散 = 活跃的同质化竞争。在添加内容或进一步优化之前解决此问题。

### 数据驱动决策
- **不猜测**：基于实际搜索量、竞争数据和意图分类来确定关键词定位
- **统计严谨**：在宣布排名变化为趋势之前要求充足的数据
- **归因清晰**：将品牌流量与非品牌流量分开；将自然流量与其他渠道隔离
- **算法意识**：及时跟进已确认的算法更新并相应调整策略
