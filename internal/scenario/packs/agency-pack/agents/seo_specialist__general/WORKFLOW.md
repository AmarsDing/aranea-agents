## 工作流程
### 阶段 1：发现与技术基础
1. **技术审计**：抓取网站（Screaming Frog / Sitebulb 等效分析），识别可抓取性、索引和性能问题
2. **Search Console 分析**：审查索引覆盖、手动操作、Core Web Vitals 和搜索性能数据
3. **竞争格局**：识别前 5 名自然竞争对手、其内容策略和链接配置
4. **基线指标**：记录当前自然流量、关键词排名、域名权威和转化率

### 阶段 2：关键词策略与内容规划
1. **关键词研究**：构建按主题集群和搜索意图分组的综合关键词库
2. **内容审计**：将现有内容映射到目标关键词，识别缺口和同质化竞争
3. **主题集群架构**：设计支柱页面和支持内容，配以内部链接策略
4. **内容日历**：按影响潜力（搜索量 × 可实现性）优先排序内容创建/优化

### 阶段 2.5：同质化竞争审计（阻塞项——必须在阶段 3 之前完成）
1. **跨页面查询映射**：对阶段 2 中定位的每个关键词，查询 GSC（维度：page+query）以识别当前为其排名的所有页面
2. **冲突解决**：对于 2 个以上页面排名同一查询的每种情况，分配单一所有者并规划竞争页面的去优化
3. **Title/H1 去冲突**：验证集群中没有两个页面在其 title 标签或 H1 中共享相同的主关键词
4. **签核**：在继续内容变更之前，获得同质化竞争映射清晰的明确确认

### 阶段 3：页面与技术执行
1. **技术修复**：解决关键抓取问题，实施结构化数据，优化 Core Web Vitals
2. **内容优化**：更新现有页面，改进定位、结构和深度
3. **新内容创建**：针对已识别的缺口和机会制作高质量内容
4. **内部链接**：构建上下文内部链接架构，将集群连接到支柱

### 阶段 4：权威建设与页外
1. **链接配置分析**：评估当前反向链接健康状况并识别增长机会
2. **数字公关活动**：创建可链接资产并执行记者/博主外联
3. **品牌提及监控**：转化未链接的提及并管理在线声誉
4. **竞争对手链接差距**：识别并追求竞争对手有而我们没有的链接来源

### 阶段 5：度量与迭代
1. **排名跟踪**：每周监控关键词排名，分析移动模式
2. **流量分析**：按落地页、意图类型和转化路径细分自然流量
3. **ROI 报告**：计算自然搜索收入归因和每次获客成本
4. **策略优化**：根据算法更新、性能数据和竞争变化调整优先级
