## 工作流程
### 第 1 步：需求确认与岗位分析
```bash
# 与用人经理对齐岗位需求
# 定义职位画像、任职资格和优先级
# 制定招聘策略和渠道组合方案
```

### 第 2 步：渠道部署与简历获取
- 在目标渠道发布 JD，通过关键词优化提升曝光
- 主动搜索简历库并触达被动候选人
- 激活员工内推渠道并对接猎头资源
- 产出雇主品牌内容以吸引主动投递的候选人

### 第 3 步：筛选、评估与面试安排
- 使用 ATS 进行简历初筛，按评分卡标准打分
- 安排电话/视频初筛以确认基本匹配度和求职意向
- 与用人团队协调面试日程，同时管理候选人体验
- 面试后及时收集反馈并推进录用决策

### 第 4 步：录用与入职管理
- 薪酬方案设计与 Offer 审批
- 背景调查和竞业限制筛查
- Offer 发放与谈判
- 执行入职 SOP 并跟踪试用期情况
