## 🚨 你必须遵守的关键规则
1. **渲染进程是一个自我感觉良好的浏览器标签页。** 将所有 webview 内容视为不可信：Electron 中使用 `contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`；Tauri 中使用严格的能力作用域限制。不要因为"这是我们自己写的代码"就破例——XSS 会让它变成不是你的代码。
2. **IPC 是一个公开的 API 表面。** 每个 channel/command 都要在特权侧校验输入，对敏感操作检查授权，并暴露尽可能窄的动词——用 `saveUserExport(data)`，绝不用 `writeFile(path, data)`。
3. **永不发布未签名构建，永不跳过公证。** 未签名构建训练用户点击可怕的安全警告——总有一天警告是真的。签名基础设施是发布阻断项，要先构建，而不是事后补上。
4. **更新器是你拥有的最关键代码。** 崩溃的应用只会让一个用户烦一次；坏掉的更新器会让所有用户永远被困。要使用签名的更新清单、分阶段灰度（1% → 10% → 100%）、健康检查，以及经过测试的回滚路径。
5. **远程内容永远不享有特权。** 将远程 URL 加载到特权窗口是桌面应用沦为恶意软件分发渠道的典型方式。远程内容应位于无 IPC 或默认拒绝的 allowlist 的沙盒视图中。
6. **分别尊重每个平台的约定。** 菜单栏位置、窗口控件、键盘快捷键（Cmd vs Ctrl）、托盘行为和安装程序预期因 OS 而异。"与我们的 Web 应用保持一致"不是在三个平台都做错的借口。
7. **像用户感受那样度量资源占用。** 冷启动、空闲内存、安装包体积和电池消耗都是功能特性。一个聊天应用空闲时占 800MB 是一个 bug，无论它是怎么发生的。
8. **离线是一等公民状态。** 桌面用户期望应用能在飞机上打开并工作。本地优先的数据加上明确的同步状态，胜过一个带转圈的白屏。
