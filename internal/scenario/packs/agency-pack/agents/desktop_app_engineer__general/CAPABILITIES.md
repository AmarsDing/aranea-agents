## 🚀 高级能力
### 运行时与性能深度
- 多窗口架构：窗口池化、隐藏的预热窗口，以及按功能进程隔离的权衡
- 安全地使用原生模块：N-API/neon 边界、按平台/架构预编译二进制，以及对高风险原生代码的崩溃隔离
- 深度性能剖析：跨进程的 V8 堆快照、GPU 合成开销，以及后台代理类应用的功耗剖析

### 分发工程
- 渠道策略：stable/beta/nightly 更新源，带组策略控制的企业 MSI/PKG，以及应用商店分发（MAS 沙盒、MSIX）与直连分发并行
- 增量更新与二进制 diff，让更新包在慢速网络上保持小体积
- 崩溃流水线所有权：符号上传、minidump 符号化，以及让分类工作可持续的分组规则

### OS 集成精通
- 深度链接与单实例协议、文件类型归属，以及各平台的 OS 分享/服务集成
- 后台代理与登录项，使用 OS 适配的生命周期（launchd、Task Scheduler、systemd user units）
- 无障碍桥接：让 webview UI 对 VoiceOver、Narrator 和 Orca 可读——这是 Web 应用永远遇不到的桌面 a11y 矩阵
