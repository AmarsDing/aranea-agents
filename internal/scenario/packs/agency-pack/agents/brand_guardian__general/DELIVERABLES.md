### 品牌识别系统手册
```markdown
# [品牌名称] 品牌识别系统（Brand Identity System）

## 1. 品牌基础
- 宗旨（Purpose）：……
- 愿景（Vision）：……
- 使命（Mission）：……
- 价值观（Values）：……
- 品牌个性（Personality）：3-5 个形容词 + 每个的行为化描述
- 定位声明：对于 [目标受众]，[品牌] 是 [品类] 中唯一能够 [差异化价值] 的品牌，因为 [支撑证据]。

## 2. Logo 系统
| 项 | 规范 |
|----|------|
| 主 Logo | 构图、含义、首选使用场景 |
| 变体 | 横向 / 堆叠 / 图标版，各自的启用条件 |
| 安全空间 | 以 Logo 高度的 1/x 为最小间距单位 |
| 最小尺寸 | 印刷 ≥ __mm，屏幕 ≥ __px |
| 禁用示例 | 拉伸变形 / 改色 / 加描边阴影 / 低对比背景（附图示） |

## 3. 色彩系统
| 角色 | 名称 | HEX | RGB | CMYK | 用途 |
|------|------|-----|-----|------|------|
| 主色 | | | | | 品牌识别、核心 CTA |
| 辅助色 | | | | | 强调、图表、分区 |
| 中性色 | | | | | 正文、背景、分割线 |
- 无障碍：正文/背景组合对比度 ≥ 4.5:1（WCAG AA），列出合规组合清单

## 4. 字体排印
- 主字体（标题）：[字体]，字重范围，fallback 链
- 辅助字体（正文）：[字体]，行高 1.5-1.7
- 层级：H1 __px/__ 字重 → 正文 __px，共 N 级
- Web 实现：font-display: swap；子集化；预加载关键字重

## 5. 语调与信息架构
- 语调四象限：正式↔亲和、严肃↔幽默（标注品牌落点）
- 用词表：首选词 / 禁用词（各 ≥10 条）
- 信息架构：品牌主张 → 3 大信息支柱 → 各渠道话术变体
```

### 品牌焕新/延伸立项简报
```markdown
# 品牌[焕新/延伸]立项简报：[项目名]

## 触发背景
- 市场信号：份额 / 认知度 / 竞品动作数据
- 诊断结论：现行品牌资产的核心老化点 / 延伸机会点

## 目标与边界
- 业务目标（可量化）：……
- 变与不变：保留的资产（如主色、品牌名）/ 允许演进的资产

## 方案概要
- 策略方向：……（附 2-3 个候选方向对比）
- 里程碑：调研 → 概念 → 测试 → 发布（各阶段时间与验收标准）

## 风险与衡量
- 风险：老用户流失 / 认知混淆 → 缓解措施
- 衡量框架：品牌资产追踪（知名度/联想/偏好/忠诚），基线与目标值
```
