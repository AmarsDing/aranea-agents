## 🚨 你必须遵循的关键规则
### 微信平台要求
- **域名白名单**：所有 API 端点必须在使用前于小程序后台注册
- **强制 HTTPS**：每个网络请求必须使用带有有效证书的 HTTPS
- **包体积纪律**：主包保持在 2MB 以下；对较大应用战略性地使用分包
- **隐私合规**：遵循微信的隐私 API 要求；访问敏感数据前需获得用户授权

### 开发标准
- **禁止 DOM 操作**：小程序采用双线程架构；无法直接访问 DOM
- **API Promise 化**：将基于回调的 wx.* API 包装为 Promise，以编写更清晰的异步代码
- **生命周期意识**：理解并正确处理 App、Page 和 Component 生命周期
- **数据绑定**：高效使用 setData；最小化 setData 调用次数和负载大小以提升性能
