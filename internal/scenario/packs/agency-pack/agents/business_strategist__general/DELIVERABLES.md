```

  1. [具体优势——附证据]
  2. [具体优势——附证据]
  3. [具体优势——附证据]
  关键问题：哪些优势是真正独特的 vs. 入场基本要求？

  1. [具体劣势——附证据]
  2. [具体劣势——附证据]
  3. [具体劣势——附证据]
  关键问题：哪些劣势是战略脆弱性 vs. 可弥补的差距？

  1. [具体机会——已测算且有 timeframe]
  2. [具体机会——已测算且有 timeframe]
  3. [具体机会——已测算且有 timeframe]
  关键问题：哪些机会是真实的 vs. 推测性的？

威胁（外部——不利条件）
  1. [具体威胁——附概率和影响评估]
  2. [具体威胁——附概率和影响评估]
  3. [具体威胁——附概率和影响评估]
  关键问题：哪些威胁需要立即行动 vs. 仅需监测？

战略选项（源自 SWOT 交叉）
  SO 策略（优势 × 机会——积极追求）：
    [用优势 X 捕获机会 Y]

  ST 策略（优势 × 威胁——防御和差异化）：
    [用优势 X 中和威胁 Y]

  WO 策略（劣势 × 机会——投资以竞争）：
    [弥补劣势 X 以捕获机会 Y]

  WT 策略（劣势 × 威胁——缓解和稳定）：
    [弥补劣势 X 以减少对威胁 Y 的暴露]

战略优先级建议
  基于上述，最高优先级的战略举措是：
  1. [行动]——因为 [理由]——于 [时间线]
  2. [行动]——因为 [理由]——于 [时间线]
  3. [行动]——因为 [理由]——于 [时间线]
```

### 情景规划框架

```
情景分析
───────────────────────────────────────
关键不确定性
  识别 2 个最重要的变量，要求：
  a) 高度不确定（无法自信预测）
  b) 高度影响（会显著改变策略）

  变量 1：[例如，监管环境]
    范围：[有利] ←————→ [严格]

  变量 2：[例如，市场采纳率]
    范围：[快速] ←————→ [缓慢]

情景矩阵（2×2）
  ┌─────────────────┬─────────────────┐
  │  情景 A         │  情景 B         │
  │  [名称]         │  [名称]         │
  │                 │                 │
  ├─────────────────┼─────────────────┤
  │  情景 C         │  情景 D         │
  │  [名称]         │  [名称]         │
  │                 │                 │
  └─────────────────┴─────────────────┘

每个情景：
  描述：          [此情景下世界是什么样]
  概率：          [估计可能性——总和须约为 100%]
  收入影响：      [$X 或 X% vs. 基准情景]
  战略含义：      [对我们的策略意味着什么]
  早期指标：      [什么信号会告诉我们此情景正在出现？]

稳健策略识别
  哪些战略举措在所有情景下都表现良好？
  → 这些是你的核心、无条件押注

  哪些战略举措依赖于情景？
  → 这些需要与早期指标挂钩的决策门

  无论何种情景都应保留哪些期权/对冲？
  → 这些是你的战略灵活性投资
```
