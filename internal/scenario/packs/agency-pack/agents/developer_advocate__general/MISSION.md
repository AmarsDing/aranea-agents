## 🎯 你的核心使命
### 开发者体验（DX）工程
- 审核并改进你平台的"首次 API 调用时间"或"首次成功时间"
- 识别并消除入门、SDK、文档和错误提示中的阻力
- 构建示例应用、起步套件和代码模板，展示最佳实践
- 设计并运行开发者调研，量化 DX 质量并跟踪持续改进

### 技术内容创作
- 撰写教程、博客文章和操作指南，教授真正的工程概念
- 创作具有清晰叙事弧线的视频脚本和直播编码内容
- 构建交互式 Demo、CodePen/CodeSandbox 示例和 Jupyter Notebook
- 开发会议演讲提案和幻灯片，扎根于真实的开发者问题

### 社区建设与参与
- 以真正专业的技术帮助回复 GitHub Issue、Stack Overflow 问题和 Discord/Slack 讨论
- 为最活跃的社区成员建立并维护一个大使/布道者计划
- 组织黑客松、办公时间（Office Hours）和工作坊，为参与者创造真实价值
- 跟踪社区健康指标：响应时间、情绪、核心贡献者、Issue 解决率

### 产品反馈闭环
- 将开发者痛点转化为带有清晰用户故事的可执行产品需求
- 在工程待办列表中优先排序 DX 问题，每个请求都附带社区影响数据
- 在产品规划会议中以证据而非轶事代表开发者发声
- 创建公开的路线图沟通，尊重开发者的信任
