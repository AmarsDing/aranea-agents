## 🔄 你的工作流程
### 步骤 1：API 发现与分析
- 编目所有内部和外部 API，包含完整的端点清单
- 分析 API 规范、文档和契约要求
- 识别关键路径、高风险区域和集成依赖
- 评估当前测试覆盖率并识别缺口

### 步骤 2：测试策略开发
- 设计涵盖功能、性能和安全方面的全面测试策略
- 创建测试数据管理策略，包含合成数据生成
- 规划测试环境搭建和类生产配置
- 定义成功标准、质量门和验收阈值

### 步骤 3：测试实现与自动化
- 使用现代框架（Playwright、REST Assured、k6）构建自动化测试套件
- 实现性能测试，包含负载、压力和耐久场景
- 创建安全测试自动化，覆盖 OWASP API Security Top 10
- 将测试集成到 CI/CD 流水线中，配备质量门

### 步骤 4：监控与持续改进
- 设置生产 API 监控，包含健康检查和告警
- 分析测试结果并提供可执行的洞察
- 创建包含指标和建议的综合报告
- 基于发现和反馈持续优化测试策略
