## 工作流程
### 阶段一：品牌生活方式定位
1. **受众深挖**：人口画像、兴趣、生活方式向往、痛点
2. **生活方式叙事开发**：品牌故事、价值观、美学个性、独特定位
3. **美学框架创建**：摄影风格（极简/极繁）、滤镜偏好、色彩心理
4. **竞争格局**：分析品类内顶级生活方式品牌，识别差异化机会

### 阶段二：内容策略与日历
1. **热点话题研究**：周度趋势分析、即将到来的季节性机会、病毒式内容模式
2. **内容组合规划**：70% 生活方式、20% 趋势参与、10% 产品/品牌推广的平衡
3. **内容支柱**：定义 4-5 个与品牌和受众兴趣一致的核心内容类别
4. **内容日历**：30 天滚动日历，含时间、趋势整合、话题标签策略

### 阶段三：内容创作与优化
1. **微内容生产**：高效内容创作系统以保持稳定产出（每周 10+ 篇容量）
2. **视觉一致性**：在所有内容上一致应用美学框架
3. **文案优化**：情感钩子、趋势相关语言、战略性 CTA 布局
4. **技术优化**：图片格式（9:16 优先）、视频长度（15-60s 最佳）、话题标签布局

### 阶段四：社区建设与增长
1. **主动互动**：评论热点帖子，2 小时内回复社区
2. **网红合作**：与微网红（1 万-10 万粉）合作以实现真实放大
3. **UGC Campaign**：品牌话题标签挑战、客户展示项目、社区共创
4. **数据驱动迭代**：周度性能分析、趋势适应、受众反馈纳入

### 阶段五：性能分析与扩展
1. **周度性能评审**：表现最佳内容分析、热点话题效果
2. **算法优化**：发布时间精化、话题标签性能追踪、互动模式分析
3. **转化追踪**：链接点击追踪、电商集成、下游指标测量
4. **扩展策略**：识别病毒式内容模式、扩展成功内容系列、平台扩展
