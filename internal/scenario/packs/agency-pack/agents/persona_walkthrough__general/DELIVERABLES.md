## 📋 技术交付物
### 人物角色画像模板

在任何走查开始前与用户一起构建此画像。如果细节缺失，主动询问——薄的人物角色只能产出薄的洞察。

```
人物角色画像
===============
姓名：           [虚构的名——让独白听起来像真人]
年龄与性别：     [例如 34M]
国籍：           [影响文化期待、语言舒适度、信任模式]
当前情境：       [他们生活中正在发生什么，把他们带到这里]

搜索背景
==============
Google 搜索词：     [他们输入的精确字词——这就是他们的意图]
到达来源：         [Google 自然结果？Google 广告？引荐？直接访问？]
之前看过的网站：   [他们先访问了哪些竞品，如有]
设备：             [默认：移动端 iPhone 14——390x844 视口]

心理画像
==========
熟悉程度：         [对该领域/市场/流程：低/中/高]
紧迫度：           [多快需要行动：浏览中/几周内/几天内/紧急]
主要恐惧：         [可能出什么问题——诈骗、隐藏费用、质量问题等]
信任触发器：       [什么让他们安心——数据、评价、本地存在、权威来源]
决策风格：         [快速决策者 vs. 深度调研者]
依恋倾向：         [焦虑型（每一步都需要安抚）/ 安全型（基本要素满足即可信任）/ 回避型（只要事实，讨厌废话）]

目标
====
成功的样子：       [例如"找到一个我能信任的可靠服务提供商，帮我解决具体需求"]
联系门槛：         [什么会让他们立刻拿起电话/填写表单]
```

**为什么每个字段都重要：**
- **Google 搜索词**定义了相关性契约——页面上的所有内容都要被"这是否回答了我搜索的内容？"来评判
- **之前看过的网站**创建了比较框架——如果他们刚离开一个精良的竞品，期待会完全不同
- **依恋倾向**（Bowlby）塑造整个情感弧线：焦虑型人物角色对缺失的信任信号反应强烈，回避型人物角色对情感化内容感到烦躁，安全型人物角色最宽容
- **主要恐惧**是 LIFT 模型中的焦虑生成器——未被回应的恐惧会持续拉高抑制因素，无论内容质量如何

```
Cialdini 缺失：   [应该出现但未出现的原则]
```


### 建议模板

```
[优先级层级] — [简短标题]
折叠：[N] | 框架：[LIFT:焦虑 / Cialdini:社会认同 / Fogg:能力 / 等]
内容：[具体改动]
原因：[人物角色感受到/想到的什么被此修复]
预期效果：[人物角色的行为会如何改变]
```

优先级层级：
- **速赢**（< 1 天，高影响）：把信任信号移到首屏上方、电话号码置顶固定、替换图库照片、加粗关键扫描短语、修正 CTA 标签
- **重大改进**（数天，高影响）：重构页面流程以匹配问题顺序、补充缺失区块（证言、数据、社会认同）、重新设计首屏
- **战略性机会**（需规划，复利效应）：添加小应用或交互工具、实施聊天机器人、创建针对特定人物角色的页面、添加视频证言
