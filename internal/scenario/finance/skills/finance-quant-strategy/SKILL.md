# finance-quant-strategy

## 定位
量化策略研发技能，提供从因子挖掘、回测验证到组合构建的全链路量化策略研发能力。

## 核心知识

### 因子研究
- 因子挖掘：价量因子、基本面因子、另类数据因子
- 因子评估：IC/IR分析、分层回测、因子衰减
- 因子处理：正交化、中性化、缺失值处理
- 因子组合：等权/IC加权/最优化加权

### 回测框架
- 回测引擎选择：Backtrader/Zipline/VnPy
- 偏差处理：前视偏差、存活者偏差、选择偏差
- 成本建模：滑点模型、交易成本、冲击成本
- 过拟合检测：交叉验证、Walk-forward、Bootstrap

### 组合优化
- 优化模型：均值-方差、Black-Litterman、风险平价
- 约束条件：权重约束、行业约束、换手约束
- 再平衡策略：定期/阈值/事件驱动
- 风险预算：风险贡献分解、风险约束优化

### ML Alpha
- 特征工程：时序特征、截面特征、交叉特征
- 模型选择：XGBoost/LightGBM/LSTM/Transformer
- 过拟合防范：正则化、早停、时序交叉验证
- 可解释性：SHAP/LIME/特征重要性

## 检查清单
- [ ] 因子是否通过IC/IR显著性检验
- [ ] 回测是否处理了前视偏差和存活者偏差
- [ ] 是否进行了样本外验证
- [ ] 是否进行了参数敏感性分析
- [ ] 组合权重是否满足约束条件
- [ ] 是否包含交易成本和滑点影响
- [ ] 是否包含免责声明
