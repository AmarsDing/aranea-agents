# finance-technical-analysis

## 定位
技术分析技能，提供基于K线形态、技术指标、量价关系的系统化技术面分析能力。

## 核心知识

### K线形态识别
- 反转形态：头肩顶/底、双顶/底、三重顶/底、圆弧顶/底、V形反转
- 持续形态：旗形、三角形（对称/上升/下降）、矩形、楔形
- 缺口理论：突破缺口、测量缺口、衰竭缺口、普通缺口

### 技术指标体系
- 趋势指标：MA/EMA/MACD/ADX
- 震荡指标：KDJ/RSI/CCI/Williams %R
- 波动指标：布林带/ATR
- 量能指标：OBV/VWAP/量比

### 量价分析
- 放量突破、缩量回调、量价背离
- 地量地价、天量天价
- 量能潮汐与资金进出

### 关键价位
- 支撑位：前期低点、均线支撑、趋势线支撑、跳空缺口上沿
- 阻力位：前期高点、均线压力、趋势线压力、跳空缺口下沿

## 检查清单
- [ ] 是否进行了多周期（日线/周线/月线）交叉验证
- [ ] 量价关系是否配合（突破是否有量能支撑）
- [ ] 是否标注了关键支撑位和阻力位
- [ ] 是否给出了技术面评分（1-10）
- [ ] 是否包含止损位和目标位
- [ ] 是否包含风险提示和免责声明
