# finance-fundamental-analysis

## 定位
基本面分析技能，提供基于财务报表、估值模型、护城河分析的系统化基本面分析能力。

## 核心知识

### 财务报表分析
- 资产负债表：资产质量、杠杆水平、营运资本
- 利润表：收入结构、利润来源、毛利率/净利率趋势
- 现金流量表：经营现金流质量、自由现金流、资本支出
- 附注披露：或有事项、关联交易、会计政策变更

### 估值模型
- 绝对估值：DCF（FCFF/FCFE）、DDM
- 相对估值：PE/PB/PS/PEG/EV-EBITDA
- 估值适用场景：不同行业/生命周期阶段的估值方法选择

### 护城河分析
- 品牌壁垒、网络效应、转换成本、成本优势、规模效应
- 护城河宽度评估（宽/窄/无）
- 护城河耐久性（是否可被侵蚀）

### 管理层评估
- 治理结构、股权激励、历史业绩兑现度
- 资本配置能力、关联交易合规性

## 检查清单
- [ ] 是否分析了三大财务报表及附注
- [ ] 是否使用了多种估值方法交叉验证
- [ ] 是否给出了估值区间（悲观/中性/乐观）
- [ ] 是否评估了护城河及耐久性
- [ ] 是否列明了核心假设及假设变动影响
- [ ] 是否包含风险因素和免责声明
