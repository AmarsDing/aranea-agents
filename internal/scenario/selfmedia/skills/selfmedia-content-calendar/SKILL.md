# selfmedia-content-calendar

## 定位
提供自媒体内容日历规划的专业知识，帮助运营团队科学规划内容排期，平衡热点与常青内容，确保多平台内容节奏稳定。

## 核心知识

### 内容日历结构
- 周计划：每日1-2条内容，覆盖2-3个平台，热点+常青交替
- 月计划：4周内容主题规划，1-2个系列内容，2-3个热点预留位
- 季度计划：3个月内容方向规划，重大节点提前布局，资源分配

### 内容配比原则
- 热点内容：30-40%，追热点、蹭流量、时效性强
- 常青内容：40-50%，干货、教程、深度分析，持续获取搜索流量
- 品牌内容：10-15%，品牌故事、价值观输出、粉丝互动
- 商业内容：10-15%，带货、广告、知识付费推广

### 各平台发布时间
- 抖音：12:00-13:00 / 18:00-19:00 / 21:00-22:00
- B站：18:00-22:00（工作日）/ 10:00-22:00（周末）
- 小红书：07:00-08:00 / 12:00-13:00 / 22:00-23:00
- 视频号：08:00-09:00 / 12:00-13:00 / 20:00-21:00
- 公众号：07:30-08:30 / 12:00 / 20:00-21:00

### 热点响应机制
- 一级热点（全民级）：2小时内响应，全平台同步
- 二级热点（行业级）：4小时内响应，核心平台优先
- 三级热点（圈层级）：24小时内响应，垂直平台为主
- 热点评估：热度指数×相关度×响应难度×品牌契合度

### 资源协调
- 人力分配：策划/拍摄/剪辑/运营各环节人力协调
- 设备调度：拍摄设备、场地、道具的预约和调度
- 素材管理：素材库维护、模板更新、品牌资产版本管理

### 数据复盘
- 周复盘：内容完成率、数据达标率、热点命中率
- 月复盘：内容ROI、粉丝增长、收入贡献、策略调整
- 季度复盘：方向校准、资源优化、团队效能、年度目标进度

## 检查清单
- [ ] 内容配比是否符合30-40-10-15原则
- [ ] 发布时间是否匹配各平台流量高峰
- [ ] 是否预留热点响应的弹性空间
- [ ] 人力和设备资源是否协调到位
- [ ] 是否建立了热点响应SOP
- [ ] 是否有定期的数据复盘机制
- [ ] 多平台排期是否避免冲突
- [ ] 系列内容是否有完整的连载计划
