# selfmedia-video-editing-standards

## 定位
提供视频剪辑的专业标准和最佳实践，涵盖Premiere Pro和剪映两大工具链，确保视频产出质量和效率。

## 核心知识

### 通用剪辑标准
- 画面质量：分辨率不低于1080P，码率不低于8Mbps（短视频）/15Mbps（中长视频）
- 音频质量：对话清晰度优先，底噪不超过-40dB，BGM不遮盖对话
- 字幕规范：字体大小适配平台（短视频大字/中长视频适中），关键信息加粗高亮
- 色彩一致性：同一视频/系列色彩风格统一，肤色保护不偏色
- 帧率标准：短视频30fps，中长视频24/25fps，慢动作60fps+

### Premiere Pro 工作流
- 项目结构：素材/序列/音频/图形/输出 五大文件夹标准化
- 代理剪辑：4K素材必须建立代理工作流，代理分辨率1/4
- 调色流程：基础校正→一级调色→二级调色→输出校验
- 音频处理：降噪→均衡→压缩→限幅，对话轨/BGM轨/音效轨三轨分离
- 输出规范：H.264/H.265编码，根据平台选择最优参数

### 剪映工作流
- 模板筛选：根据内容类型匹配模板风格，优先选择高评分模板
- 智能功能：AI字幕→智能抠像→自动卡点→AI配乐，优先使用智能功能提效
- 导出设置：根据平台选择分辨率和码率，注意剪映导出的压缩比
- 移动端协作：项目文件支持移动端继续编辑

### 节奏剪辑原则
- 切镜节奏：信息密度高的段落快切（1-2秒/镜），情感段落慢切（3-5秒/镜）
- BGM卡点：关键画面切换对齐BGM节拍点，副歌段落配合画面高潮
- 变速处理：强调动作用慢动作，过渡段落用加速，变速过渡必须平滑
- 转场选择：叙事转场用硬切/叠化，风格转场用特效转场，转场必须服务叙事

### 质量检查清单
- 画面：无黑帧/闪帧/色块/压缩伪影
- 音频：无爆音/底噪/音画不同步/BGM遮盖对话
- 字幕：无错别字/时间对齐/位置不遮挡关键画面
- 品牌：Logo位置正确/品牌色一致/片头片尾完整

## 检查清单
- [ ] 画面分辨率和码率是否达标
- [ ] 音频质量是否满足清晰度要求
- [ ] 字幕是否准确且时间对齐
- [ ] 色彩风格是否统一
- [ ] 切镜节奏是否与内容情绪匹配
- [ ] BGM卡点是否对齐
- [ ] 转场是否服务叙事
- [ ] 品牌元素是否完整正确
- [ ] 输出参数是否适配目标平台
