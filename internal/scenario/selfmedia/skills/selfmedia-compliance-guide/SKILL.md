# selfmedia-compliance-guide

## 定位
提供自媒体内容合规的专业知识，覆盖各平台内容审核规则、广告法规要求和常见合规风险，帮助团队规避合规风险。

## 核心知识

### 内容审核红线
- 政治敏感：涉及国家领导人、政治事件、领土争议等敏感话题
- 色情低俗：裸露/性暗示/低俗语言/擦边内容，各平台尺度不同
- 暴力血腥：真实暴力画面/过度血腥描写/教唆暴力
- 宗教民族：宗教敏感话题/民族歧视/地域歧视
- 违禁品：烟草/毒品/武器/假证等违禁品推广
- 未成年人：不适宜未成年人观看的内容必须标注

### 各平台审核差异
- 抖音：审核最严格，AI审核+人工复审，违规即限流或封号
- B站：分区审核，不同分区尺度不同，弹幕也有审核
- 小红书：图片审核严格，商业内容必须标注，种草与广告界限模糊
- 视频号：正能量导向，负面内容容易被限流
- 公众号：相对宽松但举报机制有效，原创保护严格

### 广告法合规
- 绝对化用语：禁止「最」「第一」「唯一」「国家级」等绝对化表述
- 虚假宣传：禁止夸大产品功效、虚构使用效果、伪造用户评价
- 比较广告：禁止直接贬低竞品，间接对比需有数据支撑
- 医疗广告：医疗/药品/保健品广告需特殊资质
- 未成年人保护：不得针对未成年人发布不当广告

### 商业内容标注
- 广告标注：商业合作内容必须标注「广告」「推广」「合作」等字样
- 种草标注：小红书商业笔记必须通过蒲公英平台发布
- 直播标注：直播间带货必须标注商品来源和价格
- 知识付费：课程效果承诺不得过度，需标注「效果因人而异」

### 版权合规
- 音乐版权：使用平台音乐库或购买版权，不使用未授权音乐
- 图片版权：使用原创图片或购买版权图片，不使用未授权图片
- 视频素材：使用原创素材或购买版权素材，搬运必究
- 文字内容：引用需标注来源，不抄袭不洗稿

### 违规处理
- 限流：内容不被推荐，仅粉丝可见
- 下架：内容被删除，账号扣分
- 封号：严重违规导致账号被封禁
- 申诉：违规处理可在规定时间内申诉
- 预防：发布前自查+工具检测+同行经验

## 检查清单
- [ ] 内容是否涉及政治敏感话题
- [ ] 内容是否包含色情低俗元素
- [ ] 内容是否有暴力血腥描写
- [ ] 广告文案是否违反广告法
- [ ] 商业合作内容是否正确标注
- [ ] 使用的素材是否版权合规
- [ ] 内容是否适配目标平台审核尺度
- [ ] 是否有合规审查流程
