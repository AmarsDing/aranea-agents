# selfmedia-viral-analysis

## 定位
提供爆款内容分析的专业知识，帮助策划师和创作者拆解爆款底层逻辑，提炼可复制的爆款方法论。

## 核心知识

### 爆款拆解框架
- 选题角度：痛点/爽点/共鸣/猎奇/争议，爆款选题至少命中1个
- 开头钩子：3秒注意力捕获——悬念/冲突/共鸣/反差四类钩子模式
- 信息结构：金字塔结构（结论先行）/倒叙结构（结果前置）/递进结构（层层深入）
- 情绪曲线：好奇→投入→紧张→释放→满足，完整的情绪体验闭环
- 互动设计：评论区引导、转发动机、点赞触发点

### 爆款数据特征
- 完播率：短视频>40%、中长视频>30%为爆款基准
- 互动率：点赞率>5%、评论率>1%、转发率>2%为爆款基准
- 传播系数：每个分享带来的平均新观看>1.5为自传播阈值
- 时效窗口：热点内容24小时内、常青内容7天内为流量黄金期

### 爆款选题模型
- 痛点选题：用户有明确问题需要解决（如何/怎么/为什么）
- 爽点选题：满足用户的即时满足感（逆袭/打脸/逆袭）
- 共鸣选题：触发用户的情感认同（社畜/北漂/育儿焦虑）
- 猎奇选题：满足用户的好奇心（揭秘/对比/实验）
- 争议选题：触发用户的表达欲（观点碰撞/价值冲突）

### 平台爆款差异
- 抖音：强节奏+高信息密度+BGM驱动+评论区文化
- B站：深度内容+弹幕互动+UP主人设+系列化
- 小红书：种草导向+视觉精致+搜索流量+关键词布局
- 视频号：社交推荐+正能量+私域导流+中老年友好

## 检查清单
- [ ] 选题是否命中至少1个爆款角度
- [ ] 开头3秒是否有有效钩子
- [ ] 情绪曲线是否完整闭环
- [ ] 互动设计是否自然不生硬
- [ ] 完播率预估是否达到爆款基准
- [ ] 内容是否适配目标平台爆款特征
- [ ] 是否有可复制的爆款模式
- [ ] 热点时效性是否在黄金窗口内
