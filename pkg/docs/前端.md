# 2 对话
显示与agent和team的对话内容和对话方式，对话历史等
## 布局和详情
### 左侧agent和team列表，列表内分组显示agent和team
  1. 宽度120px 高度：100%；agent和team分组显示。
  2. 默认agent显示在agent组的最上方，可拖拽对agent进行上下调序
  3. 默认team显示在team组最上方，可拖拽对team组进行上下调序
  4. 默认agent和team无法拖拽调序，始终在最上方
  5. 顶部是按名称搜索agent和team的搜索框，带输入提示和输入过滤
  6. agent和team条目左边显示工作状态和名称，右边显示工具按钮：设置和删除
  7. 设置按钮：弹框显示agent和team的设置界面
  8. 删除按钮：弹出删除确认对话框，正在工作无法删除，删除时需填写名称后才能删除
  9. 选中agent和team时，背景高亮显示，右侧session历史记录栏显示历史session聊天记录，中间对话框显示最近session内容
  10. 首次进入默认选中默认的agent进行显示
  11. 列表右侧中间显示折叠按钮，点击折叠和现实左侧列表，带动画
### 右侧session历史聊天记录栏，列表显示
  1. 宽度120px，高度：100% 
  2. 每条右侧显示session名称，下角标显示session时间，左侧圆环显示session的上下文额度比和删除按钮
  3. 底部功能按钮，左侧新建session和右侧一键删除历史session
  4. 列表左侧中间显示折叠按钮，点击折叠和现实session，带动画
### 中间：对话区域
  1. 底部对话输入区域，初始高度100px，宽度：100%，使用autogrow属性；
    ```javascript
    <q-input
      v-model="text"
      filled
      autogrow
    />
    ```
  2. q-input输入框，输入框高度适应输入内容的量，最高高度400px，高于400px时出现滚动条。
  3. q-input框底部是工具条，固定高40px，宽度100%，左侧下拉框显示对话模式和模型提供商，右侧显示文件导入按钮，语音输入按钮和发送按钮。
  4. 有文件导入时，q-input框内部的上方显示30*30px的方框，显示导入文件进度，名称，鼠标移动到方框时，方框右上角显示关闭按钮。
  5. 剩余空间是对话内容框，控件q-chat-message，显示头像，时间，对话内容。

# 3 agent管理

## 属性

-- agents: 单条「智能体」配置（绑定模型、工具、工作区与各类 JSON 策略）。
```sql
CREATE TABLE agents (
    -- 主键；UUID v7 近似按时间有序，便于按创建顺序浏览与索引。
    id                    UUID PRIMARY KEY DEFAULT uuid_generate_v7(),
    -- 对外稳定标识（API/配置引用）；同一 owner 下全局唯一，区别于自增或展示名。
    agent_key             VARCHAR(100) NOT NULL UNIQUE,
    -- 人类可读名称；可选，仅用于 UI 展示，不参与唯一性或路由。
    display_name          VARCHAR(255),
    -- LLM 供应商标识（如 openrouter）；与 llm_providers / 路由逻辑对应，默认 openrouter。
    provider              VARCHAR(50) NOT NULL DEFAULT 'openrouter',
    -- 模型名称或路由名（供应商体系内的 model id）；与 provider 联合决定实际调用端点。
    model                 VARCHAR(200) NOT NULL,
    -- 模型上下文窗口上限（token 量级语义，具体是否严格 enforced 由应用层解释）；默认 200k。
    context_window        INT NOT NULL DEFAULT 200000,
    -- 单次运行中「思考-工具-再思考」循环的最大步数，防止死循环或过长执行。
    max_tool_iterations   INT NOT NULL DEFAULT 20,
    -- 工作目录路径（字符串）；工具读写文件、相对路径解析的默认根，默认当前目录「.」。
    workspace             TEXT NOT NULL DEFAULT '.',
    -- 为 true 时限制工具/沙箱仅能访问 workspace  subtree（具体策略由运行时实现）。
    restrict_to_workspace BOOLEAN NOT NULL DEFAULT true,
    -- 工具启用列表、参数与覆盖项（JSON）；结构由应用约定，默认空对象。
    tools_config          JSONB NOT NULL DEFAULT '{}',
    -- 沙箱/隔离执行相关配置（可选 JSON）；未设置表示走全局默认或关闭沙箱特性。
    sandbox_config        JSONB,
    -- 子代理编排、委托策略（可选 JSON）；多 agent 协作时的扩展配置。
    subagents_config      JSONB,
    -- 记忆层：向量检索、摘要、会话记忆等（可选 JSON）。
    memory_config         JSONB,
    -- 上下文压缩/摘要策略（可选 JSON）；长会话时如何折叠历史。
    compaction_config     JSONB,
    -- 上下文裁剪：截断、优先级、保留规则等（可选 JSON）。
    context_pruning       JSONB,
    -- 其它未归类扩展配置（JSON）；必须非 NULL，默认空对象，避免应用层判空分支。
    other_config          JSONB NOT NULL DEFAULT '{}',
    -- 是否为该 owner 下的默认 agent（用于未显式指定 agent 时的回退）。
    is_default            BOOLEAN NOT NULL DEFAULT false,
    -- 智能体类型/开放模式（如 open）；枚举语义由应用定义，默认 open。
    agent_type            VARCHAR(20) NOT NULL DEFAULT 'open',
    -- 生命周期：active、disabled 等；与 deleted_at 配合可做软下线与查询过滤。
    status                VARCHAR(20) DEFAULT 'active',
    -- 创建时间（写入时由数据库默认 NOW()）。
    created_at            TIMESTAMPTZ DEFAULT NOW(),
    -- 最后更新时间；应用层应在变更时刷新（若未用触发器则依赖业务代码）。
    updated_at            TIMESTAMPTZ DEFAULT NOW(),
    -- 软删除时间戳；非 NULL 表示逻辑删除，查询层通常 WHERE deleted_at IS NULL。
    deleted_at            TIMESTAMPTZ
);
```
