设计标注（v2 · 已按反馈修正）

  1. 指令面板用户指令的显示与现状完全一致：时间 + 头像 + 名称 + 全文正文 + hover 出现的复制/重新生成按钮。折叠卡不改变指令的任何显示方式。
  2. 折叠卡历史轮次 = 现有指令面板 + 下方一行 slim 状态摘要（状态徽章 + 步数 + 耗时；失败卡追加一行错误摘要）。零 step DOM，无「执行过程」按钮。
  3. 点击水合点击卡片任意位置立即水合（复制/重新生成按钮除外，不触发）；滚动到可视区停留 500ms 自动水合（顶部可关闭体验纯手动）。快速滑过不触发。
  4. 骨架屏水合中显示 thinking / action / reply 三条 shimmer 骨架。
  5. 手动折叠水合后可重新折叠释放 DOM（卡片底部「收起执行过程」）；数据保留在内存，再展开无需重新请求。
  6. 默认定位打开会话直接停在最底部；视口上方内容展开时补偿 scrollTop，阅读位置不跳动。
  7. 活跃任务运行中 / 等待确认 / 已中断的任务永远自动水合（中断卡需要「继续执行」按钮，见最底部运行中任务）。
  8. 失败态水合失败时摘要行显示「加载失败，点击重试」。
