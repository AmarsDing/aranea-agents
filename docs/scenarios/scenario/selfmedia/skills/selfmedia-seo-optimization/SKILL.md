# selfmedia-seo-optimization

## 定位
提供自媒体内容SEO优化的专业知识，覆盖微信公众号、小红书、B站、抖音等平台的搜索优化策略，帮助内容获得更多搜索流量。

## 核心知识

### 关键词研究方法
- 平台搜索下拉词：输入核心词获取平台推荐的相关搜索词
- 竞品分析：分析同赛道头部内容的关键词覆盖策略
- 长尾词挖掘：核心词+场景/人群/问题 组合拓展长尾关键词
- 搜索量评估：通过平台搜索结果数量和内容质量间接评估搜索量
- 竞争度评估：搜索结果中头部内容的数量和质量决定竞争度

### 微信公众号SEO
- 搜索入口：微信搜一搜，权重因子为账号权重+标题匹配+内容质量+互动数据
- 标题优化：核心关键词前置，控制在22字以内确保完整显示
- 正文优化：前50字出现核心关键词，正文自然重复2-3次
- 账号权重：垂直度+原创度+活跃度+互动率+无违规记录

### 小红书SEO
- 搜索入口：小红书搜索页，权重因子为关键词匹配度+笔记权重+账号权重
- 关键词布局：标题必含核心词+正文前50字出现+正文自然重复+话题标签
- 笔记权重：CES评分=点击率+互动率+完播率+转化率
- 账号权重：垂直度+活跃度+原创度+互动率
- 长尾流量：优质笔记可持续获得搜索流量3-6个月

### B站SEO
- 搜索入口：B站搜索，权重因子为标题匹配+标签+互动数据+账号权重
- 标题优化：核心关键词+吸引眼球的后缀，控制在80字以内
- 标签策略：核心标签+长尾标签+品牌标签，标签数量5-10个
- 封面优化：高点击率封面直接影响搜索排名

### 抖音SEO
- 搜索入口：抖音搜索，权重因子为标题匹配+话题标签+互动数据+完播率
- 标题优化：核心关键词+话题标签，标题字数控制在55字以内
- 话题标签：#核心话题+#长尾话题+#品牌话题
- 视频内容：口播中包含关键词有助于搜索排名

### 通用SEO原则
- 关键词密度：2-3%为宜，过高会被判定为关键词堆砌
- 语义相关：使用LSI语义词增强内容与关键词的语义关联
- 更新频率：持续更新有助于提升账号和内容的搜索权重
- 用户行为：点击率、停留时长、互动率间接影响搜索排名

## 检查清单
- [ ] 是否完成关键词研究和矩阵建立
- [ ] 标题是否包含核心关键词且前置
- [ ] 正文关键词密度是否在2-3%区间
- [ ] 是否布局了长尾关键词
- [ ] 话题标签是否覆盖核心+长尾+品牌
- [ ] 账号权重是否达标（垂直度/原创度/活跃度）
- [ ] 是否有持续的内容更新计划
- [ ] 是否建立了搜索排名监控机制
