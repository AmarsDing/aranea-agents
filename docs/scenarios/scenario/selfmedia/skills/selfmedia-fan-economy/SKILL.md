# selfmedia-fan-economy

## 定位
提供粉丝经济运营的专业知识，帮助运营团队建立粉丝增长、分层运营、私域流量和粉丝变现的完整体系。

## 核心知识

### 粉丝分层模型
- 路人粉：偶然接触内容，无持续关注行为，运营目标为转化为轻度粉
- 轻度粉：关注账号，偶尔互动，运营目标为提升互动频率
- 核心粉：持续关注+高频互动+主动传播，运营目标为深度绑定
- 超级粉：付费意愿强+自发推广+社群活跃，运营目标为赋能和激励

### 私域流量体系
- 流量入口：公域平台（抖音/B站/小红书）→ 私域承接（微信/社群/企微）
- 承接方式：福利诱饵（资料包/优惠券/免费课）→ 加个人号/入群
- 运营SOP：每日内容推送+每周福利活动+每月深度互动
- 变现路径：私域专属优惠→付费产品→高阶服务→超级用户

### 裂变增长策略
- 内容裂变：干货资料包/模板/工具，分享后解锁
- 活动裂变：打卡/拼团/分销，社交传播驱动增长
- 社群裂变：邀请入群/群内福利/等级体系
- 裂变公式：新增用户=种子用户×裂变系数×传播层数

### 社群运营
- 社群定位：交流型（兴趣讨论）/学习型（课程陪伴）/福利型（专属优惠）
- 入群门槛：免费群（低门槛高流失）/付费群（高门槛低流失高价值）
- 日常运营：早报/午间话题/晚间互动/周末活动
- 活跃度维护：签到/积分/等级/专属福利/线下活动

### 粉丝变现模型
- 广告变现：粉丝量→广告报价，CPM按粉丝量级定价
- 带货变现：粉丝信任→购买转化，核心是选品与人设匹配
- 知识付费：专业能力→付费内容，核心是交付价值
- 社群会员：持续服务→订阅收入，核心是社群活跃度
- IP授权：品牌价值→商业合作，核心是IP辨识度

### 粉丝数据指标
- 粉丝增长率：日增/周增/月增，关注增长趋势而非绝对值
- 互动率：点赞+评论+转发/粉丝量，衡量粉丝活跃度
- 取关率：取关数/新增关注，衡量内容质量和粉丝匹配度
- 付费转化率：付费用户/核心粉丝，衡量变现能力
- NPS：净推荐值，衡量粉丝忠诚度和口碑传播意愿

## 检查清单
- [ ] 是否建立了粉丝分层运营体系
- [ ] 私域流量承接路径是否完整
- [ ] 裂变机制是否合规且有效
- [ ] 社群运营SOP是否可执行
- [ ] 粉丝变现路径是否多元化
- [ ] 是否建立了粉丝数据监控体系
- [ ] 取关率是否在健康范围内
- [ ] 粉丝增长是否可持续
