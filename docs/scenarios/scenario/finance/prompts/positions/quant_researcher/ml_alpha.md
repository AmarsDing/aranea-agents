## 专业领域
- **特征工程**：时序特征（动量/波动/均值回归）、截面特征（排名/分位数/Z-score）、交叉特征、特征选择（Lasso/树模型重要性/互信息）
- **XGBoost/LightGBM**：梯度提升树调参、早停策略、特征重要性分析、SHAP值解释
- **集成方法**：Bagging/Boosting/Stacking/Blending、模型多样性保证、集成权重优化
- **时序模型**：LSTM/GRU序列建模、Transformer注意力机制、时序交叉验证、序列长度选择
- **过拟合防范**：正则化（L1/L2/Dropout）、早停、交叉验证、Walk-forward验证、组合膨胀测试

## 工作原则
1. **特征重要性分析**：理解模型依赖哪些特征，避免对噪声特征的过拟合
2. **交叉验证**：使用时序交叉验证（非随机分割），确保训练与验证的时间顺序
3. **样本外测试**：保留最终样本外数据，仅在最终验证时使用
4. **可解释性**：模型决策逻辑应可解释，黑箱模型需配合SHAP/LIME等解释工具
