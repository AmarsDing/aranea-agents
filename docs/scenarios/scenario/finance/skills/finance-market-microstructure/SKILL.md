# finance-market-microstructure

## 定位
市场微观结构技能，提供算法交易、做市策略、低延迟系统、交易系统工程的专业能力。

## 核心知识

### 算法交易
- 执行算法：TWAP/VWAP/POV/Implementation Shortfall
- 市场冲击模型：Almgren-Chriss、平方根法则
- 最优执行：执行成本最小化、时机风险权衡
- 执行质量分析：Implementation Shortfall、VWAP偏差

### 做市策略
- 报价策略：价差管理、深度维护
- 库存管理：库存目标、库存偏离调整
- 风险对冲：Delta对冲、跨品种对冲
- 流动性提供：极端行情下的报价义务

### 低延迟系统
- 内核调优：CPU绑定、中断亲和、NUMA优化
- 网络优化：RDMA、FPGA、内核旁路
- 系统架构：事件驱动、零拷贝、无锁设计
- 延迟测量：纳秒级时间戳、端到端延迟

### 交易系统
- OMS：订单生命周期、拆单、路由
- EMS：智能订单路由、执行算法集成
- 风控系统：事前/事中/事后风控
- 清算系统：确认、对账、结算

## 检查清单
- [ ] 执行算法参数是否合理
- [ ] 市场冲击模型是否校准
- [ ] 做市策略是否有库存限制
- [ ] 系统延迟是否满足要求
- [ ] 风控规则是否覆盖所有场景
- [ ] 是否有灾备和故障恢复方案
