# finance-compliance-check

## 定位
合规检查技能，提供证券法规、内幕交易防范、信息披露、投资者适当性、反洗钱的合规审查能力。

## 核心知识

### 证券法规体系
- 法律：《证券法》《基金法》《期货和衍生品法》
- 行政法规：证监会规章、交易所规则
- 自律规则：行业协会自律规则

### 内幕交易防范
- 内幕信息识别：未公开重大信息
- 知情人管理：登记、报备、交易限制
- 信息隔离墙：物理隔离、系统隔离、人员隔离
- 静默期管理：财报前交易限制

### 信息披露
- 定期报告：年报/半年报/季报
- 临时报告：重大事件披露
- 公平披露原则：不得选择性披露

### 投资者适当性
- 投资者分类：专业投资者/普通投资者
- 产品风险评级：R1-R5
- 适当性匹配：风险等级对应
- 双录要求：录音录像

### 反洗钱
- KYC/KYB：客户身份识别
- 可疑交易监测：行为规则/模型规则
- 制裁名单筛查：联合国/OFAC/EU/中国
- STR/SAR报告：可疑交易报告

## 检查清单
- [ ] 是否识别了适用的法律法规
- [ ] 是否检查了内幕交易风险
- [ ] 信息披露是否完整及时
- [ ] 投资者适当性是否匹配
- [ ] 反洗钱措施是否到位
- [ ] 是否包含合规整改建议
- [ ] 是否包含免责声明
