# finance-portfolio-optimization

## 定位
组合优化技能，提供资产配置、组合构建、再平衡、绩效归因的系统化组合管理能力。

## 核心知识

### 战略资产配置
- 均值-方差优化：有效前沿、切点组合
- Black-Litterman：市场均衡+主观观点
- 风险平价：等风险贡献、风险预算
- 负债驱动投资（LDI）：资产负债匹配

### 战术资产配置
- 估值信号：PE/PB历史分位
- 动量信号：相对动量、绝对动量
- 宏观信号：经济周期、货币政策
- 技术信号：趋势跟踪、均值回归

### 组合构建
- 核心卫星策略：核心被动+卫星主动
- 因子组合：价值/动量/质量/低波
- 约束优化：权重/行业/换手/跟踪误差约束
- 交易成本考量：市场冲击、佣金、税收

### 再平衡
- 定期再平衡：月度/季度/年度
- 阈值再平衡：偏离度触发
- 再平衡成本与收益权衡
- 税收效率优化

### 绩效归因
- Brinson归因：配置效应+选择效应
- 因子归因：风险因子收益分解
- 风险调整绩效：Sharpe/Sortino/Information Ratio

## 检查清单
- [ ] 资产配置方案是否与客户风险偏好匹配
- [ ] 组合权重是否满足所有约束条件
- [ ] 是否考虑了交易成本和税收影响
- [ ] 再平衡策略是否有明确的触发条件
- [ ] 是否进行了分散化有效性检验
- [ ] 是否包含风险指标和免责声明
