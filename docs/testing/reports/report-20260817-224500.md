## 3. 用户自测建议

1. 打开一个绑了知识库的 Agent → 记忆设置打开「仅根据知识库作答」→ 问一件库里没有的事，应明确说没有。
2. 问一件库里有的事，回答旁应出现知识 chips，点击能跳到工作台对应文档。
3. 向团队库入库一篇提到明确实体的笔记，稍后在 `entries/` 下应出现词条短页。
4. 把一篇草稿标成「仅自己可见」，换账号或未登录检索不应命中该文。
