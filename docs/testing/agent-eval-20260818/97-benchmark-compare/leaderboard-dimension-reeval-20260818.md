- **A（90）**：唯一真失配 sh-04——植入的"FW-Edge-02 管理 IP=10.20.0.2"未被提取为 L3 事实（A01 抽查归一化命中仅 10~11/25 植入词），属提取覆盖缺口，非召回段问题（召回段 P95≈47ms 全绿）。
- **B（100）**：双跳组合（设备→机房→负责人、带宽差值计算等）全对，含 1 道算术推理（2Gbps-800Mbps→1.2Gbps）。
- **C（人工 100）**：tp-02 系统将"上周三"在提取时正确归一化为"2026-08-12"并据以作答——相对时间解析能力反被字面判分误杀，实为该维度强项；双周/季度/窗口期等时间事实全对。
- **D（人工 100）**：10 组"旧值→新值"更新全部生效（电话/温度/巡检周期/对接人/带宽/数据库/工单系统/变更窗口），未出现旧值回潮；update 类事实经双时序（valid_from/to）治理，新值稳定胜出。

## 结论

1. **首评 24.56 确为部署/集成异常，非算法差距**：升级后本地五维（A/B/C/D/H）映射均值 96.0（人工）/ 78.0（最保守自动口径），相对官方首评同五维 20.3 提升 +75.7；最保守口径亦远超 SQLite-FTS 基线（41.79）同维度水平。召回链路（P95≈47ms）与事实注入已验证正常工作。
2. **重评（amc-2026.08-r2）前必修三项**：
   - ① 提取覆盖缺口（sh-04 类"设备-属性"事实未入 L3，归一化命中率仅 ~44%）；
   - ② knowledge_search 降级空转守卫（单题烧 4.5 万 token，曾致 Run 1 上游 TPM 限流 33×500）；
   - ③ 评测判分口径（语义等价匹配、abstention 仅对正文判定）——以免官方判官误判。
3. **E/G 两维本地无独立基准**，观测信号为正；如需定量覆盖，按主计划补域 B05（偏好应用）与域 G（Skill/规则执行）用例。
4. **遗留风险**：ab-04 式 180s 超时（http 000）为单点健壮性问题，重评环境需排查长耗时请求的连接链（客户端→admin→LLM 上游）。
