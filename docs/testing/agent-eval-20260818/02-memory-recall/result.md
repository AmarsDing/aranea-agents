## 解释（不要把 80% 当成「记忆检索退步」）

1. **检索侧变好或持平**：up-03 / sh-04 的 debug 第一名就是答案事实；延迟 30ms 级。
2. **回答侧变差**：eval agent 挂了知识库工具。08-21 知识 cue 更勤（目录+预检索+eval-ops-kb 还在环境里），模型更爱 `knowledge_search`，把记忆题做成「去库里找」。记忆命中了也不写进答案。
3. **拒答变差**：无证据时开始编造（晚餐、RCA 编号）。这是 grounded_only / 拒答策略问题，不是召回打分。
