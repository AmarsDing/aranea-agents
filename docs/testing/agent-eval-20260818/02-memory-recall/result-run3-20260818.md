## 缺陷清单（Run 3 收敛后，按优先级）

1. **【P0】knowledge_search 降级空转循环 + 无 turn 预算**：同 turn 内模型对空结果换词重试无上限；循环守卫按"同工具同参数"判定被换词绕过；客户端断开后服务端 agent 循环不取消，单 turn 烧到 157+ 次模型调用 / 260K+ tokens。修复方向：① 同 turn 同工具空调用熔断（连续空结果≥2 次后强制返回"已确认无结果，禁止重试"）；② per-turn 工具调用总预算硬顶；③ 客户端断开 ctx 取消传播到 agent run。
2. **【P1】L3 注入变体选择**：同实体多变体共存时，l2_l3 预算（~350 chars）仅容 2 条，答案承载变体可能被高 vec 低信息变体挤出。修复方向：同实体去重优先"含数值/最新"变体，或上调注入预算/top-k。
3. **【P1】deferred 工具未激活空转**：list_files 需先 tool_load 激活，模型直接调用被 FORBIDDEN 后仍重试（sh-04 窗口 4 次、ab-04 窗口 5 次）。修复方向：FORBIDDEN 错误返回中内嵌"请调用 tool_load(\"list_file\") 激活"可执行指引已有一部分，需让模型 1 次失败后即激活而非重复直调。
4. **【P2】判分脚本口径**：① 时间/数字语义等价归一（上周三↔绝对日期、2Gbps↔2 Gbps、9 点↔9:00）；② abstention 词表扩充（没有保存/未存储/尚未记录/无法提供/不能凭空）；③ 已修：仅判 content_markdown（regrade.ps1）。
