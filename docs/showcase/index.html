SYSTEM ARCHITECTURE

架构设计

双框架分工：Kratos v2 负责传输与治理，trpc-agent-go 负责 Agent 编排内核。五层结构自上而下，依赖单向。

01

传输壳层

Kratos v2 提供 HTTP/gRPC/WebSocket 三协议、鉴权与中间件治理，Wire 在编译期完成依赖装配。

02

运行时内核

trpc-agent-go 承载 Runner/Agent/Session/Memory/Tool/Event/Skill/Graph/Team 十大编排原语。

03

单向依赖

service → biz → data 单向依赖，biz 不感知框架运行时，架构不变量由 Fitness Function 守护。

04

读写分离

SQLite WAL 模式下写连接串行、读连接并发，事务统一入口保证 Ent 与 Raw SQL 同事务。

CORE DATA FLOW

核心数据流

两条主链路：单智能体的三级执行模型，与团队编排的四级嵌套模型。节点按真实执行时序依次点亮。

单 Agent 执行链

TASK · TURN · STEP
用户消息User Message
任务 Task一次目标拆解
回合 Turn一轮推理交互
步骤 Step思考 / 行动 / 回复

每个 Step 产生 thinking / action / reply 活动事件，经事件总线实时推送到前端，聚合成四级嵌套活动树。

团队编排链

PLAN · STAGE · RUN · SESSION
执行计划 Plan精灵拆解 DAG
阶段 TeamStage惰性组建团队
运行 TeamRun一次团队执行
成员会话MemberSession

精灵（Spirit）将用户需求编排为 DAG 计划，团队按阶段惰性组建，成员会话挂接在节点起点，保证活动树正确归属。
