# 联邦A2A网络

## 一、需求文档

### 1.1 背景

平台已有完整的 A2A（Agent-to-Agent）实现（`internal/a2a/`），支持单组织内 Agent 互操作。框架 `pkg/trpc-agent-go/agent/a2aagent/` 提供了 A2AAgent 实现，`pkg/trpc-agent-go/server/a2a/` 提供了 A2A HTTP 服务端。联邦 A2A 网络旨在从单组织扩展到跨组织联邦，支持 Agent 发现、信任建立、审计追踪。

行业参考：
- **Google A2A Protocol**：开放协议规范，定义 Agent Card / Message / Task 等核心概念，支持跨服务 Agent 互操作
- **Agent Network**：去中心化 Agent 网络，支持发现、信任、协商

### 1.2 目标

1. 建立跨组织 A2A 联邦网络，Agent 可发现和调用其他组织的 Agent
2. 建立信任体系：组织间信任等级、Agent 能力认证
3. 审计追踪：跨组织调用的完整审计日志
4. 联邦发现服务：注册中心 + 目录服务
5. 安全通信：mTLS + API Key + OAuth2

### 1.3 功能需求

| # | 功能 | 优先级 | 说明 |
|---|------|--------|------|
| F1 | 联邦注册中心 | P0 | 组织注册其 A2A 端点到联邦目录 |
| F2 | 联邦发现服务 | P0 | 按能力/行业搜索其他组织的 Agent |
| F3 | 跨组织 A2A 调用 | P0 | 本地 Agent 可调用远程组织的 Agent |
| F4 | 信任等级 | P0 | 组织间信任等级（trusted/neutral/untrusted） |
| F5 | 审计日志 | P0 | 跨组织调用的完整审计记录 |
| F6 | 安全认证 | P0 | mTLS / API Key / OAuth2 多种认证方式 |
| F7 | 联邦 Agent Card 同步 | P1 | 定期同步远程组织的 Agent Card |
| F8 | 调用配额 | P1 | 跨组织调用的速率限制和配额管理 |
| F9 | 联邦策略引擎 | P1 | 可配置的跨组织调用策略（允许/拒绝/审批） |
| F10 | 联邦监控 | P2 | 跨组织调用的延迟/成功率监控 |
| F11 | 联邦协商 | P2 | Agent 间自动协商调用方式和参数 |
| F12 | 联邦市场 | P2 | 联邦 Agent 能力市场 |

### 1.4 非功能需求

| # | 需求 | 指标 |
|---|------|------|
| NFR1 | 联邦发现延迟 | < 500ms |
| NFR2 | 跨组织调用延迟 | 额外开销 < 100ms（不含远程执行） |
| NFR3 | 审计日志完整性 | 100% 调用可追溯 |
| NFR4 | 认证安全性 | 支持 mTLS 双向认证 |
| NFR5 | 联邦规模 | 支持 ≥ 100 个组织 |

### 1.5 验收标准

1. 两个组织可互相发现对方的 Agent
2. 本地 Agent 可成功调用远程组织的 Agent
3. 跨组织调用有完整审计日志
4. 信任等级为 untrusted 时调用被拒绝
5. mTLS 认证可正常建立连接

## 二、设计文档

### 2.1 行业参考

**Google A2A Protocol**：
- 核心概念：`AgentCard`（Agent 元数据）、`Message`（通信消息）、`Task`（异步任务）
- Agent Card 端点：`/.well-known/agent-card.json`
- 消息协议：`SendMessage` / `SendMessageStreaming`
- 认证：API Key / OAuth2 / mTLS

**Agent Network**：
- 去中心化发现：DHT 或中心化注册中心
- 信任模型：Web of Trust / PKI 证书链
- 审计：不可变日志（区块链或 append-only 存储）

#### 接口设计

**联邦领域模型**（`internal/biz/federation.go`）：

```go
type FederationOrg struct {
    ID          string
    Name        string
    Domain      string
    PublicBaseURL string
    TrustLevel  TrustLevel
    AuthType    string
    AuthConfig  string
    Status      string
    JoinedAt    string
}

type TrustLevel string

const (
    TrustLevelTrusted   TrustLevel = "trusted"
    TrustLevelNeutral   TrustLevel = "neutral"
    TrustLevelUntrusted TrustLevel = "untrusted"
)

type FederationAgent struct {
    OrgID       string
    AgentCard   A2AAgentCard
    RemoteURL   string
    LastSyncAt  string
}

type FederationAuditLog struct {
    ID           string
    CallerOrgID  string
    CalleeOrgID  string
    CallerAgentID string
    CalleeAgentID string
    Capability   string
    Status       string
    LatencyMs    int
    Timestamp    string
}

type FederationPolicy struct {
    ID             string
    CallerOrgID    string
    CalleeOrgID    string
    Action         PolicyAction
    MaxQPS         int
    DailyQuota     int
    RequireApproval bool
}

type PolicyAction string

const (
    PolicyActionAllow    PolicyAction = "allow"
    PolicyActionDeny     PolicyAction = "deny"
    PolicyActionApproval PolicyAction = "approval"
)

type FederationOrgReader interface {
    ListOrgs(ctx context.Context) ([]FederationOrg, error)
    GetOrg(ctx context.Context, id string) (FederationOrg, error)
    GetOrgByDomain(ctx context.Context, domain string) (FederationOrg, error)
}

type FederationOrgWriter interface {
    RegisterOrg(ctx context.Context, org FederationOrg) (FederationOrg, error)
    UpdateOrg(ctx context.Context, org FederationOrg) (FederationOrg, error)
    SetTrustLevel(ctx context.Context, orgID string, level TrustLevel) error
}

type FederationOrgRepository interface {
    FederationOrgReader
    FederationOrgWriter
}

type FederationAuditReader interface {
    QueryAuditLogs(ctx context.Context, q AuditQuery) ([]FederationAuditLog, error)
}

type FederationAuditWriter interface {
    RecordAuditLog(ctx context.Context, log FederationAuditLog) error
}

type FederationAuditRepository interface {
    FederationAuditReader
    FederationAuditWriter
}
```

#### 数据流图

```
组织 A 注册到联邦
    │
    ▼
FederationService.RegisterFederationOrg()
    │
    ▼
FederationUsecase.RegisterOrg(ctx, org)
    ├── 验证域名和认证配置
    ├── FederationOrgRepository.RegisterOrg()
    └── 设置初始信任等级为 neutral

组织 A 发现组织 B 的 Agent
    │
    ▼
FederationService.DiscoverFederationAgents(capability="financial_analysis")
    │
    ▼
FederationUsecase.DiscoverAgents(ctx, "financial_analysis")
    ├── 查询 FederationOrgRepository 获取 trusted/neutral 组织
    ├── 对每个组织调用 Agent Card 端点同步能力
    └── 过滤匹配 capability 的 Agent

组织 A 调用组织 B 的 Agent
    │
    ▼
FederationService.InvokeFederatedAgent(orgB_id, agent_id, capability, payload)
    │
    ▼
FederationUsecase.InvokeFederated(ctx, orgB_id, agent_id, capability, payload)
    ├── TrustManager.CheckTrust() → 检查信任等级
    ├── PolicyEngine.Evaluate() → 检查调用策略
    ├── RateLimiter.CheckQuota() → 检查配额
    ├── InvokeRemoteRegistry() → 调用远程 Agent
    ├── AuditLogger.Record() → 记录审计日志
    └── 返回调用结果
```

### 2.4 与框架的集成方式

| 集成点 | 框架组件 | 集成方式 |
|--------|----------|----------|
| A2A 代理 Agent | `a2aagent.New` | 联邦调用通过 `BuildTRPCA2AAgent` 创建 A2A 代理 |
| A2A 服务端 | `a2atrpcserver.New` | 本地 Agent 通过 `BuildA2AEndpointServer` 暴露 A2A 端点 |
| A2A 客户端 | `a2aclient.NewA2AClient` | 联邦调用使用 A2A 客户端 |
| 认证 | `ClientAuthOptions` | 复用现有 API Key / mTLS 认证逻辑 |
| 远程调用 | `InvokeRemoteRegistry` | 联邦调用复用远程调用逻辑 |
| 目标解析 | `ResolveInvokeTarget` | 扩展支持联邦目标解析 |
| 事件发射 | `agent.EmitEvent` | 联邦调用事件通过标准事件通道发射 |

### 2.5 错误处理

| 场景 | 错误码 | 处理 |
|------|--------|------|
| 组织未注册 | `NotFound("FEDERATION", "org not registered")` | 返回 404 |
| 信任等级不足 | `Forbidden("FEDERATION", "trust level too low")` | 返回 403 |
| 调用策略拒绝 | `Forbidden("FEDERATION", "call denied by policy")` | 返回 403 |
| 配额超限 | `TooManyRequests("FEDERATION", "quota exceeded")` | 返回 429 |
| 远程 Agent 不可达 | `BadGateway("FEDERATION", "remote agent unreachable")` | 返回 502 |
| mTLS 认证失败 | `Unauthorized("FEDERATION", "mtls authentication failed")` | 返回 401 |
| Agent Card 同步失败 | `InternalServer("FEDERATION", "card sync failed")` | 降级使用缓存 |

### 3.3 验证方案

| 验证项 | 方法 | 通过标准 |
|--------|------|----------|
| 组织注册 | 注册两个组织到联邦 | 组织列表包含两个组织 |
| Agent 发现 | 按能力搜索联邦 Agent | 返回匹配的远程 Agent |
| 联邦调用 | 组织 A 调用组织 B 的 Agent | 调用成功返回结果 |
| 信任控制 | 设置 untrusted 后调用 | 调用被拒绝 |
| 审计追踪 | 查询审计日志 | 包含完整调用记录 |
| mTLS 认证 | 使用 mTLS 建立连接 | 连接成功 |
| 配额限制 | 超过配额后调用 | 返回 429 |
| API 契约 | `make api && go build ./...` | 编译通过 |
| Wire 注入 | `make wire && go build ./cmd/admin` | 编译通过 |
