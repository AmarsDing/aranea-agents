## 四、聊天发送到任务结束的完整流程

### 4.1 单 Agent 对话流程 (owner_type=agent)

```
用户在 Web 输入 "帮我分析这段代码"
    │
    ▼
POST /v1/chat/messages/stream  (SSE) 或 POST /v1/chat/messages (unary)
    │
    ▼
[HTTP Filter 链] CorsDevFilter → Auth.Middleware → LegacyRESTProxy (可选)
    │
    ▼
ChatService.ProxyStream(ctx)  或  ChatService.SendChatMessage(ctx, req)
    │
    └── nativeSendChatMessage / proxyNativeStream
            │
            ▼
    ┌───────────────────────────────────────────────────────────────────┐
    │  runNativeAgentTurn(ctx, req, stream)                             │
    │                                                                   │
    │  1. 检查 activeRuns — 若 session 已在运行 → 排入 pendingQueue    │
    │                                                                   │
    │  2. 加载会话 SessionUsecase.Get(sessionID)                        │
    │     → sessions 表: owner_type, agent_id, team_id, dialog_mode    │
    │                                                                   │
    │  3. 判断 owner_type:                                             │
    │     ├── "team" → teamsNative.RunTurn()  (见 4.2)                 │
    │     └── "agent" → 继续以下流程                                    │
    │                                                                   │
    │  4. 加载 Agent hydratedAgent(ctx, agentID)                        │
    │     → AgentUsecase.Get() → agents + agent_runtime_settings       │
    │     → 包含: provider, model, system_prompt, files, settings      │
    │                                                                   │
    │  5. 解析对话参数:                                                 │
    │     dialogMode ← req > session > agent (默认 "default")          │
    │     provider   ← req > session > agent                           │
    │     model      ← req > session > agent                           │
    └───────────────────────┬───────────────────────────────────────────┘
                            │
                            ▼
    ┌───────────────────────────────────────────────────────────────────┐
    │  runSingleAgentViaTRPC(ctx, sess, req, agent, ...)               │
    │                                                                   │
    │  6. 构建 Agent BuildTRPCLLMAgent(ctx, agent, deps)               │
    │     ├── 解析 Model: TRPCModelForProviderModel()                   │
    │     │   → LlmProviderModelUsecase → CatalogConfig                │
    │     │   → trpcprovider.Model("openai", "gpt-4o", opts...)        │
    │     │   → 可选 Failover/Hedge 包装                                │
    │     ├── 构建系统提示: BuildSystemPrompt()                          │
    │     ├── 挂载技能: SkillUsecase → FSRepository + LocalExecutor    │
    │     ├── 挂载工具: GetEffectiveTools → BuildToolsets               │
    │     │   → filesystem / hostexec / web / search / mcp / ...       │
    │     ├── 注册回调: AfterTool → RecordToolInvocation               │
    │     ├── 设置重试: RetryPolicy (可选)                              │
    │     └── 设置并行: ToolsParallelEnabled (可选)                    │

    │  7. 创建 Runner NewTRPCRunner(root, deps)                         │
    │     ├── SessionService → SQLite 持久化会话链                     │
    │     └── MemoryService → sessionmemory.Store 适配器               │
    │                                                                   │
    │  8. 注册 activeRuns[sessionID] = runner                          │
    │                                                                   │
    │  9. 意图识别 (可选) intent.Run()                                  │
    │     → LLM 快速分类 → intent_artifact 合入 user_options           │
    │                                                                   │
    │  10. 保存用户消息 Sessions.AppendChatMessage(userMsg)             │
    │      → messages 表: role=user, content, options_json             │
    │      → SSE: emit("user_message", userMsg)                        │
    │                                                                   │
    │  11. 执行 Agent Run RunTRPCUserTurn()                             │
    │      → runner.Run(ctx, userID, sessionID, UserMessage)           │
    │      → 返回 <-chan *trpcevent.Event                               │
    └───────────────────────┬───────────────────────────────────────────┘
                            │
                            ▼
    ┌───────────────────────────────────────────────────────────────────┐
    │  事件循环 for ev := range events                                  │
    │                                                                   │
    │  ┌─────────────────────────────────────────────────────────────┐  │
    │  │  trpc-agent-go Runner 内部执行:                             │  │
    │  │                                                             │  │
    │  │  A. 加载会话历史 SessionService.Get(sessionID)              │  │
    │  │     → SQLite session_chain 表                              │  │
    │  │                                                             │  │
    │  │  B. 注入记忆 MemoryService.Store()                          │  │
    │  │     → L0 最近对话窗口 / L1 工作记忆 / L3 向量检索          │  │
    │  │                                                             │  │
    │  │  C. 组装 LLM 请求 (system + memory + history + user)       │  │
    │  │     → TokenTailor 裁剪超限上下文                            │  │
    │  │                                                             │  │
    │  │  D. 调用 LLM Model.Generate()                               │  │

    │  │     → 流式返回 Response.Choices                            │  │
    │  │                                                             │  │
    │  │  E. 解析 LLM 响应:                                         │  │
    │  │     ├── 纯文本 → 拼接 reply                                │  │
    │  │     ├── reasoning_content → 拼接 reasoning                 │  │
    │  │     └── tool_calls → 执行工具                              │  │
    │  │                                                             │  │
    │  │  F. 工具执行 (若有 tool_calls):                             │  │
    │  │     ├── Filter 检查 → deny 列表过滤                        │  │
    │  │     ├── 执行 Tool.Call(ctx, arguments)                     │  │
    │  │     ├── AfterTool 回调 → RecordToolInvocation()            │  │
    │  │     │   → tool_invocations 表: tool_key, status, duration  │  │
    │  │     ├── RetryPolicy (若失败且可重试)                        │  │
    │  │     └── 工具结果 → 追加到会话 → 回到 D 继续调用 LLM       │  │
    │  │                                                             │  │
    │  │  G. 重复 D~F 直到 LLM 不再产出 tool_calls                  │  │
    │  └─────────────────────────────────────────────────────────────┘  │
    │                                                                   │
    │  12. 事件处理 (逐条消费):                                        │
    │      ├── ev.StateDelta → SSE: emit("state_delta")                │
    │      ├── ev.Response.Choices[].Content →                         │
    │      │   ├── 流式: VisibleStreamingDelta → SSE: emit("delta")   │
    │      │   └── 非流式: 拼接 reply 字符串                          │
    │      ├── ev.Response.Choices[].ReasoningContent →                │
    │      │   └── 流式: SSE: emit("delta", {reasoning_content})      │
    │      ├── ev.Response.Choices[].ToolCalls →                       │
    │      │   └── SSE: emit("tool.call", {tool_name, tool_call_id})  │
    │      └── ev.Response.Usage → 记录 promptTok / completionTok     │
    │                                                                   │
    │  13. 保存助手消息 Sessions.AppendChatMessage(assistantMsg)        │
    │      → messages 表: role=assistant, content, model, tokens      │
    │      → SSE: emit("done", assistantMsg)                           │
    │                                                                   │
    │  14. 更新上下文用量 patchSessionContextUsage()                    │
    │      → sessions 表: context_used_tokens, context_used_ratio     │
    │      → 触发压缩 AfterNativeTurn() (若超阈值)                    │
    │                                                                   │
    │  15. 记录用量 recordChatIngressUsage()                           │
    │      → usages 表: provider, model, tokens, cost                 │
    │                                                                   │
    │  16. 清理 activeRuns.Delete(sessionID)                           │
    │      → 检查 pendingQueue → 若有待处理消息则继续执行              │
    └───────────────────────────────────────────────────────────────────┘
                            │
                            ▼
    SSE 连接: 前端收到事件流
    ├── event: user_message   → 显示用户消息气泡
    ├── event: delta          → 逐字渲染助手回复
    ├── event: tool.call      → 显示工具调用状态
    ├── event: state_delta    → 更新 Agent 状态
    └── event: done           → 完成渲染，显示 token 统计
```
