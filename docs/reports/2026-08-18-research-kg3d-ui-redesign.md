### 1.2 视觉系统（直接观察）

**节点 = 发光甜甜圈**（非实心球/点精灵）：

| 层级 | 形态 | 颜色 | 标签 |
|------|------|------|------|
| 核心（集团） | 最大，亮芯 + 外环 + 强辉光 | 品红/粉 #f06a9e 系 | 白色粗体，常显 |
| 一级（供应商） | 中，金色环 + 暗芯 + 辉光 | 金 #f5c542 系 | 白色，中距可见 |
| 二级 | 小，青色环 | 青 #35c8d0 系 | 浅青小字，近距/hover 可见 |
| 末梢 | 微小暗点（几乎融入星空） | 暗青蓝 | 仅 hover |

**边**：细直线，青白色低透明；核心射出的边更亮更青；聚焦链路为亮青色。**背景**：近黑深空蓝（≈#050a12）+ 稀疏星点微粒。**整体**：高对比品红/金/青三带配色，强辉光（bloom），"科技感指挥中心"风格。

### 1.3 HUD 系统（直接观察）

- **顶部居中**：科技括号 `[ ]` 框住的大标题「大数据知识图谱」青色辉光 + 英文小字副标 `ARTIFICIAL INTELLIGENCE REVIEW`（字距拉宽）。
- **左上**：`SYS:STATUS` + 绿色 `ONLINE` 状态灯。
- **左中**：竖向胶囊玻璃工具栏（青描边发光、分隔线）：约 5 枚线性图标——布局/面板、魔法棒、重置（循环箭头）、全屏（四角展开）、灯泡（提示）。
- **左下**：操作提示 chips（如「鼠标左键」），随交互上下文增减。
- **右上（hover 时）**：节点迷你信息卡。
- **右下**：录屏软件水印（非设计内容，忽略）。

### 1.4 详情面板（f07，直接观察）

- 深色玻璃 + 青强调，贴右缘全高滑入。
- **头部**：节点图标（青色圆形）+ 名称「组件制造商…」+ `ID: entity_4.31` 芯片 + 属性标签（「中外合资企业」）。
- **三统计块横排**：企业评分 `842`（青）｜注册资本 `4912万元`｜风险状况 `中风险`（橙）。
- **Tab 栏**：基本档案（激活，青下划线）｜经营数据｜风险洞察。
- **小节**（中英双语标题 + 图标）：工商信息 // REGISTRATION（双列键值：法定代表/成立日期/实缴资本/参保人数/信用代码/地址）；主营业务 // PRODUCTS（标签 chips：精密轴承/液压系统/传感器模组/伺服电机 + 一段描述）；股东结构 // SHAREHOLDERS（名称 + 青色占比进度条）。

### 1.5 可借鉴的 6 个设计要点

1. **结构层级着色**：颜色表达节点在图里的结构地位（核心/一级/末梢），而非仅表达分类。
2. **甜甜圈节点形态**：环+芯+辉光，比实心点更"高端"，且环色/芯色可双通道编码。
3. **电影化相机叙事**：拉远秀规模 → 环绕秀纵深 → 推近秀细节，全程自动且可随时打断。
4. **聚焦三连**：幽灵化（信息降噪）+ 邻域重排（结构清晰化）+ 详情面板（内容深化），一键完成。
5. **标签 LOD**：常显标签只给最高层级；其余靠 hover/聚焦点亮——画面永远干净。
6. **HUD 极简化**：画布占满，控件全部浮层化、图标化，无常驻侧栏。

## 二、现状盘点与差距分析

### 2.1 现状（G5 V12.8，已具备的能力）

- 自研 three.js GPU 管线：PositionTexture 一次 memcpy/tick，instanced 节点/边，UnrealBloom，物理 Worker（主线程兜底），自适应画质 governor（HIGH/MID/LOW）。
- 节点三层分级 `tiering.ts`（regular/supernode/ultranode，度数为据）——**与视频的结构层级天然对应**。
- 着色：doc_type 哈希调色板（8 色，`graphUi.ts`），边按 explicit/entity/semantic 三色。
- 相机状态机 `cameraDirector.ts`：idle/flying/orbiting/cruising/**genesis（创世绽放）**。
- 交互：hover 一跳高亮 + 焦点标签；单击聚焦锁定（BFS N 跳 dim，**只调暗不重排**）；双击在浏览中打开；超点点击→组聚焦；图例透镜。
- UI 布局：左画布 + **右侧 300px 常驻操作台**（库选择/边过滤/范围/邻域步进/实体治理/搜索/节点列表/选中卡）；画布右上横排**文字按钮**工具条；左下图例 + 统计行；FocusCard 浮层（名称/类型/度数/路径 + 2 操作）。

### 2.2 差距分析

| # | 维度 | 视频参考 | 现状 | 差距 |
|---|------|----------|------|------|
| G1 | 页面布局 | 全幅沉浸画布 + 浮层 HUD，无常驻侧栏 | 画布+300px 常驻操作台，舞台被挤压 | **布局范式不同** |
| G2 | 节点形态 | 甜甜圈（环+芯+辉光） | 实心光斑（点精灵） | 形态高级感不足 |
| G3 | 着色语义 | 结构层级色（粉>金>青>尘） | doc_type 8 色 | 结构可读性弱 |
| G4 | 聚焦反馈 | 幽灵化 + **邻域重排为径向链路** + 详情面板 | 仅 BFS dim + 小 FocusCard | 聚焦后结构仍乱、内容浅 |
| G5 | 详情内容 | 统计带 + Tab + 双语小节 + 进度条 | FocusCard 仅 4 字段 | 信息架构单薄 |
| G6 | hover 反馈 | 标签点亮 + 右上迷你卡 | 一跳高亮 + 焦点标签 | 少迷你卡 |
| G7 | HUD | 括号大标题/状态灯/竖排图标栏/按键提示 | 横排文字按钮 + 统计行 | 仪式感弱 |
| G8 | 相机叙事 | 开场拉远-环绕-推近全自动编排 | genesis 单段绽放 + cruise | 编排层次少 |

**保留不动的底盘**：GPU 管线、物理 Worker、画质 governor、tier 分级、相机状态机、doc_type 调色板（改作第二着色模式）、全部数据流（页面 → props → 画布）。本次重设计 = **渲染层视觉替换 + HUD 重构 + 聚焦/详情交互升级**，纯前端，零后端/Proto 改动。

## 三、重设计方案（拟命名 V13「沉浸深空」）

> 命名沿用模块演进序列（V12.8 = G5）。各决策点 D1–D10 可独立评审、独立实施。

### D1 布局：全幅沉浸画布 + 抽屉化控制台

```
┌────────────────────────────────────────────────────┐
│  [左上: SYS 状态灯]   [顶部居中: 括号标题+库名]      │
│                                                    │
│ ┃工具┃                                             │
│ ┃胶囊┃              3D 画布（全幅）        [迷你卡] │
│ ┃(竖)┃                                             │
│                                                    │
│  [左下: 按键提示] [统计行]              [详情面板→] │
└────────────────────────────────────────────────────┘
```

- 画布占满整个舞台（非全屏模式下亦是），现有右侧 300px 操作台**改为右缘滑出抽屉**（默认收起，边缘把手 + 快捷键 `]` 开合）。抽屉内功能原样保留（库选择/过滤/治理/搜索/列表）。
- 全屏覆盖模式（SP2-8 已有）直接复用此沉浸布局。
- 库选择器上移到**顶部标题区**（标题下方小字下拉），边类型过滤并入图例浮层，搜索保留在抽屉 + 新增 `⌘K` 图谱内搜索浮层（P1）。

### D2 节点视觉：甜甜圈化 + 双模式着色

- **形态**：NodeLayer 片元着色器内 SDF 绘制「外环 + 内芯 + 径向衰减辉光」三件套（不增几何体，instanced 不变）：环半径/芯半径/辉光强度为 per-instance attribute；ultranode 额外一层细外环（双环 = 视频选中态/超点态）。
- **着色模式 A：结构层级（默认，视频同款）**：
  - ultranode → 品红 `#f472b6`；supernode → 金 `#f5c542`；regular → 青 `#35c8d0`；degree ≤1 末梢 → 暗青 `#1d4e5e` 降 alpha。
  - 与现有 `classifyTiers` 输出直挂，零新计算。
- **着色模式 B：doc_type 分类**（现状 8 色，保留）：图例/过滤语义不变。工具栏一键切换 A/B（`kg3d-color-mode` localStorage 持久化）。
- 环色 = 模式色，芯色 = 模式色提亮；hover/选中时芯扩展为满盘（视频双环高亮态）。

### D3 边视觉：聚焦亮青化

- 常态：细青白低透明（现状参数微调：降亮度、降饱和度，向视频的"隐入背景"靠拢）。
- hover/聚焦链路：亮青 `#39e6ff` + 轻微流光（UV 滚动，受 reduced-motion 约束降级为纯色）。
- explicit/entity/semantic 三色移至**图例开关**：默认统一青白，开启「边类型着色」后才上色（视频观感优先）。

### D4 标签 LOD 分级

| 通道 | 内容 | 显隐规则 |
|------|------|----------|
| 常显 | ultra/super 节点名 | 现有 labelCandidates（20/14/8 随画质档） |
| 近距 | regular 节点名 | 相机距离阈值淡出（LabelLayer 已有距离衰减，调曲线） |
| hover/聚焦 | 任意节点名 | 焦点标签通道（现状已有） |
| 末梢 | 不常显 | 仅 hover |

### D5 HUD 重构（深空仪式感）

- **顶部居中**：`[ 知识图谱 ]` 括号大标题（青辉光）+ 副标 `KNOWLEDGE GRAPH · {库名}`（小字宽字距，点击=库切换下拉）。
- **左上**：`SYS:STATUS` + 状态灯：加载中 `SYNCING`（琥珀闪烁）/ 就绪 `ONLINE`（青）/ 错误 `OFFLINE`（红）。
- **左中竖排图标胶囊**（玻璃、青描边、tooltip + 快捷键）：适应视图 ⛶｜布局 force/galaxy 切换｜着色模式 A/B｜自动旋转｜标签开关｜图例（弹层）｜控制台抽屉｜全屏。替代现有横排文字工具条（文字按钮迁入抽屉顶部）。
- **左下**：按键提示 chips，随上下文变化：默认「左键 旋转｜右键 平移｜滚轮 缩放」；hover 节点时追加「单击 聚焦｜双击 打开」；聚焦态追加「单击空白 退出聚焦」。
- **统计行**：保留现状（节点/边/隐藏孤立/邻域提示），移到画布下缘居中。

### D6 hover 迷你卡（右上浮层）

触发：hover 节点 >150ms。内容 4 行：名称（粗）｜doc_type chip + 度数｜rel_path（单行省略）｜灰字提示「点击查看详情」。玻璃小卡，指针不穿透（`pointer-events:none`），移出 120ms 淡出。复用现有 hover 去抖（HOVER_REPICK_PX）。

### D7 聚焦 V2：幽灵化 + 径向重排（核心交互升级）

单击节点（或迷你卡/列表/搜索定位）触发三连：

1. **幽灵化**：非 N 跳邻域节点 alpha → 0.06、尺寸 ×0.6（per-instance attribute 插值 300ms，不重建几何）；非邻域边 alpha → 0.03。——现状只有 dim，不够"尘化"。
2. **径向重排**：邻域子图叠加径向布局力——根节点锚定画面中心偏左，第 k 跳邻居目标半径 = k × R（R≈60），同跳按度角均布。实现复用现有 `setLayout` 机制：新增 `radial` 力参数预设（hops 分层 radial force + 强 link + 弱 charge），物理收敛 morph 过去，不打断可拖拽。
   - 备选（实现更轻）：前端直接计算邻域目标坐标，300–500ms 位置插值 morph（绕开物理）。P0 先用插值，P2 评估径向力。
3. **详情面板滑入**（D8）。

退出：单击空白 / ESC / 面板关闭 → 反向 morph 回原坐标 + 解除幽灵化。跳数沿用现有 1–4 步进（聚焦后面板内可调）。

### D8 节点详情面板（文档版，右缘全高滑入）

数据全部为现有字段或现有 API 懒加载，**无后端改动**：

- **头部**：doc_type 图标 + 名称 + `ID: {doc_id}` chip + doc_type 标签 +（team 库）团队徽标。
- **统计带（3 块）**：连接度（青）｜出链数｜入链数（由 edges 现算）；第二行可放「显式/实体/语义」迷你占比条（= 视频股东进度条的迁移语义）。
- **Tab 栏**：
  - `概览 // OVERVIEW`：rel_path、doc_type、更新时间（文档详情 API 懒加载）、frontmatter tags chips、摘要段（frontmatter description，无则隐藏）。
  - `关系 // RELATIONS`：按边类型分组的邻居列表（名称+类型色点），点击→相机飞往该邻居并切换面板对象（= 沿链漫游）。
  - `操作 // ACTIONS`：在浏览中打开（现有链路）、重新向量化（现有 B1 入口）、聚焦邻域跳数步进、实体合并建议（现治理列表中与本节点相关项）。
- 滑入/滑出 240ms easeOutCubic；面板打开期间画布右侧自动留出安全区（相机 target 左移，视频的链路图居左构图）。
- **取代 FocusCard**（能力完全覆盖），FocusCard 退役。

### D9 相机导演编排

复用现有 `CameraDirector` 状态机，新增一条**开场编排**（generation 变化/首次进入触发，可随时打断 = user-interrupt）：

```
genesis(绽放 1.2s) → pullback(匀速拉远至全图 1.6s) → orbit(半周环绕 2.4s) → pushin(回中景 1.2s) → idle
```

- 聚焦时复用现有 flying（二次贝塞尔甩镜），落点改为「节点居中偏左」（配合 D8 面板）。
- cruising（巡游）默认关闭，工具栏可开。

### D10 动画规格表

| 动画 | 时长 | 缓动 | 备注 |
|------|------|------|------|
| hover 高亮/迷你卡 | 120ms in / 120ms out | easeOut | 去抖 150ms |
| 幽灵化过渡 | 300ms | easeInOutQuad | per-instance attribute 插值 |
| 径向重排 morph | 450ms | easeInOutQuad | P0 坐标插值 |
| 面板滑入/出 | 240ms | easeOutCubic / easeInCubic | translateX |
| 相机 flying | 900ms | easeInOutQuad | 现状 |
| 开场编排 | 6.4s 全程 | 分段 | 可打断 |
| 布局切换 morph | 收敛式 | 物理 | 现状 reheat |

全部遵守 `useReducedMotion`：reduced 时重排/相机降为瞬切 + 单次淡入。

### D11 性能与降级

- 甜甜圈 SDF 在片元内完成，GPU 增量 ≈ 每像素数次代数运算，可忽略；LOW 档自动退化为现状光斑（qualityTiers 规格加 `donut: boolean`）。
- 幽灵化/着色模式均为 attribute/uniform 驱动，零几何重建、零物理重跑。
- 径向 morph 期间物理暂停（Worker standby），结束后回写位置，不额外耗帧。
