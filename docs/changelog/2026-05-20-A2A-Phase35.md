# Changelog — A2A Phase 3.5（传输语义 + Graph + 远程 Invoke + 网关）

**日期**：2026-05-20  
**模块**：A2A（26）

## 摘要

澄清 **SSE / WebSocket / 多协议** 分工；交付 Graph resume 元数据桥接、**远程 registry 直接 Invoke**、**GatewayDiscover** 联邦 API，并增强 Discover 来源字段。

## 传输模型（文档）

| 场景 | 传输 | SSE 必须？ |
|------|------|------------|
| A2A Public Endpoint / Proxy → 远程 | A2A `message/send` 或 `message/stream`（SSE） | 否；按 AgentCard streaming 协商 |
| Chat UI | `/v1/ws` WebSocket | 否 |
| Admin `POST /v1/a2a/invoke` | 一元 JSON | 否 |

详见 [26 a2a-protocol.design.md §十二](../需求/26%20a2a-protocol.design.md)。
