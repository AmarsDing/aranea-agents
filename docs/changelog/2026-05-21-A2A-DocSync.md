## 架构对齐要点（文档已反映）

- **派发单一路径**：`call_agent` 与 Admin `Invoke` 共用 `internal/a2a/invoker.go` + `ChatService.RunAgentTurn`
- **运行时注入**：`injectA2AContext` / `InjectRunContext`（非散落 `With*` 三处手写）
- **Agent Kind**：`BuildTRPCAgent` 路由 `llm` | `a2a_proxy`；Endpoint 仅 catalog LLM + enabled Card
- **远程**：`ResolveInvokeTarget` + `remote_invoke.go`；本地 disabled 不 fallback 远程同 ID
- **联邦**：`GatewayDiscover`（`internal/biz/a2a_gateway.go`）与扁平 `Discover` 职责分离
- **传输**：A2A HTTP（公开 Endpoint）/ Admin JSON（Invoke）/ Chat WebSocket 三分工
