## hook
[[cue:question]]一个人，能同时经营多少家公司？
[[cue:pain]]过去，答案受限于你的时间、精力，和你请得起多少人。
[[cue:shift]]但在 AI 时代，这个等式被彻底改写。
[[cue:slogan]]Aranea-Agents，一个企业级多智能体编排平台。
[[cue:ceo]]你当总裁，AI 组队，一个人，就是 N 家公司。

## features
[[cue:platform]]先看这个平台的家底：三十六个业务模块，覆盖 Agent 全生命周期。
[[cue:spirit]]核心是 Spirit 动态编排引擎：你说一句话，它自动拆任务、建团队、跑执行。
[[cue:modes]]六种团队编排模式加可视化 Graph 图编排，从流水线到复杂分支，全部覆盖。
[[cue:memory]]五层记忆系统，从短期对话到知识图谱，让 Agent 过目不忘。
[[cue:evolution]]技能和 Agent 都会自动进化：从运行数据中发现模式，人工审批后越用越强。
[[cue:observability]]全链路可观测：每一次调用有 Trace，故障自动根因分析，甚至自动自愈。
[[cue:cost]]六维定价、微美元精度、三级配额告警，每分钱的去向都算得清。
[[cue:channels]]十三个 IM 平台一键接入，飞书、钉钉、企微，Agent 一次创建、全平台上岗。
[[cue:security]]五重安全护栏加十二家模型供应商，企业级，开箱即用。

## orchestration
[[cue:why]]多 Agent 编排的平台不少，Aranea 最吸引人的，是三件事。
[[cue:dynamic]]第一，动态组队。Spirit 先找现成团队，没有就从角色库挑人，再没有，就亲手创造一个，三层兜底，永不落空。
[[cue:visible]]第二，全程可视。团队面板里，每个成员的思考、行动、产出实时展开，不是黑盒，是透明的作战指挥室。
[[cue:control]]第三，随时接管。发现跑偏，一键暂停、注入新指令、调整方向，关键决策还会停下来等你拍板。这不是全自动化，这是人机共驾。

## stockx
[[cue:scenario]]光说不练假把式。看一个真实场景：每日股票分析。
[[cue:doc]]这个场景的完整方案，就写在项目的场景文档里：十个以上的专业分析师角色，六个预置团队，二十七个数据源工具。
[[cue:build]]你只需要把这份文档交给 AI，说一声：按这个方案，给我组建一支投研团队。
[[cue:roster]]平台就会照方抓药：主控调度员总揽全局；数据采集员统一喂数；技术、基本面、资金、消息、情绪、行业，六位分析师各管一摊；风险评估师守住底线；图表构建员负责可视化；报告撰写员汇总成文；评审员最后把关。
[[cue:teams]]六位一体，各司其职：盘前简报用协调者模式，个股深度分析走图编排，板块扫描顺序执行，持仓诊断并行推进，盘后复盘流水线合成。
[[cue:cron]]再加上定时调度，每个交易日开盘前、收盘后，简报和复盘自动推送到你的飞书。
[[cue:value]]这，就是把一份专业方案，变成一支随叫随到的 AI 团队。

## customize
[[cue:own]]当然，你不必照抄。每个 Agent 都能深度定制，让它变得更强。
[[cue:model]]第一招，按角色配模型：强推理模型给分析师，快速廉价模型给采集员，好钢用在刀刃上。
[[cue:memory-cfg]]第二招，按任务配记忆：长期研究员开满五层，一次性执行者只留工作记忆，省钱又精准。
[[cue:skill]]第三招，技能按需加载：清单常驻、正文按需调用，Token 花在真正用得到的技能上。
[[cue:tool]]第四招，工具策略细调：重试次数、并行度、熔断器，关键工具还可以要求人工确认。
[[cue:guard]]第五招，进化加护栏：限制变更速率、质量下降自动回滚，让 Agent 自己变强，但永不失控。
[[cue:eval]]再配上评估系统，LLM 评审加趋势追踪，每个 Agent 的质量曲线一目了然。

## more-teams
[[cue:any]]同一套打法，可以复制到任何行业。
[[cue:drama]]想做短剧？组建一支剧组：总导演把控全局，编剧产出剧本，分镜师拆解镜头，角色设计师锁定形象，剪辑师合成成片，审核员守住一致性。
[[cue:novel]]想写爽文？组建一支创作团队：总编剧掌控主线，世界观管理员防止设定崩塌，剧情设计师安排冲突、爽点和反转，伏笔管理员挖坑必填，人设稽查员杜绝角色跑偏。
[[cue:graph]]团队怎么协作，你说了算：顺序、并行、循环打磨，或者在 Graph 画布上，亲手画出你们的生产线。
[[cue:market]]生态市场里，公司、部门、岗位、技能，都能一键安装，最佳实践直接复用。
