# 日志升级计划

> 审计日期：2026-06-01
> 完成日期：2026-06-01
> 目标：将全后端模块统一为 `pkg/loggateway.Logger` 构造函数注入，替换 `loggateway.Global()`，补齐 L1-L10 关键日志节点。

## 三、改造模板

```go
type XxxService struct {
    lg loggateway.Logger
}

func NewXxxService(uc *biz.XxxUsecase, lg loggateway.Logger) *XxxService {
    return &XxxService{uc: uc, lg: lg}
}

// L1 入口:  x.lg.Info("Xxx 操作", loggateway.StepID("xxx.operation"), loggateway.Str("id", id))
// L2 错误:  x.lg.Error("Xxx 失败", loggateway.StepID("xxx.fail"), loggateway.Err(err))
// L4 外部:  x.lg.Error("外部调用失败", loggateway.StepID("xxx.ext_fail"), loggateway.Source(provider), loggateway.Err(err))
// L5 状态:  x.lg.Info("状态变更", loggateway.StepID("xxx.status_change"), loggateway.Str("from", from), loggateway.Str("to", to))
// L6 摘要:  x.lg.Info("批处理完成", loggateway.StepID("xxx.batch"), loggateway.Int("count", n))
// L7 降级:  x.lg.Warn("降级", loggateway.StepID("xxx.fallback"), loggateway.Str("reason", reason))
```

## 四、Data 层特殊策略

| 场景 | 是否加日志 | 原因 |
|------|-----------|------|
| 事务提交失败 | ✅ `lg.Error` | 数据一致性风险 |
| 批量写入失败 | ✅ `lg.Error` | 批量数据丢失风险 |
| Schema 迁移失败 | ✅ `lg.Error` | 启动阻塞 |
| 种子数据写入失败 | ✅ `lg.Warn` | 可能重复写入 |
| 单条查询不存在 | ❌ | 由上游 biz 记录 |
| 单条更新失败 | ⚠️ 视情况 | 关键字段加，普通字段不加 |
| 列表查询失败 | ❌ | 由上游 biz 记录 |
