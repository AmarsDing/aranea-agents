## 四、Data 层特殊策略

| 场景 | 是否加日志 | 原因 |
|------|-----------|------|
| 事务提交失败 | ✅ `lg.Error` | 数据一致性风险（ExecInTx 已加日志） |
| 批量写入失败 | ✅ `lg.Warn` | 批量数据丢失风险（batchUpdateSessions 已加日志） |
| Schema 迁移失败 | ✅ `lg.Error` | 启动阻塞（P1 goroutine 已有 Warn 保护） |
| 种子数据写入失败 | ✅ `lg.Warn` | 可能重复写入（已通过 d.lg 替换 Global()） |
| 单条查询不存在 | ❌ | 由上游 biz 记录 |
| 单条更新失败 | ⚠️ 视情况 | 关键字段加，普通字段不加 |
| 列表查询失败 | ❌ | 由上游 biz 记录 |
| JSON 反序列化容错 | ✅ `lg.Warn` | 数据降级但需关注（data repo 中仍有 4 处使用 Global()） |

### Data 层 ExecInTx 日志规范

```go
func (d *Data) ExecInTx(ctx context.Context, fn func(ctx context.Context) error) error {
    tx, err := d.entClient.Tx(ctx)
    if err != nil {
        d.lg.Error("transaction begin failed", loggateway.StepID("data.tx"), loggateway.Err(err))
        return err
    }
    if err := fn(txCtx); err != nil {
        _ = tx.Rollback()
        d.lg.Warn("transaction rolled back", loggateway.StepID("data.tx"), loggateway.Err(err))
        return err
    }
    if err := tx.Commit(); err != nil {
        d.lg.Error("transaction commit failed", loggateway.StepID("data.tx"), loggateway.Err(err))
        return err
    }
    return nil
}
```
