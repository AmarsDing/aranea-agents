## 0. 文档导读

本文描述 **媒体生成** 的产品能力与验收（用户视角）。架构、接口、表结构见设计文档；代码锚点与差距见开发计划。

---

## 1. 产品定位

用户希望 Agent 能根据自然语言描述生成图片或视频，并在对话与观测画布里直接看到结果，而不是只拿到一段会过期的远程链接。

媒体生成与聊天用的 LLM Provider **不是同一套**：媒体任务是「提交 → 轮询 → 取结果」的长耗时调用。用户在 Agent 设置里启用媒体工具后，对话中即可让 Agent 调用；无需单独打开媒体页面（当前也没有独立媒体管理 UI）。

与观测画布（架构图 39，前端 `chat/observe`）的关系：媒体工具的产物出现在成员节点预览与灯箱中；观测画布本身不是本模块。

## 2. 用户故事

### 2.1 文生图

> 作为使用者，我想在对话里让 Agent「画一张……」，以便立刻看到符合描述的图片。

要点：

- 可指定尺寸（1024×1024 / 1792×1024 / 1024×1792）、风格（写实 / 动漫 / 油画）、数量（1–4）；
- 未配置可用图像提供方时，该工具不会出现在 Agent 可用工具里（构建时跳过并告警），而不是对话中途才报「未配置」；
- 生成结果出现在本轮工具卡片与观测节点预览中。

### 2.2 文生视频 / 图生视频

> 作为使用者，我想让 Agent 按文字生成短视频，或把已有图片变成视频。

要点：

- 文生视频：描述、时长、帧率、分辨率（720p / 1080p）；
- 图生视频：用已有图片的制品 ID 作为输入，可附运动描述；
- 工具在目录中可见且可启用；**当前已注册的通义万相与 ComfyUI 本地实现尚未完成视频接口**，调用会得到明确的「尚未实现」错误，而不是静默失败。

### 2.3 产物长期可看

> 作为使用者，我想过几天再打开历史消息时，图片/视频仍能打开，而不是远程临时 URL 已过期。

要点：

- 成功生成后，产物落入本会话制品库；消息里保存稳定引用；
- 前端展示时换取带时效的下载地址；
- 落盘失败时仍展示原始远程地址（尽力而为，不把整次工具调用打成失败）。

### 2.4 观测画布预览

> 作为使用者，我想在对话观测画布的节点上直接看到缩略图，点击后放大查看。

要点：

- 节点最多展示 3 张缩略图，更多用「+N」提示；
- 图片与视频均可预览；`artifact://` 引用能解析为可播放地址。

### 2.5 运维配置提供方

> 作为运维，我想配置通义万相或本机 ComfyUI 作为生成后端，以便 Agent 真正打到外部服务。

要点：

- 在 `media_providers` 中登记名称、类型、地址、密钥、能力（image / video / image_to_video）与启用状态；
- 同一能力取**最早创建且 status=active** 的一条；
- 无独立 REST 管理面：当前靠库表配置，不在 Web 控制台提供媒体提供方 CRUD。

## 3. 功能需求

| ID | 需求 | 说明 |
|----|------|------|
| FR-1 | 文生图工具 `generate_image` | 必填 prompt；默认尺寸 1024×1024、数量 1；数量上限 4 |
| FR-2 | 文生视频工具 `generate_video` | 必填 prompt；默认 5000ms / 24fps / 720p |
| FR-3 | 图生视频工具 `image_to_video` | 必填 `image_artifact_id` |
| FR-4 | 提供方：通义万相 | 文生图走 DashScope 异步任务（提交 + 轮询） |
| FR-5 | 提供方：ComfyUI 本地 | 文生图走 `POST /prompt` + `GET /history/{id}` |
| FR-6 | 产物落盘 | 远程 http(s) URL 下载后写入会话制品，URL 改写为 `artifact://<id>` |
| FR-7 | 前端预览 | 观测节点缩略图、灯箱、工具详情、Chat 活动流识别媒体工具名 |
| FR-8 | 工具默认关闭 | 内置种子 `enabled=false`，需在 Agent 工具策略中显式启用 |
| FR-9 | 风险等级 | 媒体工具 `riskLevel=medium`，受工具确认策略约束 |

### 3.1 显式不做

| # | 项 | 说明 |
|---|----|------|
| N1 | 独立媒体 HTTP/gRPC 服务 | 无 `api/kratos/media`；只通过 Agent 工具进入 |
| N2 | Web 媒体提供方管理页 | 配置走 `media_providers` 表 |
| N3 | 可灵（Kling）运行时 | 类型字符串出现在配置注释中，**没有**已注册实现 |
| N4 | 与 LLM Provider(9) 共用目录 | 媒体与文本模型目录分离 |

## 4. 交互规格（用户视角）

- Chat 中 Agent 调用媒体工具后，工具卡片展示产物；观测画布节点同步缩略图。
- 历史消息中的 `artifact://` 在打开时换签，用户无感。
- 未启用工具或未配置对应能力的提供方：用户看不到该工具，或 Agent 无法调用。
- 视频类工具在现有提供方上会返回明确错误文案（「not yet implemented」），前端按普通工具失败展示。

---

## 5. 非功能需求

| ID | 项 | 要求 |
|----|----|------|
| NFR-1 | 超时 | 单次生成 HTTP 客户端 5 分钟；轮询上限约 3 分钟 |
| NFR-2 | 降级 | 落盘失败保留远程 URL，工具结果仍成功 |
| NFR-3 | 日志 | 进程日志不记录远程 URL 全文（只记 hash）；prompt 仅前 50 字 |
| NFR-4 | 密钥 | `api_key` 按敏感字段存储 |

## 6. 验收标准

> 进度勾选在开发计划中跟踪，本节只列标准。

| # | 场景 | 标准 |
|---|------|------|
| A1 | 文生图 | 启用 `generate_image` 且存在 active + `image` 能力的提供方时，prompt 可生成至少 1 张图 |
| A2 | 无提供方 | 无匹配提供方时 Agent 构建跳过该工具，不因媒体配置缺失而构建失败 |
| A3 | 落盘 | 成功下载的 http(s) 产物变为 `artifact://`，会话制品可下载 |
| A4 | 历史预览 | 前端将 `artifact://` 换为可显示地址；http(s) 原样展示 |
| A5 | 观测画布 | 节点上可见缩略图，点击可预览 |
| A6 | 视频未实现 | 当前 Qwen / ComfyUI 调用 `generate_video` / `image_to_video` 返回明确错误 |
| A7 | 单测 | `go test ./internal/provider/media/... ./internal/tools/media/...` 通过 |
