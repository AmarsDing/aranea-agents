## 2. 功能需求

### 2.1 制品 CRUD

- 制品与会话（Session）绑定，每个制品属于一个会话。
- 支持上传（base64 编码）、下载（base64 编码）、列出元数据、删除。
- 单个制品大小上限 **10 MB**；超过限制拒绝上传并提示不支持。大于 10 MB 的流式传输为后续支持。
- 上传时自动计算 SHA-256 校验和。
- MIME 类型缺省为 `application/octet-stream`。

### 2.2 版本管理

- 同一会话下相同文件名的制品自动创建新版本，版本号递增。
- 加载制品时可指定版本号；未指定时返回最新版本。
- 列出制品元数据时默认返回每个文件名的最新版本。
- 支持查询某文件名的全部版本历史。
- 删除制品时删除该 ID 的所有版本；也支持按版本号删除。

### 2.3 Agent 运行时集成

- Agent 运行时可通过 trpc-agent-go 的 `artifact.Service` 接口保存/加载制品。
- 代码执行（CodeExecutor）产出物自动保存为制品。
- Runner 创建时注入 ArtifactService，使 Agent 工具链可访问制品。

### 2.4 在线预览

- 支持图片（JPEG/PNG/GIF/WebP）、PDF、代码文件（语法高亮）的浏览器内预览。
- 预览需做 XSS 防护（沙箱 iframe 或 Content-Disposition）。
- 大文件预览需流式处理，避免内存溢出。

### 2.5 签名下载 URL

- 下载链接包含 HMAC-SHA256 签名和过期时间戳。
- 签名密钥由服务端配置，不暴露给前端。
- 过期后返回 403。
- 生产环境缺少签名密钥时 fail-closed（拒绝服务），开发环境回退到不安全密钥。

### 2.6 云存储后端

- 支持 S3 和 COS 作为存储后端，替代本地文件系统。
- 可按配置选择存储后端。
- 多租户路径隔离。

### 2.7 Chat 集成

- Chat 会话面板可查看关联制品列表。
- Chat 消息气泡可内嵌附件 chip 并预览。
- Agent 多模态附件可传入 LLM 上下文。

### 2.8 媒体生成产物持久化

- 媒体生成工具（generate_image / generate_video / image_to_video）产出的图片/视频必须落盘到制品存储，替换远程临时 URL。
- 落盘后产物经 TurnCollector 自动关联到当前消息附件，出现在会话制品列表中。
- 落盘失败时降级保留原始远程 URL，不阻断工具结果返回。

### 2.9 音视频在线预览

- 音频（audio/*）与视频（video/*）制品支持浏览器内联播放（`<audio>` / `<video>`）。
- 大文件不经 base64 内联，走签名直链流式播放。

### 2.10 资源管理器（制品管理页升级）

- 制品管理页提供双视图：「会话产物」（按 session 过滤）与「全部产物」（跨会话按 session 分组浏览存储目录）。
- 聊天页头部提供入口按钮，一键跳转并自动按当前会话过滤。
- 制品详情展示完整落盘路径，支持一键复制。
- 本地部署模式下可调用系统资源管理器打开制品所在文件夹（可配置开关，默认关闭）。

## 4. 非功能需求

- **安全性**：签名密钥生产环境 fail-closed；预览做 XSS 防护（图片 data URI、PDF iframe、文本 `<pre>` 转义）。
- **性能**：单文件上限 10 MB（base64 传输）；文本预览截断 512 KB 避免内存溢出。
- **可扩展性**：存储后端可插拔（local/s3/cos）。
- **可靠性**：制品不在节点间复制，多实例部署需共享卷或云存储后端。

## 5. 已知限制（用户视角）

- S3/COS 云存储后端的生产配置与多租户路径隔离为后续支持。
- 制品不在节点间复制。多实例部署需使用共享卷或配置 S3/COS 后端。
- `data_base64` 编码增加约 33% 开销；大文件（> 10 MB）应优先使用分块流式传输（计划中）。
- 签名密钥生产环境 fail-closed（缺少密钥拒绝服务），开发环境回退到不安全密钥。
