# Agent 设置 —「进化」Tab

本文档描述 **Agent 详情 → 主导航「进化」** 分区：进化能力开关、**时间范围** 筛选、**工具成功率 / 检索质量** 看板、**建议** 区与 **适应护栏** 数值配置；并与 **`agents` 主表** 列、及 **`5 agent-setting.md`** §12、**`2 agents-create.md`** 对齐。

> 本文仅描述用户视角的需求与验收标准。代码分层、Proto/API 契约、数据模型、开发进度等内容分别见 [7-agent-evolution.design.md](./7-agent-evolution.design.md) 与 [7-agent-evolution.development.md](./7-agent-evolution.development.md)。

---

## 1. 页面定位

| 项目 | 说明 |
|------|------|
| **路由建议** | `/agents/:id/settings/evolution`（作为 `settings` 子路由，与 `5` 中 Tab「进化」对应） |
| **用户目标** | 开关控制「风格进化 / 技能进化 / 指标采集 / 建议生成」；查看进化相关指标与建议；配置 **适应护栏** 限制自动调整的幅度与回滚 |
| **数据形态** | 开关与护栏为 **可写配置**；指标与建议多为 **只读**（由运行时写入或日更任务生成） |

## 3. 进化开关（与 `5` §12 一致）

垂直列表；每项 **标题 + 说明 + `QToggle`**，项间 **分隔线**。

| # | 标题 | 说明（产品） | 字段 |
|---|------|--------------|------|
| 1 | 允许 Agent 进化其沟通风格 | 允许随时间更新 **SOUL.md** 中的语调与风格；**身份与操作指令（如 AGENTS.md / IDENTITY.md）保持锁定** | `self_evolve`（BOOLEAN） |
| — | 信息框 | 强调：仅风格/语调可变，身份与工作流规则不变 | `QBanner` / `QCard` bordered |
| 2 | 允许从经验中创建和管理技能 | `skill_manage` 默认可用；可提示用户将工作流保存为技能 | `skill_evolve` |
| 3 | 进化指标 | 记录工具效果、检索质量、反馈等，供看板展示 | `evolution_metrics_enabled` |
| 4 | 进化建议 | 基于指标由分析任务生成改进建议 | `evolution_suggestions_enabled` |

**与创建页对齐**：默认值与行为见 **`2 agents-create.md`**（如 `self_evolve` 默认 true 等）。

**交互**：切换即 **PATCH**（或与全局 debounce 策略一致）；关闭「进化指标」时，§5～§6 可隐藏或展示禁用遮罩 + 说明。

> 字段实现状态、运行时逻辑进度等内容见开发文档 §2「现状评估」。

## 7. 建议（Suggestions）

| 项目 | 说明 |
|------|------|
| **标题** | 建议 |
| **空态** | 文案大意：建议由 **每日分析定时任务** 生成后展示于此 |

## 8. 适应护栏（Adaptive Guardrails）

独立 **`QCard`**：左侧图标（线稿为 **绿色六边形描边**），标题 **「适应护栏」**。

| 字段（UI） | 控件 | 示例值 | 含义（产品） |
|------------|------|--------|----------------|
| **每周期最大变化** | `QInput` type=number 或 slider + 数字 | `0.1` | 单次/每周期允许策略或风格向量的最大变化幅度（0～1 或百分比，以后端语义为准） |
| **最少数据点** | `QInput` type=number，min≥1 | `100` | 低于该样本量时不执行自动调整或仅记录不生效 |
| **下降时回滚** | `QInput` + 后缀 `%` 或 `QInput` 百分比 | `20%` | 当监控指标相对基线下降超过该阈值时，触发回滚到上一稳定版本 |

**校验**：数值范围由后端约定；错误时 `Notify` + 禁止提交。

## 9. 字段 ↔ `agents` 与 `other_config`

### 9.1 顶层与已有键（与 `5` §13 一致）

| UI | 存储 |
|----|------|
| 进化沟通风格 | `self_evolve` |
| 技能进化 | `skill_evolve`（及可选 `skill_nudge_interval`） |
| 进化指标 | `evolution_metrics_enabled` |
| 进化建议 | `evolution_suggestions_enabled` |

### 9.2 适应护栏（建议 JSON 路径）

统一放入 **`evolution_guardrails`**（对象），避免与现有平铺键冲突：

| UI 字段 | 建议键 | 类型 | 示例 |
|---------|--------|------|------|
| 每周期最大变化 | `max_change_per_period` | number | `0.1` |
| 最少数据点 | `min_data_points` | integer | `100` |
| 下降时回滚 | `rollback_on_decline_percent` | number（0–100） | `20` |

若后端用 **小数 0.2 表示 20%**，应在 API 层与 UI 统一换算并在文档/Schema 中写死。

### 9.3 时间范围（可选持久化）

| 行为 | 存储 |
|------|------|
| 默认仅会话态 | 前端 `ref`，不写库 |
| 需记住用户上次选择 | `evolution_time_range_days`：`7` \| `30` \| `90` |

## 10. API 建议

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/agents/:id` | 详情含 `self_evolve`、`skill_evolve`、`*` |
| PATCH | `/agents/:id` | 部分更新；`other_config` 需 **深度 merge**，避免覆盖整块 JSON |
| GET | `/agents/:id/evolution/metrics?range=7d\|30d\|90d`（建议） | 返回工具成功率、检索质量等序列或聚合，供 §5～§6 绘图 |
| GET | `/agents/:id/evolution/suggestions?range=...`（建议） | 返回建议列表（cron 写入后的读取） |

指标与建议的 **写入** 由 **运行时埋点 + 定时任务** 完成，不在此 Tab 内编辑。

> 指标响应含 `partial` / `partial_errors` 字段：部分统计子查询失败时置位，前端可据此区分「暂无数据」与「数据不完整」（2026-08-14 P1-3）。

> API 契约的 Proto 定义、RPC 方法签名等内容见设计文档 §二「Proto 层」。
