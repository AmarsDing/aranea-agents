> **定位**：基于 2023-2026 年 LLM Agent 记忆系统学术研究与竞品分析，系统性补齐本项目记忆系统的关键能力缺口。

## 一、Phase 6 总览

### 1.1 核心判断

Letta 2025 基准测试揭示：**简单文件系统 + 基本检索工具就能超越复杂专用记忆系统**（LoCoMo 74.0% vs Mem0 68.5%）。记忆系统的价值不在于存储和检索机制有多复杂，而在于**上下文管理策略**有多智能——什么该记住、什么该遗忘、什么该整合、何时该召回。

本项目的改进应聚焦于**策略层**，而非盲目增加存储后端。

### 1.2 现有优势

| 能力 | 现状 | 行业对标 |
|------|------|---------|
| 五层记忆模型 L0-L4 | 完整落地 | 业界最系统化（多数竞品仅 2-3 层） |
| 多后端存储 | 8 种后端实现 | 与 Mem0（19+ 向量库）相当 |
| 向量+关键词混合检索 | BM25 + 余弦 + RRF | 与 Mem0、Zep 相当 |
| 自动记忆提取 | LLM 驱动 Extractor + Checker | 与 Mem0 两阶段管线相当 |
| 记忆去重/对账 | Jaccard + 向量相似度 reconcile | 与 Mem0 Update 阶段相当 |
| 分层衰减/遗忘 | L2/L3/L4 分层衰减 | 超越多数竞品 |
| 知识图谱 | L4 实体-关系 + 级联更新 | 部分对标 Zep/Graphiti |
| PII 审查 | memory_pii.go | 少数竞品具备 |
| 死信队列 | 三优先级 + 死信持久化 + 重放 | 少数竞品具备 |

### 1.3 关键差距

| 维度 | 现状 | 行业最佳 | 差距程度 |
|------|------|---------|---------|
| 时序推理 | L2 有时间戳，L3/L4 无双时序 | Zep Bi-Temporal（4 时间戳） | **大** |
| Agent 自主编辑 | 工具调用式（add/update/delete） | MemGPT memory_replace/insert/rethink | **中** |
| 记忆演化 | L4 有演化提案，L2/L3 静态 | A-MEM 动态链接+演化 | **中** |
| 上下文压缩 | 无 | Letta 递归摘要；Claude Code /compact | **大** |
| 多图正交 | L4 单一图谱 | MAGMA 语义/时间/因果/实体四图 | **中** |
| 智能后台整理 | Cron Job 规则驱动 | Letta Sleep-Time Agent（LLM 驱动） | **中** |
| 社区/领域摘要 | 无 | Zep Community Subgraph | **小** |
| 策略引导检索 | 统一评分公式 | MAGMA 策略引导图遍历 | **小** |

## 三、实施路线图

```
Phase 6A — 时序与自主性（高优先级，4 项）
├── 01-双时序模型：L3 Fact + L4 Relation 增加 valid_at/invalid_at
├── 02-Agent自主编辑：memory_replace/memory_rethink 工具
├── 03-记忆演化：L2/L3 新记忆触发旧记忆上下文更新
└── 04-递归摘要：长对话自动压缩，/compact 命令

Phase 6B — 架构升级（中优先级，4 项）
├── 05-多图正交：L4 图谱拆分为语义/时间/因果/实体子图
├── 06-Sleep-Time：LLM 驱动后台 Agent 替代 Cron Job
├── 07-社区摘要：L4 增加社区检测和高层摘要
└── 08-策略引导：查询意图自适应选择检索路径

Phase 6C — 外挂与进化（持续迭代）
├── 10-外挂集成：L3 可外挂 Mem0，L4 可外挂 Zep/Graphiti
└── 09-RL驱动：强化学习训练记忆读写策略（长期研究）
```
