# Agent 头像 — 需求规格

本文档定义 **头像资源库**（持久化）与 **头像管理 UI**（组件）。**不设独立「头像管理」路由页**；仅在 **Agent 创建 / 编辑** 流程中，用户点击头像（`QAvatar`）时弹出组件进行选择、上传与裁剪。

### 与 `2-agents-create.md` 的对应关系（双向关联）

| 文档 | 职责 |
|------|------|
| **`2-agents-create.md` §Avatar** | 产品触点：头像在表单中的位置（与显示名称同区）、`QAvatar` 尺寸、点击行为摘要、**`agents.icon` 存 `avatar_assets.id`**。 |
| **`50-avatar.md`（本文）** | 需求规格：`avatar_assets` 表（BLOB）、**`AgentAvatarPicker`** 弹层、裁剪与上传、**只读出图 API**、删除与引用规则。 |
| **`50-avatar.design.md`** | 实现设计：Proto/Biz/Data/Service/Web 各层具体实现。 |
| **`50-avatar.development.md`** | 开发计划：任务清单与进度。 |

修改头像方案时，请 **同时核对** 上述文档，避免表单字段与存储/API 脱节。

## 1. 设计目标

| 项目 | 说明 |
|------|------|
| **入口** | 创建或编辑 Agent 表单内，点击 **头像区域**（约 80–100px `QAvatar`）。 |
| **形态** | `QDialog`（或 `QBottomSheet` 移动端），内嵌选图、上传、裁剪、确认。 |
| **无独立后台页** | 不提供 `/settings/avatars` 类全屏管理；「我的头像」仅在弹层内以网格维护（可选删除自己上传的项）。 |
| **落库** | **图片字节存数据库**（`avatar_assets.image_data` BLOB）；Agent 侧仅存 **`avatar_assets.id`**（写入 `agents.icon`）。 |

> 存储策略、表结构、`agents.icon` 字段约定的实现细节详见 [50-avatar.design.md §四 数据模型](./50-avatar.design.md#四数据模型) 与 [§五 存储策略](./50-avatar.design.md#五存储策略)。

## 2. 前端组件（用户视角）

### 2.1 弹层内布局

```
┌─────────────────────────────────────────────────────────┐
│  选择头像                                          [×]   │
├─────────────────────────────────────────────────────────┤
│  [ 内置 ]  [ 我的上传 ]     （QTabs）                    │
├─────────────────────────────────────────────────────────┤
│  ┌────┐ ┌────┐ ┌────┐   网格 QAvatar / QImg + 选中描边   │
│  └────┘ └────┘ └────┘                                    │
│  …                                                         │
├─────────────────────────────────────────────────────────┤
│  [ 从本地上传 ]  （QUploader 或隐藏 input + QBtn）         │
├─────────────────────────────────────────────────────────┤
│                    [ 取消 ]  [ 确定 ]                      │
└─────────────────────────────────────────────────────────┘
```

| 区域 | 用户行为 |
|------|---------|
| 容器 | 弹层 `QDialog`，`max-width` 约 480–560px |
| 分区 | `QTabs`：`内置`（系统预置）/ `我的上传`（当前用户 + 工作区） |
| 网格 | 头像网格展示，选中项有描边或勾选标记 |
| 上传 | 选文件后进入 **裁剪子步骤**（见 §2.2），确认后入库 |
| 底部 | `取消` 关闭不写回；`确定` 将当前选中项回写给父组件 |

> 组件命名、Props/Emits、裁剪实现细节详见 [50-avatar.design.md §九 Web 前端设计](./50-avatar.design.md#九web-前端设计)。

### 2.2 裁剪流程

**当前行为**：用户选择本地图片后，前端自动居中裁剪为正方形并缩放，服务端再次中心裁剪 + 生成主图 512px + 缩略图 128px。用户无需手动操作。

**未来增强**：增加 **交互式裁剪**（`vue-advanced-cropper`）让用户自选裁剪区域。

**约束（产品）**：仅允许 **正方形或裁剪为正方形**；最大边长 512px（服务端可再压图）。

> 裁剪算法、图片处理函数签名详见 [50-avatar.design.md §三 Biz 层](./50-avatar.design.md#三biz-层)。

### 2.3 与创建 / 编辑表单的衔接

| 场景 | 行为 |
|------|------|
| **创建** | 默认头像为内置占位或空；点击打开 `AgentAvatarPicker`；确认后 `icon` 参与创建 `POST`。 |
| **编辑** | `QAvatar` 的 `src` 指向 **`GET /v1/avatar-assets/{agents.icon}/thumbnail`**（或 `/file`）；点击可更换；未点确定关闭则保留原值。 |
| **列表/会话** | `src` 同上；需 **登录态 Cookie** 或 **签名 query**；不打开本组件。 |

## 3. 功能需求

### 3.1 头像资源管理

| 需求 | 说明 |
|------|------|
| 内置头像 | 系统预置头像（`is_system=1`），所有用户可见可选 |
| 用户上传 | 用户可上传自己的头像，仅本人/同工作区可见 |
| 头像选择 | 在弹层中通过网格浏览、点选，确认后回写资源 id |
| 头像删除 | 用户可删除自己上传的头像（软删）；内置头像不可被普通用户删除 |
| 引用保护 | 删除头像前检查是否有 Agent 引用，有引用时禁止删除 |

### 3.2 头像出图

| 需求 | 说明 |
|------|------|
| 主图读取 | 通过 API 读取头像主图二进制流，供 `<img :src="...">` 或 `QImg` |
| 缩略图读取 | 通过 API 读取缩略图（128×128），列表/网格优先用缩略图降低带宽 |
| 鉴权 | 二进制流与会话 Cookie 同源；禁止遍历他人 `id` |

### 3.3 渠道平台图标

| 需求 | 说明 |
|------|------|
| 内置渠道图标 | 系统预置渠道平台图标（从 Iconify API 获取） |
| 图标刷新 | 可触发从 Iconify API 重新获取渠道平台图标并更新 DB |
| 自定义渠道图标 | 用户可上传自定义渠道图标 |

> API 端点、Proto 契约、权限规则详见 [50-avatar.design.md §二 Proto 层](./50-avatar.design.md#二proto-层) 与 [§六 API 契约](./50-avatar.design.md#六api-契约)。

## 4. 非功能需求

| 项 | 要求 |
|----|------|
| 文件类型 | `image/jpeg`、`image/png`、`image/webp` |
| 文件大小 | ≤ 2 MB（上传前前端校验 + 服务端再验） |
| 输出边长 | 主图 512px，缩略图 128px（服务端自动处理） |
| 列表分页 | 内置一次加载；上传较多时 `mine` 分页或虚拟滚动 |
| BLOB 限额 | 单张原图压至 ≤512px、≤200KB 级再入库，避免单行过大拖慢备份 |
| 缩略图 | 128×128 JPEG，列表只读小图 |

## 5. 验收要点

- [ ] 创建/编辑页点击头像仅通过弹层完成选图，**无独立管理页**亦可完成闭环。
- [ ] 内置 / 我的上传 分区清晰；选中态与「确定」回写正确。
- [ ] 上传 → **自动中心裁剪** → **BLOB 入库** → `agents.icon` 写入资源 id → 列表/表单通过 **`/thumbnail` 或 `/file`** 正常显示。
- [ ] 服务端自动压缩至 512px 正方形 + 生成 128px 缩略图。
- [ ] 渠道平台图标刷新（从 Iconify API 获取 → 渲染 PNG → upsert）。
- [ ] 交互式裁剪（`vue-advanced-cropper`），用户可自选裁剪区域。
- [ ] 删除前 Agent 引用检查，有引用时禁止删除。
- [ ] 预置资源不可被普通用户删除（`is_system=true` 保护）。
- [ ] 与 `2-agents-create.md` §Avatar 行为一致（图库 + 上传 + 裁剪 + 写入 icon）。

> 各验收项的当前实现状态详见 [50-avatar.development.md §6 验收标准](./50-avatar.development.md#6-验收标准)。
