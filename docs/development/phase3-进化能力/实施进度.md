### 实现详情

- **Delta 更新协议**：SKILL.md 规则用 `<!-- aranea:rule id="..." helpful=N harmful=M -->` 标记包裹为规则块；Curator 只输出 add/modify/merge/remove 操作序列，程序执行局部更新，避免整体替换的 Context Collapse。规则 id 跨版本稳定，是计数归因锚点
- **计数归因闭环**：Create 时落 baseline_success_rate → 下一周期 AttributeLastEvolution 裁决（±5pp 阈值，<5 次调用 insufficient_data）→ effectiveness 幂等回写 → BumpRuleCounters 归账到受影响规则 → 随新版本正文传递（版本不可变）
- **协议降级**：delta 解析/应用任一失败 → Warn 日志回退全量重写；全量重写 prompt 要求包裹规则块，下一周期有机进入 delta 模式
- **Gate 五维**：功能（sandbox + 数据集回放，通过率 <60% 拒绝）+ 安全 + 性能 + 风格 + 效果（harmful≥3 规则原样保留拒绝）
- **nil-safe 降级**：无绑定数据集 / LLM 未配置 / 查询失败 → Gate 对应维度跳过不阻断
- **验证**：`go build ./...` exit 0；`go test ./internal/biz/ ./internal/service/` 全绿
