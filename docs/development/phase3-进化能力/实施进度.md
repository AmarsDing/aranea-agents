### 实现详情

- **四层架构**：api/proto → service → biz → data (Raw SQL + DDL Migration)
- **ProfileResolver 桥接**：biz.RuntimeProfile (DB-backed) → framework runtimeprofile.Profile (in-memory) → agent.RunOption (per-request)
- **单活跃不变量**：每个 Agent 同时只有一个 active profile，由 Usecase 层 deactivateActiveForAgent 强制
- **优雅降级**：Profile 解析失败时记录 Warn 日志，使用 Agent 默认配置继续
- **框架复用**：ToolFilter/SkillFilter/KnowledgeFilter 由 `runtimeprofile.RunOptions()` 内部生成，无需重复实现
- **RunOptions 注入点**：`buildTurnRunOptions` 中追加 profile 覆盖选项，在 LLM 调用前生效
- **HTTP/gRPC 双协议**：6 个 RPC 端点（List/Get/Create/Update/Delete/SetActive）
- **前端 API + Store**：完整 CRUD API wrapper + Pinia Store（单活跃不变量本地同步）
- **DDL 迁移版本**：20260730（避免与 avatar_image_repair 的 20260729 冲突）
