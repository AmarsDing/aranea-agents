横切关注点

trpc-agent-go 桥接

  • sqliteMemoryService 实现 6 个工具
  • Add / Update / Delete / Clear / Search / Load
  • Agent 运行时通过工具集操作记忆

记忆注入流程

BeforeModelHook
↓ L1 pinned 字段
↓ Composite(L2+L3) 召回
↓ L4 实体关系
↓ 注入 system prompt

AutoMemory 队列

  • 对话结束后入队
  • Consolidator.Extract 提取
  • UpsertFactsAndEpisodeBatch 写入

CompositeRecall

  • 融合 L2 + L3 召回结果
  • 去重 + 重排序
  • 统一注入上下文窗口

PolicyEngine

  • 审计日志 memory_action_log
  • PII 检测与脱敏
  • 作用域隔离 (scope_type + scope_id)

数据流总览

用户消息 → L1 工作记忆
L1 归档 → L2 情景片段
AutoMemory → L2 + L3
L3 事实 ↔ L4 实体关系
CompositeRecall → system prompt
