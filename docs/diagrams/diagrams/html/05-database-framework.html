Aranea-Agents 数据库架构
Data → ReadWriteClient → Ent / RawSQL / PostgreSQL
Data 结构体
  • entClient 写连接 MaxOpenConns=1
  • readClient 读连接 MaxOpenConns=2
  • rawDB 原始写数据库句柄
  • readDB 原始读数据库句柄
  • pg PostgreSQL 连接 (可选)
ReadWriteClient Write→entClient / Read→readClient
ReadWriteDB WriteDB→rawDB / ReadDB→readDB
entsql.OpenDB 共享连接池 Ent + Raw SQL
pg PostgreSQL 独立连接池 (可选启用)
SQLite 主库
  • WAL 模式启用并发读写
  • foreign_keys=ON 外键约束
  • busy_timeout=30000 锁等待 30 秒
  • Ent ORM: 56 schemas 类型安全 CRUD
  • Raw SQL: 50+ 记忆表 复杂 upsert / 向量查询
  • entsql.OpenDB 共享底层连接池
  • 单文件部署，零外部依赖
PostgreSQL 向量库
  • pgvector 扩展向量相似度检索
  • ivfflat + GIN 索引加速
  • agent_memory_{dim} 按维度分表存储
  • knowledge_chunks 知识分块存储
  • knowledge 三表结构: 文档 → 分块 → 嵌入
  • 可选启用，SQLite 独立可用
  • 高维向量近邻搜索专用
初始化流程
同步
initSQLite → initPostgres → seedAdminUsers
异步 P1
ensureSchemaDDL (37 迁移) → ensurePostgresSchemas → runPendingDataMigrations → seedP1Data
读写分离
ReadWriteClient
Write → entClient (MaxOpenConns=1)
Read → readClient (MaxOpenConns=2)
ReadWriteDB
WriteDB → rawDB (原始写句柄)
ReadDB → readDB (原始读句柄)
Ent CRUD
  • 类型安全代码生成
  • 56 schemas 自动生成
  • Where / Order / Pagination
  • 编译期类型检查
  • Eager Load 关联
Raw SQL
  • 复杂 upsert 操作
  • 向量相似度查询
  • 50+ 记忆表访问
  • 批量数据迁移
  • 跨表聚合统计
PostgreSQL
  • 纯 pgvector 操作
  • ivfflat 近邻搜索
  • knowledge 三表 CRUD
  • agent_memory 嵌入存储
  • GIN 索引全文检索
事务管理
  • ExecInTx 事务执行入口
  • context.WithValue 传递事务
  • fn() 执行业务逻辑
  • Commit / Rollback 自动处理
  • 嵌套事务检测与拒绝
DDL 迁移
  • 37 版本 增量迁移
  • schema_migrations 表幂等控制
  • 按版本号顺序执行
  • 已执行版本自动跳过
  • 启动时自动检测并运行
Wire DI
  • 65 providers 依赖注入
  • 编译期依赖图验证
  • Data → Biz → Service 分层注入
  • Repo 接口绑定自动完成
  • 循环依赖编译期报错
编译时接口检查
26+ × var _ biz.XxxRepo = (*xxxRepo)(nil)  —  确保每个 Repo 实现均满足 Biz 层接口契约，编译期即发现签名不匹配
