Aranea-Agents 日志管线架构
loggateway.Gateway → logpipeline.Pipeline → SinkGroup → Sink
loggateway.Gateway 调用方入口
  • Logger 接口: Debug / Info / Warn / Error
  • With(fields) 子 logger 预设字段链式追加
  • emitToPipeline 序列化 Fields → 构造 LogEntry → pipeline.Emit
  • noopLogger 空实现，静默丢弃
Field 类型
StepIDSessionID TraceIDRunID DomainAgentKey PhaseDuration Err
logpipeline.Pipeline 异步管道
  • 主 channel 缓冲=4096
  • dispatchLoop 独立 goroutine 消费
3 级背压策略
closed → dropped
→
throttler → throttled
→
channel 满 → dropped
令牌桶限流
  • stepThrottler 按 step_id 前缀匹配
  • ThrottleRule{Prefix, MaxPerSec}
SinkGroup 隔离输出
  • 每个 Sink 独立 SinkGroup 隔离
  • 独立 goroutine + 独立 channel
  • DropPolicy: DropNewest(默认) / DropBlock
  • Panic recovery 自动恢复
FileSink
  • zap JSON 编码
  • lumberjack 日志轮转
  • 按大小/日期自动切割
  • 持久化落盘存储
StdoutSink
  • JSON → stdout 输出
  • 级别过滤 LevelFilter
  • 开发环境调试用
  • 零持久化开销
EventBusSink
  • Publisher → EventBus
  • 断路器保护 (CircuitBreaker)
  • 失败自动熔断隔离
  • 半开探测恢复机制
断路器状态机 — EventBusSink 保护
Closed
正常通过
5 次失败
Open
熔断拒绝
10 秒超时
HalfOpen
探测恢复
3 次成功
Closed
恢复通过
HalfOpen → 1 次失败 → Open   |   Closed → 5 次连续失败 → Open
RuntimeLogAdapter
  • 桥接 trpc-agent-go 运行时日志到 loggateway
  • 实现 logging.Logger 接口适配
  • Fatal 级别旁路管线，直接 os.Exit(1)
  • Debug/Info/Warn/Error 走正常管线流程
  • 运行时日志零额外配置接入
Flow Tracking 追踪体系
  • TraceContext — 链路上下文传递
  • FlowTracker — 流程追踪器，关联 step/run
  • FlowContext — 流程上下文，携带 Span 信息
  • SpanCollector — Span 采集聚合
  • UsageAggregator — 用量统计聚合 (token/time)
