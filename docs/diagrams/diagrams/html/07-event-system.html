Aranea-Agents 事件与实时通信架构
Service/Biz → Infra.Publish → Bus → WebSocket → Frontend
Service / Biz 事件源
  • 业务逻辑触发事件
  • Infra.Publish() 统一发布
  • 携带 sessionID / type / payload
Infra.Publish 路由分发
  • Split 模式路由规则
  • flow_log → MonitorBus
  • alert → 双发
  • 其他 → SessionBus
SessionBus / MonitorBus 事件总线
  • SessionBus 会话级事件
  • MonitorBus 监控级事件
  • 订阅者模式分发
环形缓冲 — 断线重连保障
  • 环形缓冲容量: 200 / 会话
  • TTL: 30 分钟 自动过期
  • Replay: 断线重连时回放丢失事件
  • 按 event_id 顺序回放
  • 内存开销可控，自动淘汰旧事件
断线重连流程
  • 客户端携带 last_event_id 重连
  • 服务端 Buffer 查找断点位置
  • 发送 replay_start 标记
  • 回放 entries 事件序列
  • 发送 replay_end 标记完成
last_event_id → Buffer.Replay → replay_start → entries → replay_end
WebSocket 服务端
  • WSServer: eventBus + monitorBus + buffer + canceller
  • wsConn: sessionID, channels, filterKey
  • 每连接独立 goroutine 读写
  • 连接级取消控制
  • 事件过滤 filterKey 按类型筛选
writePump 消费策略
drainSelect: high → normal → low
每轮最多 8 条 low 事件
high cap=64
alert / MCP 健康 — 阻塞 5 秒后关闭连接
normal cap=128
runner_completion / team / system
low cap=256
flow_log / log — 每轮限 8 条
