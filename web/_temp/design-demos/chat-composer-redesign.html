针对「输入框与按钮布局太杂乱」的 3 个方向

方案 A · 统一圆角卡片

推荐

参考 ChatGPT / Claude 的现代聊天输入：把选择器、文本域、操作按钮全部收纳进一个圆角卡片。选择器以紧凑 pill 形式放在卡片顶部，按钮在底部一行排开，视觉重心聚焦在输入区。

方案 B · 极简悬浮条

最干净

把次要操作（附件、语音、面板入口）收到胶囊入口里，默认只显示输入框和发送按钮。适合希望界面尽可能克制的场景；复杂选择器通过入口展开或前置到顶部。

方案 C · 结构化双行（精炼版）

保留现有结构

保留「顶部工具栏 + 底部输入区」的双行骨架，但把选择器压缩为更小的下拉控件，并把输入框与按钮整合进同一张卡片，减少视觉碎片。

设计师建议

针对当前产品定位（企业级多 Agent 编排助手，非轻量聊天工具），推荐方案 A：它既保留了模式/模型选择的可见性（用户需要知道当前 Agent 以什么能力运行），又把输入框、附件、语音、发送整合到一个卡片内，视觉碎片最少。方案 B 虽然最干净，但会把高频选择器隐藏，增加用户认知负担；方案 C 是对现有结构的温和改良，适合不希望大改交互习惯的场景。
