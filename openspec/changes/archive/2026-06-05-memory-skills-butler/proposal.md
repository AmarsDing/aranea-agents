# Memory & Skills Butler

## Why

记忆管家和技能管家是系统内置管家体系的核心成员，但当前系统缺少：选择性记忆能力（存储所有经验反而降低性能）、质量驱动遗忘机制（错误记忆通过经验跟随效应传播）、技能进化/消亡决策能力（基于使用数据驱动）、编排效率分析能力。需要基于学术研究构建经验分析引擎，为记忆管家和技能管家提供数据驱动的决策能力。

## Goals

- 构建经验分析引擎（ExperienceAnalyticsUsecase）作为共享基础设施层
- 实现记忆管家：选择性记忆（预测误差蒸馏）、质量驱动遗忘（misaligned 检测）、记忆蒸馏（情景→语义）、dream_cycle 复合操作
- 实现技能管家：Skill 健康度分析、技能进化/退役、工具权重优化、编排效率分析
- 所有设计原则可追溯到学术论文（7 篇论文，15 条原则）

## Non-goals

- P0 阶段不做 LLM 预测误差调用（改用语义新颖度规则替代，节省 Token）
- P0 阶段不实现遗忘策略可配置（默认 hybrid 策略）
- 不修改 trpc-agent-go 框架的 Assemble() 方法
- 不实现 Agent 能力画像自动更新（P2 阶段）
