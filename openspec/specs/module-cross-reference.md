## 定位

模块交叉参考手册描述"改模块 X 时必须注意谁"，与架构蓝图（描述"模块是什么"）互补。

## 使用方法

1. 找到目标模块卡片
2. 检查**上游依赖**：调用了谁的接口？改了签名谁会断？
3. 检查**下游影响**：谁依赖你的接口？改了谁会崩？
4. 检查**共享契约**：修改的类型/事件是否被其他模块消费？
5. 检查**事件契约**：新增/修改的事件类型是否在消费方处理？
6. 检查**前端对应**：后端改动是否需要前端同步？

## 卡片维度（8 维度）

每个模块卡片包含：

| 维度 | 说明 |
|------|------|
| 上游依赖 | 调用了谁的接口 |
| 下游影响 | 谁依赖你的接口 |
| 核心导出 | 对外暴露的函数/类型 |
| 实现接口 | 实现了哪些 biz 端口 |
| 共享类型 | 被多模块共享的 DTO |
| 事件生产 | 产出的事件类型 |
| 事件消费 | 消费的事件类型 |
| 数据库 | 直接/间接访问的表 |
