## Requirements
### Requirement: SkillIntelligenceRepo interface split
The SkillIntelligenceUsecase constructor SHALL accept three narrow interfaces (ExperienceReportReader, ExperienceReportWriter, SkillHealthAggregator) instead of the combined SkillIntelligenceRepo interface. The SkillIntelligenceRepo composite interface SHALL be retained as a Wire binding anchor.

#### Scenario: Constructor accepts narrow interfaces
- **WHEN** NewSkillIntelligenceUsecase is called with reader, writer, aggregator, and logger
- **THEN** the usecase stores each interface in its own field and delegates accordingly

#### Scenario: Wire binds SkillIntelligenceRepo to data implementation
- **WHEN** Wire resolves SkillIntelligenceUsecase dependencies
- **THEN** the data.SkillIntelligenceRepo is bound to biz.SkillIntelligenceRepo, and the three narrow interfaces are resolved from the same concrete type

### Requirement: Skill intelligence magic number extraction
All numeric thresholds in skill_intelligence.go SHALL be defined as named constants at package level.

#### Scenario: Timeout threshold constant
- **WHEN** AnalyzeInvocation checks duration against 30s timeout
- **THEN** it uses the constant `TimeoutThresholdMS = 30000`

#### Scenario: Context overflow threshold constant
- **WHEN** AnalyzeInvocation checks input length against overflow threshold
- **THEN** it uses the constant `ContextOverflowThreshold = 5000`

#### Scenario: Minimum invocation count constant
- **WHEN** ScoreSkill checks if invocation count is below minimum
- **THEN** it uses the constant `MinInvocationCount = 5`

#### Scenario: Default neutral score constant
- **WHEN** ScoreSkill returns a neutral score for insufficient data
- **THEN** it uses the constant `DefaultNeutralScore = 50`

### Requirement: Skill intelligence ID generation
GenerateReport SHALL use uuid.New().String() for report ID generation instead of fmt.Sprintf.

#### Scenario: Report ID is a UUID
- **WHEN** GenerateReport creates a new ExperienceReport
- **THEN** the ID field is a UUID string generated by uuid.New().String()

### Requirement: Data layer interface{} modernization
The data layer skill_intelligence.go SHALL use `map[string]any` instead of `map[string]interface{}`.

#### Scenario: Selection snapshot deserialization
- **WHEN** Create or BatchCreate deserializes SelectionSnapshot JSON
- **THEN** it uses `map[string]any` as the target type
