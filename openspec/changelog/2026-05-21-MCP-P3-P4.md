# MCP P3–P4 优化（2026-05-21）

## 摘要

完成 MCP 模块 Phase 2–3 演进：调用统计与 Prometheus、持续健康告警、按用户凭据、配置预检 API 及前端入口。

## P3-4 调用统计

- `internal/mcp/classify`：识别 Broker 工具、`mcp_*__*` 前缀及 `GetMeta()` 结果
- `tool_invocation_recorder`：`aranea_mcp_invocation_total` + 会话 `mcp_call_count` 增量

## P3-5 健康告警

- `metadata`：`health_error_since` / `last_health_alert_at` 与防抖
- `internal/mcp/alert`：持续 `error` 超 `MCP_HEALTH_ALERT_AFTER`（默认 5m）后发布 `mcp.health_alert` 事件
- Wire：`provideMCPHealthRunnerDeps` 注入 `event.Bus`

## P3-6 用户凭据

- 表 `platform_mcp_user_credential`（`docs/sql/20_mcp_user_credential.sql`）
- Biz/Data：`List/Upsert/Delete`、`ResolveUserAuthHeaders`（加密存储，复用 Channel 密钥方案）
- Agent：`require_user_credentials` 时合并用户头
- API + 前端：`McpUserCredentialDialog`、列表项「用户凭据」

## P4-7 预检 API

- `POST /v1/mcp-servers/validate` → `MCPServerUsecase.ValidateConfig`（probe，不落库）
- 表单「预检配置」按钮
