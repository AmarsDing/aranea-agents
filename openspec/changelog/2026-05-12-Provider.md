# 2026-05-12 Provider: ADK → trpc-agent-go 迁移 + 多 Provider 支持

**影响**：🔴 高 | **模块**：Provider / Agent / Team / Memory / Tools

## 变更摘要

核心框架从 Google ADK 完全迁移到 trpc-agent-go (v1.9.1)，新增 Anthropic/Gemini/Ollama/混元 Provider 原生支持，引入 Failover/Hedge 高可用机制，新增工具集系统和 SQLite 内存持久化。

## 关键变更

- 核心框架 ADK → trpc-agent-go (v1.9.1)
- 新增 Anthropic、Gemini、Ollama、混元等 Provider
- 引入高可用机制：Failover（故障转移）和 Hedge（请求对冲）
- 新增工具集系统（文件系统 + Shell 执行）
- 重构内存服务，实现 SQLite 持久化适配器

## 破坏性变更

1. 完全移除 Google ADK 依赖
2. Provider 配置结构变化，需迁移
3. 内存接口变更，需适配 `trpcmemory.Service`
