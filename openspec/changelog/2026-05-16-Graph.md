# 2026-05-16 Graph: 工作流完善

**影响**：🟡 中 | **模块**：Graph / Event / Service / Frontend

## 变更摘要

Graph 工作流模块三阶段完善：P0 基础能力（事件桥接、Checkpoint API、DOT 可视化增强、前端事件流）+ P0/P1 四维架构（设计时校验引擎、设计模式模板、前后端全链路打通）+ P1 核心实现（Task 模型与状态机、Agent 角色派工、审核门禁、结构化日志、运行历史、心跳感知超时）。

## 关键变更

### 阶段一：P0 基础能力

- Graph 事件桥接到 EventBus/WS（9 种事件映射）
- 新增 ListCheckpoints/GetStateSnapshot/EditState 3 个 Checkpoint RPC
- DOT 可视化增强，解析为结构化 JSON 支持 Vue Flow 渲染
- 前端 Graph 事件流（useGraphStream composable）

### 阶段二：P0/P1 四维架构

- 设计时校验引擎（5 维度：拓扑/节点引用/Agent 引用/State Schema/循环出口）
- 6 种内置设计模式模板（pipeline/approval/parallel_review/review_loop/dispatch/nested_subgraph）
- 3 个新 RPC（ValidateGraph/ListGraphTemplates/CreateGraphFromTemplate）
- NodeDef 扩展（description + destinations）
- 前端类型与 API 同步更新

### 阶段三：P1 核心实现

- Task 模型与 10 状态状态机（PENDING/CLAIMED/COMPLETE/BLOCKED/REVIEW_REQUIRED/FAILED/TIMED_OUT/CANCELLED/CRASHED/PENDING_ASSIGNMENT）
- Agent 角色与动态派工（required_role + assignment_mode + assignment_strategy）
- 审核门禁（Reviewer Agent + 评论反馈 + ApproveTask/RejectTask）
- 结构化日志（TaskLog：stream/level/timestamp）
- 运行历史（TaskRun：exitCode/logRef）
- 心跳感知超时（Heartbeat + 租约自动续约）
- 事件追踪（TaskEvent）
- 12 个新 RPC（ListTasks/GetTask/ClaimTask/SubmitTaskResult/Heartbeat/ReportBlocked/ListTaskComments/AddTaskComment/ListTaskLogs/ListTaskRuns/ListTaskEvents）
- Agent Ent Schema 新增 roles_json 字段
- 前端 Task 类型 + 11 个 API 函数

## 破坏性变更

无破坏性变更，均为新增功能。
