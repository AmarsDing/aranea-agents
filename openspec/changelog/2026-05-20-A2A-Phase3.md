# Changelog — A2A Phase 3（跨实例 Server + 远程注册 + mTLS + 工作区策略）

**日期**：2026-05-20  
**模块**：A2A（26）、HTTP 传输、Auth

## 摘要

完成 A2A **Phase 3** 主体：本地 LLM Agent **A2A Server 对外 HTTP 暴露**、**远程 Agent 注册 API/UI**、客户端 **mTLS / API Key / Bearer** 鉴权、Admin **Invoke 跨工作区策略**。

## 后端

### A2A Server 对外 HTTP

- `internal/a2a/trpc/server.go`：`BuildA2AEndpointServer`（trpc-agent-go `server/a2a`）
- `internal/a2a/trpc/registry.go`：`EndpointRegistry`，路径前缀 `/v1/a2a/public/{agent_id}`
- `internal/service/a2a_endpoint.go`：`A2AEndpointBuilder` 按 catalog Agent + 已启用 AgentCard 构建 handler
- `internal/server/http.go`：`HandlePrefix(PublicPathPrefix, registry)`；`auth.RegisterNoAuthPathPrefix` 公开路径免 Admin JWT
- `cmd/admin/wire.go`：`A2A_PUBLIC_BASE_URL` 或从 HTTP addr 推导公开 Base URL

**公开 URL**：`{base}/v1/a2a/public/{agent_id}`（需 catalog Agent + `a2a_agent_cards.enabled=true`，非 `a2a_proxy`）

### 远程 Agent 注册

- `api/kratos/a2a/v1/a2a.proto`：`A2ARemoteAgent`、`RegisterRemoteAgent`、`ListRemoteAgents`、`DeleteRemoteAgent`、`DiscoverRemoteAgent`
- `internal/biz/a2a_remote.go`：远程注册用例
- `internal/data/a2a.go`：表 `a2a_remote_agents` + CRUD；`Discover` 合并本地 cards + 远程 registry

### mTLS / 客户端鉴权

- `internal/a2a/remote_client.go`：`ClientAuthOptions`、`MTLSHTTPClient`、`FetchRemoteAgentCard`
- `internal/a2a/trpc/auth.go`：委托 `a2a.ProxyClientAuthOptions`（api_key / bearer / mtls）
- Proxy Agent 与远程 Discover/Register 共用同一 auth 解析逻辑

**mTLS 配置**（`auth_config_json`）：`{ "cert_file", "key_file", "ca_file?" }`  
Server 侧 mTLS 终止建议走反向代理（Ingress / Nginx）。

### Admin Invoke 跨工作区策略

- `api/kratos/a2a/v1/a2a.proto`：`A2AInvokeRequest.workspace`
- `internal/a2a/invoke_workspace.go`：`ValidateAdminInvokeWorkspace`（请求 workspace + `X-Workspace-ID` context 与 callee card workspace 一致）
- `internal/service/a2a.go`：Invoke 调用校验；复用 `NewInvoker`

## 前端

- `/a2a` 新增 **远程注册** Tab：`A2ARemoteAgentPanel.vue` + 已注册列表
- `stores/a2a`：`loadRemoteAgents` / `registerRemote` / `removeRemote` / `previewRemote`
- `A2AInvokePanel`：可选 **Workspace** 字段（Admin 跨工作区 Invoke）
- `AgentSettingsA2ATab`：Proxy 鉴权支持 **mTLS** 证书路径

## 架构质量

- **分层**：biz 不 import trpc-agent-go；公开 A2A Server 组装在 `internal/service` + `internal/a2a/trpc`
- **接口**：远程注册 CRUD + Discover 预览独立 RPC；Invoke workspace 显式 proto 字段
- **安全**：公开 Endpoint 仅暴露已启用 AgentCard 的 catalog Agent；Admin Invoke 仍须 JWT + workspace 对齐
