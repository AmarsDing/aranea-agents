# 2026-05-12 Provider: ADK → trpc-agent-go 迁移

## 影响范围

🔴 **高** - 核心框架从 Google ADK 完全迁移到 trpc-agent-go，同时扩展 LLM Provider 支持

## 关键变更

- 核心框架从 Google ADK 迁移到 trpc-agent-go (v1.9.1)
- 新增 Anthropic、Gemini、Ollama、混元等 Provider 原生支持
- 引入高可用机制：Failover（故障转移）和 Hedge（请求对冲）
- 新增工具集系统（文件系统 + Shell 执行）
- 重构内存服务，实现 SQLite 持久化适配器
