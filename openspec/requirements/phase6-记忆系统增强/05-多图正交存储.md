# 05 — 多图正交存储

> **借鉴来源**：MAGMA（Multi-Graph Agentic Memory Architecture, arXiv:2601.03236）
> **优先级**：中（架构级改进）
> **影响层**：L4 知识图谱
> **最后更新**：2026-06-06

## 一、需求文档

### 1.1 背景

当前 L4 图谱是单一图谱，语义关系、时间关系、因果关系、实体关系混合存储。这导致：
1. **检索精度受限**：不同关系类型纠缠，查询时无法按意图选择关系维度
2. **因果推理缺失**：无法表达"因为X所以Y"的因果链
3. **时间骨干缺失**：时间信息仅作为边属性，无法作为硬约束

### 1.2 MAGMA 的做法

MAGMA 将记忆表示为 4 个正交图：

| 图 | 存储内容 | 边类型 | 特性 |
|----|---------|--------|------|
| 语义图 | 语义相似关系 | SIMILAR_TO | 向量相似度 |
| 时间图 | 时序关系 | BEFORE/AFTER | 严格有序、不可变 |
| 因果图 | 因果关系 | CAUSES/PREVENTS | 可异步推断、可修正 |
| 实体图 | 实体关系 | WORKS_AT/LIVES_IN/... | 结构化属性 |

**关键原则**：
- **时间骨干 = hard constraints**（低延迟、可重放、不可改）
- **因果链接 = soft inferences**（可异步修正）
- 检索是**策略引导的图遍历**，根据查询意图自适应选择遍历路径

### 1.3 目标

1. L4 图谱拆分为语义/时间/因果/实体四个正交子图
2. 时间图作为不可变骨干，写入后不可修改
3. 因果图支持异步推断和修正
4. 检索时根据查询意图选择遍历的子图

### 1.4 功能需求

#### P0 — 必须实现

| ID | 需求 | 说明 |
|----|------|------|
| MG-P0-1 | 子图类型标识 | L4 Relation 增加 `graph_type` 字段（semantic/temporal/causal/entity） |
| MG-P0-2 | 时间图不可变 | graph_type=temporal 的边写入后不可修改或删除 |
| MG-P0-3 | 按图类型过滤检索 | 召回时可指定遍历哪些子图 |

#### P1 — 应该实现

| ID | 需求 | 说明 |

### 1.5 验收标准

1. L4 Relation 可按 graph_type 分类存储和检索
2. 时间图边写入后不可被修改
3. 召回时可指定仅遍历特定子图
4. 现有 L4 数据迁移后 graph_type 默认为 entity
5. `make wire && make build && make test` 全部通过

## 二、设计文档

### 2.1 数据模型变更

```sql
ALTER TABLE memory_relations ADD COLUMN graph_type VARCHAR(20) NOT NULL DEFAULT 'entity';

-- 图类型枚举
-- semantic: 语义相似关系（SIMILAR_TO）
-- temporal: 时序关系（BEFORE/AFTER）
-- causal: 因果关系（CAUSES/PREVENTS）
-- entity: 实体关系（WORKS_AT/LIVES_IN/...）

-- 时间图不可变约束（应用层强制）
-- graph_type=temporal 的记录不允许 UPDATE/DELETE
```

### 2.2 检索逻辑变更

```go
type GraphTraversalOptions struct {
    GraphTypes []GraphType  // 要遍历的子图类型
    MaxHops    int          // 最大跳数
    Direction  Direction    // 遍历方向
}

type GraphType string

const (
    GraphTypeSemantic GraphType = "semantic"
    GraphTypeTemporal GraphType = "temporal"
    GraphTypeCausal   GraphType = "causal"
    GraphTypeEntity   GraphType = "entity"
)
```

### 2.3 与 theory.md 的对齐

`theory.md` §13 明确指出：
> 时间图为严格有序对构成不可变时间骨干；快路径先建时间边，慢路径异步推断因果/实体。消融：去掉时间骨干评分 0.700 → 0.647。
